## 1 三条采集纪律

1. **只采公开或授权数据**。公开 API、公开 CSV、公开通报、登记制学术数据。平台内部行为数据只走研究接口或授权存档，不爬、不绕验证。
2. **一文件一账**。每个快照记 URL、UTC 时间、HTTP 状态、字节数、SHA256（`data/MANIFEST.tsv`）。没有账的读数不许进正文。
3. **拿不到就写拿不到**。受限、超时、限速，一律在 `MANIFEST.tsv` 留痕，并在 `variables.md` 降级为 C。**不许用"估计"填缺口。**

Kaggle 公开数据集**无需登录即可下载**（实测 200），HF 公开文件可直接 resolve。已落三份：

| 数据集 | 内容 | 用途 | 结论 |

**两个实测结论（都是坏消息，但有用）**

**⑤ τ 有分布了，而且比模型假设的短。**
PolitiFact 21,063 条可配对记录：**中位 6 天，P25 = 2，P75 = 13，P90 = 26**；τ>30 天占 7.8%，τ>365 天占 0.5%。
按年中位数：2007 = 8，2008 = 2，2016 = 5，2020 = 4，2022 = 4——**没有上升趋势**。
**后果**：模型说"τ 以天计、套利窗口以小时计"成立；但"τ 极长"不成立。美国侧的核实已经相当快，套利空间靠的是**首发—核实的时差**，不是"没人核实"。

**⑥ 热搜标题不能测 π_L。**
微博热搜 69,936 条里，"摆拍"只出现 4 次，"剧本" 44 次，"反转" 15 次——命中率 0.006%—0.2%。
**后果**：π_L 必须用语料**正文**，不能用标题。这条否掉了"抓热搜算标签频率"的整条路线，也解释了为什么这件事需要作者本人去找正文语料（见 `REQUESTS.md`）。

## 3e 第五批：推导与审计（2026-11-15 深夜）

产物：`analysis/DERIVATION.md`、`analysis/figures/seshat_jumps.png`。

**推导链的五步，两步是公设**
```
公设：F = 预测误差 + λc − T·H
推导：K* = N(μ,v)，v = T/(λc'' 的精确式)
公设：G = ∫F dP − E[π_S] + τD_KL        ← 位势博弈假设
推导：∂ₜP = ∇·[P∇(F−π)] + TΔP           ← π 的自变量写错了
选择：三策略 + softmax + 三个无量纲数
公设：E_t, θ_t, π_L, μ_R 各自带方程      ← 不从 F 导出
```

**四处必须修的数学问题**

1. **个体核的精确解不是 `T/(λc'')`**，而是 `λc''v²+(1−T)v−D=0` 的根。差一个 1（高斯归一化），多一项 `D`（信号模糊度）。
   → 新预言：**同一群人在模糊刺激下核更宽**。原公式说核只由人决定，与刺激无关，可直接否证。
2. **`q=1−e^{−τ/φ}` 量纲不成立**（时间是量、φ 是难度）。改为 `q=φ/(φ+τ)`（φ 重定义为"识破所需天数"），得到
   `Π = (βEbh/p)(1+φ/τ)`——套利利润 = 单位收益 × (1 + 识破时间/核实延迟)。
3. **群体层的 `π_S` 写错了自变量**：它是发送端收益，不能对接收端的 K 求梯度。必须引入 `π_R`，两层通过 (σ*,P*) 不动点耦合。
4. **`G` 是位势博弈假设**（隐含零和），而流量套利是正和的。要么明说假设，要么改双层。

**可识别性：比原来想的乐观一点，也更具体**

- 单一情境下 `T` 与 `λc''` 不可分；**改变信号模糊度 D 之后两者可解**（给出闭式）。
- `α`：不可识别（已实测，CI 跨 0—0.8）。
- `δ`：完全没有估计——**E_t 的动力学整个压在它上面，这是最脆弱的一环**。

## 4 第一批读数已经改掉的四个说法

这一节是本轮最有用的产出：**数据不是为了支持理论，是为了先改掉理论里说错的地方。**

**① 中国 TFR：2024 是 1.013，不是 0.97。**
World Bank `SP.DYN.TFRT.IN`：2019 = 1.496，2020 = 1.236，2021 = 1.117，2022 = 1.034，**2023 = 0.999，2024 = 1.013**。
对话里"2025 年约 0.97—1.0、首次跌破 1.0"混了两个口径：跌破 1.0 发生在 **2023**；2024 因龙年小幅回升。
**后果**：`α<1`（加速耗竭）不能用单年序列支撑——至少要看 5 年趋势，且必须写明"2024 回升是生肖效应还是拐点，尚未裁决"。

**② 韩国 2024 是 0.748，不是 0.68。**
0.68 是 2023 的新闻口径（WB：2023 = 0.721）；2024 已回升到 0.748。
**后果**：把 0.68 当"现状"会把"最低"说过头，属于证据强度被高估。

**③ Gallup 28% 可核，可以升到 A−。**
原文标题即 "Trust in Media at New Low of 28% in U.S."，正文有 "at a new low of 28%"。
但同一段的"1970 年代 68%—72%"仍只在新闻稿里，未回到原始表——**这一半保持 B**。

**④ 中国互联网普及率出现口径跳变，暂标 C。**
WB 序列：2022 = 75.6%，2023 = 90.6%，2024 = 92%。
一年跳 15 个百分点不像真实渗透，更像 ITU 口径修订。**在核对元数据之前，不得用它支撑"平台化提速"的论证。**

1. **辟谣时滞 τ**：抓"中国互联网联合辟谣平台 + 腾讯较真"2020—2026 条目，算"事件日 → 核查日"的分布。这是模型里 `τ` 唯一能落地成一条真实分布的变量。
2. **治理通报编码**：CAC"清朗"行动逐条编码（处置量、对象类型、通报措辞），得到 `p` 与 `ρ` 的年度代理。
3. **标签词频**：用可下载新闻语料替代热搜，测 `π_L`。已知限制：`伪人` 在 zh.wikipedia 无条目（实测 404），百科路线走不通。
4. **情绪响应小样本**（n≈200，预注册）：给被试看 6 条具象冲击（真/假各半），测峰高、峰宽、恢复时间。这是 `v` 与 `T` 的唯一直接检验，也是"塔西佗陷阱 ∂e/∂s→0"的唯一可行路径。

**非必需**：微博热搜存档、Gallup/Pew 微观、X API。它们只增加分辨率，不改变可证伪性——**没有它们，模型仍可被检验；有了它们，只是检验得更细。**

## 6 不做的事

- 不为凑样本量去爬平台（违反 ToS，且样本代表性无法论证）。
- 不把新闻稿数字当原始数据（Gallup 那条是范例：标题可核 ≠ 序列可核）。
- 不在体裁未定时先写"数据支持了模型"——本轮四条例子里，三条是在改模型，不是在支持它。
