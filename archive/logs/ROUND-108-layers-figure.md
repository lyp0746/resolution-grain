# 第一百零八轮（2026-11-20）：图 3.3（四层环）＋ 两处“可查痕迹”

## 1 图 3.3：为什么竖排

第一版画成横排：四个盒子一字排开，蓝箭头向右、红箭头向左，标注“上行／下行”。问题很明显——**图上的“右”与文字里的“上”对不上**，读者要在心里做一次旋转。改成竖排（文明在上、个人在下）之后：

- 右侧蓝色向上箭头 = 上行：送参数（涌现）；
- 左侧红色向下箭头 = 下行：改可行集（重置）。

**一句话落在图上**：链与环的差别只有一处——断一条，就没有回头路；没有回头路，就没有迟滞。

**两个技术坑**：
1. `C<sub>Φ</sub>` 在 matplotlib 里被原样画出来（不解析 HTML），改纯文本“分离成本”。
2. `⇒` 在 Microsoft YaHei 里没有字形，显示成 □；改 `→`。**收口时若有“豆腐块”，先查 U+21D2／U+2261 这类数学符号。**

## 2 ch22 §22.7.2：换码的四个痕迹

重训时长／停运天数／旧件清点／既得者组织化。前三项能算、第四项只能判。
- **缺第 ④ 项，只能报 C 的下界**——因为抵制会把 C 推高，而看不见的那部分正是它。
- **四项单位不同（小时／天／件／组织），不许相加成一个“总 C”**；一加，C 就成了作者的态度。

## 3 ch16 §16.7.2：三件套的三处痕迹

定名与执行的间隔／释义的留痕／申诉入口的宽度。
- **第三处最便宜：零受理不是“没人有意见”，是“门是画上去的”。**
- 缺第 ③ 项，只报 <i>H</i>、不报 <i>C</i><sub>Φ</sub>——“分不开”与“分开了但门很窄”在 <i>H</i> 上可以长得一样。
