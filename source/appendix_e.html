附录 E　工具、清单与模板

E.1　两周自观察（只有一个人也能做）

做法：选一件事，你反复觉得“我在这上面很粗”。每次遇到它，记三样：什么时刻、当时还剩多少工夫、当时有多累。不写心情，不写评价。两周后把卡片摊开，按“工夫”与“累”交叉分组。

它能回答：你的粗，主要是时间给的，还是疲劳给的。
它不能回答：你的分辨率是多少（一个人估不出参数）。

它最容易失败的两种方式：记录本身太麻烦（记得太细）；读的时候心里已有结论。两种都要提前防。

E.2　事件台账模板

要算核实延迟，每个事件至少需要四个字段：首次曝光（到日）、首次官方回应（到日）、反转／纠错（到日）、信息来源（链接）。缺“首次曝光日”的，只能算“报道—纠正”的上界，那与真正的延迟差一段“媒体发现的时间”，而这段没有任何公开记录。

E.3　双通道核查表

分析任何“群体会不会合作”的问题时，问五次：

  1. 相遇：这些人以后还会遇到吗？（决定在意程度）
  2. 可见：一个人做错会被看见吗？（决定一致性代价能不能收上来）
  3. 闭合：看见了的人会不会说出来？（决定制裁能否执行）
  4. 工夫：他们有工夫把规则谈清楚吗？
  5. 份额：一个人分摊到的好处有多大？

只有第 5 条与规模直接相关。前四条都是结构，与人数无关：这是“小群体更易合作”这句话为什么只能写成条件命题的原因。

E.4　读任何一份统计前的三问

  1. 算的是哪一批？（含不含养老金、对谁、标题还是正文）
  2. 是存量还是流量？
  3. 两个时点用的是同一个口径吗？

三问答不出来，就可以不谈结论了。

E.5　一条警报

凡看到“恰好一周 / 一月 / 一年”的峰或周期，先怀疑流程，再怀疑机制。本书自己在这上面栽过一次。

E.6　一张纸的入门：化约版

这一节为一种读者写：要读很多理论，但不想把每套理论从头学一遍的人。它做的事只有一个——把这本书压到一张纸上，让下一个人面对任何一套社会科学理论时，有六个可以立刻问的问题。

第一，六个量。任何关于"理解、判断、分类、规则、叙事"的说法，先看它讲的是哪一个：

量它管什么可数的代理
v 分辨率分得多细信号检测论的 d′；泛化核宽度；块数

w 利害错了有多疼只能操纵（后果、署名、追责）

C 换码成本换一套码要付多少没有直接读数（本书欠账）

第二，六个问题。遇到任何一套理论，按顺序问：

  1. 它讲的是哪个量？说不出来，那它多半在讲态度，不在讲机制。
  2. 它的分母是什么？（第 25 章）写不出分母的分歧，可以不必讨论。
  3. 它允许什么反驳？给不出"看到什么它就算错"的，只能当描述。
  4. 它在哪个尺度上说话？个人、群体、社会、文明，四层的式子并不一样（第 4.5 节）。
  5. 它的证据是哪一档？A 官方可复现／B 稳定公开估计／C 稀疏·构造·思辨。C 级的句子只能读成条件句。
  6. 它需要第几条公设？若一句结论要原理二才能讲通，那它比看上去弱一档。

第三，三个陷阱。它们能解释多数学术争论为什么谈不完：

  • 把"读不懂"当成"不严谨"——常常只是进场费（R）高（第 20.3c 节）；
  • 把"争议大"当成"还没谈拢"——它可能是两套码各自稳住了（第 23 章）；
  • 把"更严格"当成"更可信"，抬高标准会抬高所有人的进场成本，反而让小共同体更闭合（第 20.3b 节）。

怎么用。读一篇论文时，用这六问扫一遍，不超过十分钟；读一个学派时，先用第二问把它的分母找出来。若六问里有三问答不上，那篇东西不必读完：不是因为它不好，是因为它还没把自己的位置说清。

这一节不给"新范式"，只给一张网。网的好处是可以兜住不熟悉的东西；坏处是它漏掉的，你永远不知道。所以它必须与第 26 章那张"九处空白"一起读：一张纸负责进门，一张表负责告诉你门里哪几间是空的。

E.7　一个能跑的小程序：估公开表现与私下响应的散度

式子。DKL(P公开‖P私下) ＝ Σc P公开(c)·log[P公开(c)／P私下(c)]，c 是同一套题里的类别；P公开 取公开（实名）条件的响应分布，P私下 取匿名条件（第 13 章那段）。三个条件缺一不可：同一批人、同一套题、两条件只差“会不会被看见”。

最小实现。给定两张计数表（同一类别轴上），先平滑再加 1（否则零概率会把散度打爆），报三个数：散度、它的自助区间、以及平滑前的零格子数——第三个是“这个估计靠不靠得住”的信号。

import numpy as np
def dkl(a, k, alpha=0.5, B=2000, seed=0):
    a, k = np.asarray(a, float), np.asarray(k, float)
    empty = int((a == 0).sum() + (k == 0).sum())
    a, k = a + alpha, k + alpha
    a, k = a / a.sum(), k / k.sum()
    d = float(np.sum(a * np.log(a / k)))
    rng = np.random.default_rng(seed)
    n = (a * 2).astype(int)            # 用平滑后的比例当重抽样参数，仅为给量级
    bs = []
    for _ in range(B):
        ai = rng.dirichlet(a * 50); ki = rng.dirichlet(k * 50)
        bs.append(float(np.sum(ai * np.log(ai / ki))))
    return d, (float(np.percentile(bs, 2.5)), float(np.percentile(bs, 97.5))), empty

一份玩具数据，跑一遍就有数。data/derived/dkl_demo.csv 是同一套六类题在两种条件下的计数（公开 200 次、匿名 200 次；公开那一侧偏向“安全的大类”，匿名那一侧更散）。把它喂进上面那个函数，得到 DKL ≈ 0.22 比特，零格子 0 个——这个数没有实证含义（数据是构造的），它只证明两件事：这个量能算出来，而且能报出“算得靠不靠得住”的那个附注。

四个坑。① 零格子：类别越多、样本越小，零越多；零一多，散度就没意义，先报零格数。② 轴要对齐：两条件必须用同一套类别，否则量的是“分类不同”不是“表现不同”。③ 样本量：每类中位数 ≥5 才勉强；不够就把尾类并掉，并报并了多少。④ 它不告诉你“为什么”：散度大可以是 γ 高（怕被罚），也可以是题目难度不同（选择效应），这两件要用第 11 章那条“只动一样”的操纵分开。

否证线。若同一批人在“实名／匿名”之间随机切换（同一天内、同一套题、切换顺序随机），散度仍显著大于零，那“散度来自 γ”这条要降级——因为它可能是题目本身的随机性。指针：定义在正文第 13 章，读法与两个边界也在那里；这一节只给可跑的形状。
