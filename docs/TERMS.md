# 术语与符号（`front_terms.html` 的源）

> 规则：每个术语**首次定义指章号**；符号表与术语表分开（符号给式子，术语给话）。
> 等级标注：一个术语背后有几条锚点（`ANCHORS.md` 的编号），决定它能被推到多远。

## 二、术语

| 术语 | 定义 | 不要与什么混 |
|---|---|---|
| **粗码 / 细码** | 同一件事的两种理解粒度。粗码省力、失真大；细码相反 | 不要与"抽象/具体"混：抽象是 `μ`（位置），粗细是 `v`（宽度） |
| **支撑宽度** | 一份码覆盖多少种情形 | 不要与"适用范围"混：这是我们自己给的码的属性，不是世界的属性 |
| **档内刻度** | 每个情形内部区分得多细 | 与支撑宽度是同一个预算的两种花法（`δ=Δ/2^R`） |
| **码率预算** | 一个人/一个社会在一件事上愿意花的理解成本总额 | 不要与"注意力"混：注意力是分配，预算是总量 |
| **驻点** | 在失真与成本的交换里，最省钱的那个分辨率 | 不要读成"最优"：它对**环境宽度**是相对的 |
| **标签** | 用一个词替代一段叙述的粗码 | 不要与"概念"混：概念有内涵与外延，标签只求可操作 |
| **分类替代叙事** | 说明"这是什么人"取代说明"发生了什么" | 不要写"标签化"：那是评价，这是机制 |
| **反转** | 首发叙事与后续证据方向相反 | 不要与"纠错"混：纠错是补事实，反转是换方向 |
| **核实延迟 `τ`** | 从首次曝光到纠正 | 不是"调查时长"，是**等待的时长** |
| **程序性反转** | 由司法/行政程序（而非舆论压力）造成的反转 | 与"通告式反转"分开，因为两者的 `τ` 差两个量级 |
| **通告式反转** | 由官方通报造成的反转，通常在数日内 | 同上 |
| **失真未被定价** | 发送端省了自己的力，代价由接收端承担 | 这是外部性，不是道德问题 |
| **可测边界** | 一条结论在什么条件下测不出来 | 每章必须有，不是免责声明 |
| **A/B/C 级** | A 官方可复现 / B 稳定公开估计 / C 稀疏·构造·思辨 | C 级一律写成条件句 |
| **情景句** | "若……那么……"式的表述，用于 C 级 | 不是预测，是标明条件 |
| **口径** | 同一个量的两种定义 | 与"误差"无关：两个口径可能都对 |
| **便利样本** | 因为"有代表性"而被挑出来的样本 | 不能报中位数之外的东西 |
| **快而准** | 只用一条线索却判断得更好的策略 | 我们的框架必须能容纳它，否则框架倒（第 3 章反例） |

## 三、三个容易混的对照

| 对照 | A | B | 差别 |
|---|---|---|---|
| 宽 vs 粗 | 支撑宽（能覆盖多） | 刻度粗（分不清） | 可以同时发生，也可以相反——这正是 §8b |
| 抽象 vs 粗 | `μ` 在高处（谈规则） | `v` 大（分不清细节） | 一个讲**在哪**，一个讲**多细** |
| 懒 vs 偏 | 没核查（省力） | 有立场地扭曲（动机） | Pennycook & Rand 2019 说前者更主要；我们采这个 |

## 四、禁词与替代

| 禁词 | 换什么 |
|---|---|
| 必然 / 注定 / 不可避免 | "在 X 条件下会"／"倾向于" |
| 无法消除 / 死路 | "代价是"／"这条路上要付的是" |
| 人性如此 | 不给这种句子；改成"在 `w` 高、`T` 小的情形下" |
