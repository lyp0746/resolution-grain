**① k 码相图（附录 A.12，新；脚本 `analysis/phase_kcodes.py`）**

**② 临界慢化的数值检查（脚本 `analysis/ewi_check.py`）**
平均场一阶展开：`dm/dt=−κ(m−m*)+σξ`，`κ=[1−βzγ·sech²]/τ₀` ⇒ `AR(1)=e^{−κΔt}`。扫 `βzγ` 从 0.2 到 0.98：`τ` 从 1.25 升到 50，方差从 0.009 升到 0.51，`AR(1)` 从 0.959 升到 0.999；由 `AR(1)` 反解出的 `τ` 与真值吻合（1.19/1.25、2.12/2.0、4.72/5、9.73/10），越近临界偏差越大（71 vs 50）——**这本身就是一条该写进协议的限制**。

**③ L4 的候选闭合（附录 A.13，新；分析文档 `analysis/L4-VOCABULARY.md`）**
不是给“语义”加一门学问，而是换一个提问：**不问“词是什么意思”，问“一套词凭什么留在词汇里”。**
- **用法＝固定点**：`q ∈ Q* ⟺ q 是对它自己造出来的 `μ(q)` 的最优反应`（＝ A.11 的自洽条件提到词汇层）。**维特根斯坦的“意义即用法”在这个式子里就是一个固定点条件**；**私人语言**那一支因此有了式子：一个人的码 `γ=0`，没有谁执行它，外延随时间漂——**这正是第 10 章的“码的折旧”**。
- **规则遵循**：划分不决定外延，**外延由共同体的执行决定** ⇒ **P3 不是心理学补丁，是“一个划分凭什么算规则”的可能性条件**。
- **先验由通道造出来**：提案 → 采纳（`γz>δ`）→ 自洽；`Q_{t+1}={q∈Q_t∪提案: 过门槛且自洽}`。**迭代学习（Kirby–Cornish–Smith 2008）说：瓶颈会自己造出组合结构——先验是通道的稳态，不是一份清单。**
- **语义变化两律可推**：换码收益 ∝ 现码失真 ⇒ 高频词（码更准）变得慢（趋同律）、多义词（歧义大）变得快（创新律）——**两条经验律是一条式子的两个符号**。
- **地缘先验写准**：`Q_可行 = {q : 每一块可观测且至少一块有后果}`——**地理定可行集，不定选择**。
- **判定改写**：L4 以前写“不通（缺语义）”，现在写“**通了形式，没通内容**”：方程／速率律／可行集都有了，缺的是**提案者的私码**（不可观测、无 γ、会折旧）。**残余不是语义学，是私人表征的不可观测性。**

**"反差名人"那组案例在新框架里的位置**（`CASE-FIGURES.md` §5—§7、§10.3）：它们不是人物分析，是**词汇更新的微观基础**——
抢占＝过不了 γ 门槛或不自洽；陈述＝提案已在用法里；**反例型（冯道、李鸿章）＝提案由后来的人提出且成功**（"变的是后世的码"）；
拒绝换码＝个体不采纳，只有被跟随即成提案。**四型对应方程四格。**

### 第三十八轮：ch19 三条线其实是一个比值 + ch15 把"本题无解"改成一条界线

**ch19（4,392 → 4,857）**：三条线并排有个读法陷阱——**它们不在同一侧**。ρ 与 p 在**分母侧**（压低做粗码的收益），κ 在**分子侧**（抬高它）。
于是正确的读法不是"三个指标的涨跌"，是**一个比值的方向**：**粗码的净收益 ∝ κ ÷（ρ·p）**。
这个比值没有单位、只能看方向，但它把三条线锁在一起，并立刻解释两件事：
① **"同时变好"仍然可能更糟**——ρ、p 各涨一成而 κ 涨一倍，比值仍升；
② **为什么技术的跳变是决定性的**——κ 是**乘性**跳变（两三年翻几倍），ρ、p 是**加性**改善（一年几个百分点）。
**一个乘性的量与两个加性的量赛跑，长期只有一个结果——这不是宿命，是算术**；反过来也成立：分母一旦出现乘性改善，赛跑重新开始。
可查形式从三条线变成**一条比值线**（以 2021 为 1），拐点应落在 κ 跳升那一年，且**拐点前后 p 的斜率应几乎不变**。
并顺手回答"为什么不合成一个指数"：合成要权重，**比值不要权重，只要符号**。

**ch15（5,998 → 6,212）**：把"榜与榜之间怎么竞争——本题无解"改成一条**可判界线**：
**长榜卖"给你原料"，短榜卖"替你核过"**；选哪条取决于**用户自己核一遍的成本**——核得便宜长榜占优，核得贵短榜占优。
可查：跨平台比 `K` 与核实成本的代理（搜索、可点开、外链）。**若核实成本下降后用户反而更依赖短榜**，这条就错——那说明短榜卖的是"省心"而非"核过"。
并把它归到第三类缺口：不是缺数据、不是缺概念，是**缺一个测量对象**（核实成本在这个框架里连代理都没有）。

### 第三十七轮：ch23 的"稳定"三件事 + ch15 的榜的交易

**ch23（4,085 → 4,637）**：§23.3 原来只有四小段，现在把"稳定"拆成三件事：

### 第六轮：网络结构入模型（同日，作者定稿）

**① 网络不是新公设**：把 P3 的均场 `q̄` 换成邻居加权 `Σ A_ij D(q_i,q_j)/Σ A_ij`。
均场是全连通特例 ⇒ 这是推广。两条定理：图版仍是势博弈（`Φ=Σ A_ij(γ/2)D`）；**`γ*=δ` 按连通分量成立**
⇒ **"局部共识 + 全局争议"不是矛盾，是同一方程的两个尺度**（解释了叙事距离 0.91—0.98 与苏联 D1）。

**② 六个机制 → 三处落点 + 一个算术项**：`θ`（相遇）、`γ` 的执行成本（监督）、`T`（沟通）、`1/N`（份额）。
**规模只是结构的代理变量**，结论改写为条件命题。

**③ `p_ij` 最小可测化（logit）+ 双通道**：
`p = Λ(ψ_0+ψ_1 d+ψ_2 c+ψ_3 f+ψ_4 dc+ψ_5 fc+ψ_6 X)`；
**相遇 `p^enc` 进 `θ`，监督 `p^san` 进 `γ_eff`，两套系数**。
可判预言：弱关系/大会场景下 **`θ`↑ 而 `γ_eff` 不↑**。

**④ 四处符号冲突已改名**：`γ→a`（网络形成）、`δ→b`（行为更新）、`β→ψ`（logit 系数）、`q→g`（公共品投入）。
**`q` 这一处最要紧**——P2 的"规则＝划分 `q`"不能被占用。

**⑤ 识别红线 G10**：凡报告网络系数必须交代识别策略；做不到只报符号与排序。

**⑥ 联立系统落 A.6（不是 F）**：按附录准入判据，"算得出来"归 A；F 保持缺口清单，只留一句交叉引用。
内容按七小节：设定／均衡定义／存在性（Kakutani）／多重均衡与稳定性／比较静态（`N→d,c,f→p→θ,γ→g`）／

**⑦ 一句硬结论**：同质性选择对小群体**内部**供给有利，对**跨群体**供给可能有害——主文若只写一面，A.6 就是它的反面。
