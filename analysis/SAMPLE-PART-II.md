## 第二部分 导语（样）

一个人有一个人的码。两个人为什么必须共用一套？

不是因为共用更“高级”，是因为**不共用的每一次交接都要付一次翻译费**。翻译费低的时候，各用各的更聪明；翻译费高的时候，共用一套粗码反而更省。第二部分要做的，就是把“翻译费”写成 `γ`、`A`、`z` 三个量，然后回答：谁付这笔钱，什么时候不付更好。

## 第4章　两个人为什么必须共用一套码

<div class="box box-takeaway"><p><b>本章主张。</b>共用一套码不是道德选择，是一笔交易：它用<b>一致性代价</b> `γ` 换<b>交接成本</b> `T`。两个港口要不要共用一套集装箱标准，取决于它们之间的 `A` 有多密、偏离有多可见（`z`）、以及错一次有多疼（`w`）。<b>共用不是善意，是账单；账单落在谁头上，由 `γ` 与 `A` 决定。</b></p></div>

<p class="lead" data-story="1">1956 年 4 月 26 日，纽瓦克港。一台起重机把一只 35 英尺长的铝制箱体吊上“理想 X 号”。码头工人围着看：这不是一只箱子，是一只可以脱离卡车、直接上船的箱子。船长问麦克莱恩：“这东西能省多少？”麦克莱恩说：“装卸费从每吨五块八毛六，降到一毛六。”旁边一个老装卸工没说话。他知道，省下的钱里，有一部分是他的工资。（数字为公开记载的估计值，B/C 级。）</p>

### 4.1　两种装法，一笔装卸费

集装箱之前，货物是“散装”的：一袋咖啡、一桶油、一箱零件，各自搬上搬下。一艘货船在港口停几天，靠的是成百上千个装卸工，一件一件地扛。慢、贵、易损、易丢。

集装箱之后，货装进标准箱：箱体从卡车或火车直接吊上船，到岸再吊下来，装上另一辆卡车或火车。中间不拆箱，只换运输工具。**箱子是同一只，接口是同一套。**

关键是“标准”，不是“箱子”。箱子的尺寸、角件、扭锁、吊点，必须一致；不一致，就吊不上、叠不稳、装不下。标准是这套系统的码。

### 4.2　把两个港口写成两项

设两个港口 `i,j`，各有一套装卸标准 `q_i,q_j`。它们之间的货运密度是 `A_ij`；偏离对方标准的代价是 `γ`；错装的代价是 `w`；港口改造的成本是 `T+λ`。

两个港口的总账：

```
F = w_i D(q_i) + (T_i+λ_i) R(q_i)
  + w_j D(q_j) + (T_j+λ_j) R(q_j)
  + γ · A_ij · d(q_i, q_j)
```

最后一项就是装卸费：两套标准差得越远、货运越密，付得越多。

如果两个港口共用一套 `q`，最后一项变成零，但双方要付一次改造费 `C`：

```
F_shared = w_i D(q) + w_j D(q) + (T_i+λ_i+T_j+λ_j) R(q) + C_i + C_j
```

共用是否划算，比较两式：

```
γ · A_ij · d(q_i,q_j)  >  C_i + C_j
```

左边是“继续各用各的”的装卸费，右边是“共用”的改造费。**当装卸费大于改造费时，共用发生；否则，各用各的更聪明。**

这就是为什么两个不相往来的小港可以各用各的装卸方式，而一条主干航线必须共用一套标准：不是干线更团结，是 `A_ij` 更高。

### 4.3　`γ` 不是道德，是价格

`γ` 是“偏离共享标准要付的钱”。它可以是：

- 货多卸一次；
- 船多停一天；
- 箱子多换一次吊具；
- 账本多记一笔。

`γ` 越高，共用标准越稳；`γ` 越低，各用各的越容易。**但 `γ` 不是越高越好**：太高，少数派被压掉，创新也被压掉；太低，公共标准不存在，每次交接都重新装卸。

集装箱的 `γ` 落在谁头上？一部分落在货主（时间、货损），一部分落在港口（改造、拥堵），一部分落在装卸工（岗位）。**标准不是免费的；它把装卸费从“每次交接”搬到“一次改造”，也把一部分人的饭碗搬走了。**

### 4.4　偏离可见性：`z` 与门槛

`γ` 要起作用，偏离必须被看见。定义执行范围：

```
z_i(q) = Σ_j W_ij · 1{ |q_i − q_j| ≥ d* }
```

`W_ij` 是“`i` 能看见 `j` 的程度”；`d*` 是可分辨阈值：差到几格才算“不一样”。`z_i` 就是“有多少人看得出你偏离”。

门槛是：

```
γ · z_i  >  δ_i
```

左边是“被看见的罚”，右边是“偏离的收益”。**偏离只有在罚大于收益时才会被压回去。**

集装箱的偏离最容易被看见：箱子吊不上船，所有人都得等。`z` 极高，所以 `γ` 不用很大，压力就传到了。相比之下，一条内部规范（比如记账格式）偏离了，只有同事看得见，`z` 低，`γ` 要很高才压得住。

### 4.5　共用码不是最细的码，是最能共用的码

两个港口共用一套标准，不会选最大的箱子，也不会选最小的箱子，而会选**能通过门槛的最粗那套**。

箱子太大，很多港口吊不动、路走不了；箱子太小，装不了多少货、单位成本高。20 英尺与 40 英尺的标准，是折中：它不最优，但它**最能共用**。最优共用码在两者之间：

```
q_shared = argmin_q [ w D(q) + (T+λ) R(q) + C(q) ]
```

这就是“标准”为什么在群体层出现：它不是“最先进”，是**共用得起**。集装箱不是输在技术，是赢在 `A`：当航线越密，`A` 越高，标准的价值越高。

### 4.6　网络：块分解与桥

把港口扩展成一张图 `A`。一致性代价写成：

```
γ · qᵀ L(A) q
```

`L(A)=D−A` 是图拉普拉斯。它给三句话：

1. **若 `A` 有 `k` 个连通分量**，`L` 的零特征值重数是 `k`；分量之间没有一致性压力。于是至少可以同时存在 `k` 套互不施压的码。
2. **桥的容量是 `λ₂(L)`**：它为 0 就是断，很小就是窄桥。没有起重机的港口，就是一座窄桥：箱子到了，吊不下来。
3. **共用不等于连成一片**：把 `λ₂` 抬得太大，会压掉分量内的多样性；最优的桥是稀疏的——用最少的边，把 `λ₂` 抬过门槛。

集装箱化不是“所有港口同时改造”，是主干航线先连成一片，支线港口慢慢被拉进来；拉不进来的，就变成“被绕过的港”。**这不是“标准赢了”，是网络效应把 `γA d` 推过了 `C`。**

### 4.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 共用标准（降 `T`） | 装卸更快 | 港口、船公司（改造费） | 货量太稀，改造费收不回 |
| 港口投资（降 `C`） | 共用更快 | 纳税人、港务局 | 投资停后，支线又掉队 |
| 双套吊具（降 `γ`） | 两边都能接 | 港口（维护两套） | 场地不够时，做不起 |
| 法律统一（改 `Φ`） | 标准扩散 | 旧标准的既得者 | 法律太早，技术被锁死 |
| 劳动力转型（降 `w`） | 阻力变小 | 公共财政、工会 | 转型太慢，岗位先没了 |
| 留出口（降 `γ`） | 不共用也能活 | 留下的人 | 出口太便宜，公共标准不存在 |

### 4.8　反例：不共用有时更好

两个港口不共用，不一定是失败。若 `A_ij` 很低（两条支线不相连），装卸费本来就少；若货物是超大件、散装液体、活体动物，集装箱反而不合适。**“多连接”不是万能药**：如果两港的 `I(q)` 不同，共用标准只会制造“假朋友”——同一只箱子，不同的报关规则，越连越慢。

第23章会展开：两套叙事可以稳定并存，因为分量之间没有一致性压力。那不是“没谈拢”，是 `λ₂=0`。**共用不是目标；共用是当 `γA d > C` 时的一笔交易。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `A_ij` 很高、`γ` 也高的两个港口之间，仍然长期各用各的标准、且没有装卸费上升，那么“共用是交易”这条不成立；共用可能由权力强制，不由成本决定。</div>

### 4.9　本章小结

四句。第一，共用一套码，是用一致性代价 `γ` 换交接成本 `T`；划算与否看 `γA d > C`。第二，`γ` 要起作用，偏离必须被看见；门槛是 `γz>δ`。第三，共用码不是最细的码，是能通过门槛的最粗那套；标准因此出现。第四，网络有分量，`λ₂(L)` 是桥的容量；共用不等于连成一片。

<div class="box box-takeaway"><p><b>一句话带走：</b>共用不是善意，是账单；账单落在谁头上，由 `γ` 与 `A` 决定。</p></div>

<p><b>钩子。</b>两个港口共用一套标准，靠的是装卸费；一群人共用一套码，靠的是谁有资格罚。下一章：标签为什么比叙事便宜。</p>

## 第5章　标签为什么比叙事便宜

<div class="box box-takeaway"><p><b>本章主张。</b>标签不是“想不清楚”的产物，是<b>想清楚了一部分之后的省钱选择</b>。它把码率压到一比特，把交接成本压到一句话，把责任推给“那种人”。它的代价不在贴的人身上，在<b>被贴的人</b>、<b>后来的人</b>与<b>核实的人</b>身上。<b>标签不是不问，是把问题关掉。</b></p></div>

<p class="lead" data-story="1">2026 年，一个插画师把一张手绘过程视频发到平台。两小时后，系统给她打上“疑似 AI 生成”的标签。标签只有一比特，却让三个约稿在同一天取消。她贴出图层、笔刷、录像；平台回复：“以检测结果为准。”她无法举证“我不是 AI”，因为可举证的东西恰好是标签抹掉的那些笔触。</p>

### 5.1　标签是一套一比特的码

标签是码的一种极端：`k=2`。买／不买、懂／不懂、难缠／好说话、我们／他们。

```
R = log₂ 2 = 1 bit
```

一比特的码，记得少、传得快、不用对齐、不必负责。这四项不是道德缺陷，是**成本优势**。第4章说“共用码不是最细的码，是最能共用的码”；标签就是最能共用的那一端。

多档标签是 `k>2` 的同一件事：疑似的、高概率的、确认的。每多一档，`R` 多一比特，`D` 低一点，但 `T` 与 `C` 也上升。`d*` 决定“差到几格才算不一样”：档太少，错分多；档太多，没人分得清。

但一比特的代价是失真 `D` 高：被贴的人落进一格，格内的差别被抹掉。抹掉的那部分不会消失，它只是不再被任何人看见。

### 5.2　四项成本优势

| 省的是什么 | 在式子里 | 可数的痕迹 |
|---|---|---|
| **记得少** | `R` 极低 | 一句话能装几类；复述时的字数 |
| **传得快** | `T` 低 | 转发一条所需的字数 |
| **不用对齐** | `C` 低 | 开场几句能进入正题 |
| **不必负责** | `w` 被转移 | 被追问“你指谁”时的退路 |

第四项最隐蔽：给一个具体判断要担责，给一个标签不必。“我没说他是坏人，我只是说他是那类人。”粗码把责任也一起压缩了。它在式子里有一个不走运的位置：**它把错分的后果从说话者身上挪走，却没有把挪走的后果放到任何别处——它只是让后果变得难以指定。**

### 5.3　标签的账：三层承担者

按本系列的规矩，一处约束要写清谁在付钱。标签的账有三层，而且三层都不是说话的人。

**第一层是被标的人。** 他落进某一格，格内的差别被抹掉。一个人被说成“那种人”，他无法举证“我不是那种人”，因为可以举证的东西恰好是被抹掉的那部分。

**第二层是后来的人。** 标签一旦成了公共词汇，后来的讨论就得在它里面开始。想谈一件不符合这个格的事，第一句话就得先拆掉它——而拆标签本身要花 `T`。所以粗码有一种跨时间的收费方式：**它让下一次对话变贵。**

**第三层是核实的人。** 标签省下的核实，不会消失，它被推到了别处：推到平台、推到机构、推到那些后来不得不去查的人身上。

### 5.4　标签的蕴涵：`I(q)` 的假朋友

标签不只给一个格，它还给一组蕴涵：

```
“只问不买” ⇒ “不用认真接待”
“难缠” ⇒ “不要给他退货”
“不懂” ⇒ “不用跟他解释”
```

这些蕴涵在 `I(q)` 里是合法的，在具体的人身上可能全错。第3章说“同一个 `q`、不同的 `I`，行为分叉”；标签的问题不是 `q` 太粗，是 `I(q)` 被当成了默认。

更麻烦的是：被标的人很难反驳 `I(q)`，因为 `I(q)` 的证据恰好是被标签抹掉的那些细节。**标签不是“信息不足”，是“信息被关掉”。**

### 5.5　标签会自我实现：`w(P,A)` 的回声

标签一旦成为公共码，它会改变被标的人的 `w`：

- 他被打上“难缠”，店员少跟他说话，他于是更急；
- 他被打上“不懂”，没人跟他解释，他于是更听不懂；
- 他被打上“只问不买”，没人认真接待，他于是真的不买。

这不是“他本来就是那样”，是**标签改变了他面对的价格**。用第1章的 `w(P,A)` 读：标签改变 `A`（谁被认真对待），也改变 `w`（错一次的代价），于是行为跟着变。被标“疑似 AI”的插画师，约稿减少，于是转做不露脸的素材；越转越像 AI 的产出，标签就越“准”。**标签不是描述，是定价。**

### 5.6　标签为什么在当代变多：三件事同时发生

标签不是新东西，但它的使用密度在上升。按本书的式子，只有三种可能。

**一、`w` 降了。** 判断错了的代价，在很多场合确实变小了：因为判断的后果不再落到自己身上。转发、围观、评论，都不必承担。

**二、`T` 升了。** 信息变多，而工夫没变。要在同样的时间里处理更多的东西，只能把每件都压得更粗。

**三、传播变便宜了。** 这一项不在式子里，但它改变了一个隐含参数：码能传多远。粗码传得远，所以在一个“传得远就赢”的环境里，它被选择。第三项要特别标出来：**本书的式子是“一个人选一个码”，没有“码与码争夺传播”这一层。** 第三项是一个外挂；承认它，比假装式子里什么都有的好。

三条合起来有一个可查的推论：**如果原因是 `w` 与 `T`，那么标签的使用应当与“是否承担后果”和“可用时间”两项一起变，而不是与人的品性一起变。** 同一个人在需要署名的地方会写得细，在匿名的地方会写得粗。

### 5.7　反例：标签有时比细码更准

标签不是道德错误。急救分诊的“红色”、危险品的“易燃”、代码里的“deprecated”，都是标签；它们比细码更准、更快、更安全。判据不是“标签好不好”，是**错分的代价 `w` 与省下的 `T` 的比值**：

- 当 `w` 低、`T` 高、标签可核实时，标签是最优码；
- 当 `w` 高、标签不可核实、被标的人无法举证时，标签是坏码。

同一个“AI 生成”标签，在谣言视频上是好标签：`w` 高（阻止传播）、标签可核实（有水印/元数据）、被标的是内容不是人。它在原创画师上是坏标签：`w` 高（丢约稿）、标签不可核实（检测器不给证据）、被标的人无法举证（笔触被抹掉）。**区别不在粗细，在 `w` 与可核实性。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `w` 很高、标签不可核实的场景里，标签仍然长期比细码更准、更省，那么“标签的代价在别人身上”这条不成立；标签可能只是被污名化了。</div>

### 5.8　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 压 `R`（用标签） | 记得少、传得快 | 被标的人 | `w` 高时，错分代价爆发 |
| 抬 `T`（信息变多） | 标签更多 | 后来的人 | 有时间核实时，标签退化 |
| 降 `w`（匿名） | 标签更随意 | 第三方 | 需要署名时，标签收缩 |
| 加核实（补 `I`） | 标签更准 | 核实者 | 核实成本高于收益时，没人做 |
| 改 `A`（换圈子） | 标签改写 | 被标的人 | 新圈子仍用旧标签时，改不动 |

### 5.9　本章小结

四句。第一，标签是一比特的码：记得少、传得快、不用对齐、不必负责；这是成本优势，不是道德缺陷。第二，标签的账有三层：被标的人、后来的人、核实的人；三层都不说话。第三，标签给出一组 `I(q)`，它把“信息不足”变成“信息被关掉”；被标的人无法举证。第四，标签有时比细码更准；判据是 `w` 与可核实性，不是粗细。

<div class="box box-takeaway"><p><b>一句话带走：</b>标签不是不问，是把问题关掉；省下的核实，不会消失，只是换了一个人付。</p></div>

<p><b>钩子。</b>标签省下的核实，被推给了别人。那么，谁有资格贴标签？下一章：谁有资格说“你是什么人”。</p>

## 第6章　谁有资格说“你是什么人”

<div class="box box-takeaway"><p><b>本章主张。</b>贴标签不是一次判断，是一次<b>权力动作</b>。它同时做三件事：<b>命名</b>（把什么划进哪一格）、<b>解释</b>（这一格意味着什么）、<b>执行</b>（偏离要付什么）。谁同时握住这三样，谁就有资格说“你是什么人”。<b>`Φ` 不是一个人的属性，是一个位置；它通常不是一个人，是一张三件套。三件套分不分，由分离成本 `C_Φ` 与错误代价、申诉网络一起定。</b></p></div>

<p class="lead" data-story="1">插画师提交了申诉。平台回复得很快：检测置信度 0.87，维持标签。她问：能不能看检测器的证据？不能。能不能人工复核？可以，但复核的也是同一套标准。她问：那谁说了算？对面停了两秒，说：“系统。”她后来把过程视频置顶，评论里有人说：“画得这么像 AI，肯定是 AI。”</p>

### 6.1　三种权力：命名、解释、执行

第5章说标签是一比特的码。这一章要问：**谁有权按下这一比特？**

把旧版的 `Φ` 拆成三件：

```
Φ = ( Φ_name, Φ_interp, Φ_enforce )
```

- `Φ_name`：谁定“这一格叫什么”、谁把什么划进这一格；
- `Φ_interp`：谁定“这一格意味着什么”（`I(q)`）；
- `Φ_enforce`：谁定“偏离要付什么”（`γ`）。

旧版把 `Φ` 写成一个标量，是这三样**重合**时的特例。现实里，三样常常分开：平台命名，政策解释，算法执行；或者社区命名，管理员解释，封禁执行。**分开不等于制衡，重合也不等于独裁；关键是看谁能在哪一段说“不”。**

### 6.2　为什么被标的人争不过

插画师争不过，不是因为她没有道理，是因为三样都不在她手里：

- `Φ_name`：标签由检测器给，不由她给；
- `Φ_interp`：标签意味着“疑似 AI”，解释权在平台；
- `Φ_enforce`：标签影响推荐与约稿，执行权在算法。

她能做的，是贴图层、贴录像、贴笔刷；这些恰好是标签**不采信**的证据。她的 `w` 很高（丢约稿、丢名声），她的 `Φ` 接近零，她的 `A` 很小（没有多少人看得到她的申诉）。**高 `w`、低 `Φ`、低 `A`，就是“争不过”的结构。**

而贴标签的人，`w` 很低：误标一个画师，平台不会赔；误放一个谣言，平台才可能被罚。**误标与误放的代价不对称，标签就会偏向“多标”。** 这不是恶意，是账。

### 6.3　`Φ` 与 `γ`：权力不是罚，是定码

`γ` 是“偏离要付的钱”；`Φ` 是“谁定这个码”。两者不是一回事：

- 有 `γ` 没 `Φ`：罚得动，但名不正；这是暴力，不是权威；
- 有 `Φ` 没 `γ`：名正，但罚不动；这是建议，不是制度；
- `Φ` 与 `γ` 同手：名正且罚得动；这是主权，也可能是垄断。

用第4章的 `γz>δ` 读：`z` 是“多少人看得见你偏离”，`γ` 是“看见之后罚多少”。`Φ` 决定的是：**谁有资格设 `z` 的刻度、谁有资格收 `γ` 的钱。** 所以“谁有资格说‘你是什么人’”不是一句道德追问，是一个结构问题：**三件套在谁手里。**

### 6.4　三种 `Φ`：算法、社区、专业

同一套三件套，可以长成三种样子。三种都要看清：命名、解释、执行分别在哪，争辩从哪里进，代价落在谁头上。

#### 6.4.0 判据：集中度 `H` 与分离成本 `C_Φ`

三种 `Φ` 不是三个类型，是同一个判据的三组取值。先把判据写出来。

**集中度**：每个权力（命名／解释／执行）上的份额 `s_{ki}`，用赫芬达尔指数：

```
H = Σ_k Σ_i s_{ki}²
```

`H` 越接近 1，越集中；越接近 1/3，越分散。

**分离成本** `C_Φ`：把三权分开要付的成本——时间、协调、责任推诿、决策变慢。

**分离条件**：

```
S* = 1   if  C_Φ < w·D_error + A·voice
S* = 0   otherwise
```

- `w·D_error`：错误代价越高，越值得分权；
- `A·voice`：被标的人越能被听见，越值得分权；
- `C_Φ`：分权越贵，越不分。

**三种 `Φ` 就是三组取值**：

| 判据 | 算法 `Φ`（平台） | 社区 `Φ`（维基） | 专业 `Φ`（DSM） |
|---|---|---|---|
| `H` 集中度 | 高 | 中 | 中高 |
| `C_Φ` 分离成本 | 高（要建独立复核） | 中（共识慢） | 高（专业门槛） |
| `w·D_error` 错误代价 | 低（平台误标不赔） | 中（删错有成本） | 高（误诊代价） |
| `A·voice` 申诉网络 | 低（申诉难） | 高（讨论页） | 中（第二意见） |
| `S*` 分权 | **低** | **高** | **中** |
| 观察到的三权 | 合一 | 分开 | 部分分开 |

**这不是事后分类，是事前预测**：抬 `w·D_error`（平台被罚）、抬 `A·voice`（申诉可转发）、降 `C_Φ`（独立复核变便宜），`S*` 就往 1 走；反过来，三权就往一起收。第6章后面三个案例，只是这三组取值的展开。

#### 6.4.1 算法 `Φ`：平台 AI 标签

- **命名**：检测器＋平台政策。`Φ_name` 是一个概率阈值：超过 0.8 就标“疑似”，超过 0.95 就标“确认”。命名者不是人，是一套模型加一条产品规则。
- **解释**：平台把“疑似”翻译成“不值得推荐”“不值得约稿”。这一步没有公开的解释规则；用户看到的是标签，不是理由。
- **执行**：推荐、限流、约稿取消，全是自动的；申诉是人工的，而且复核用的是同一套标准。
- **争辩入口**：理论上可以申诉；实际上要提供“硬证据”，而检测器的特征不公开，硬证据不被采信。
- **代价**：被标的人付名声与收入；平台误标的成本很低，误放的成本才高。**代价不对称，标签就偏向多标。**
- **可争辩性**：低。证据不保留、解释不分离、申诉难改判。
- **典型失效**：对抗性样本、误标、标签游戏（把真作品做得“像 AI”以规避）。

#### 6.4.2 社区 `Φ`：维基百科关注度

- **命名**：删除讨论的参与者。`Φ_name` 不是一个人，是一群人的共识；谁参加、谁有时间，谁就更有发言权。
- **解释**：关注度指引。解释者是社群，不是管理员；指引可以被引用、被争论、被修改。
- **执行**：管理员结案。执行者通常不是命名者；有删除复核，但很慢。
- **争辩入口**：讨论页、来源、保留理由。证据是公开的；被删条目的主角通常不知道讨论存在。
- **代价**：被删除条目的主角付机会成本；编辑付时间；社群付分裂。
- **可争辩性**：中—高。证据保留、解释分离、申诉有效，但慢，而且需要懂规则。
- **典型失效**：删除主义与保留主义的派系；来源偏差；被删者缺席。

#### 6.4.3 专业 `Φ`：DSM 诊断

- **命名**：专业协会的诊断标准委员会。`Φ_name` 是“什么算障碍”的清单，几年改一次。
- **解释**：临床医生。解释需要训练；同一标准在不同医生手里有差异，所以有“第二意见”。
- **执行**：保险、学校、司法。执行者不是命名者，但依赖诊断码；诊断码一变，报销、 accommodations、法律责任都变。
- **争辩入口**：复诊、第二意见、上诉。证据是临床记录；记录由专业人士写，患者很难改写。
- **代价**：被诊断的人付身份与保险；误诊代价高；标签可能改变一个人怎么看待自己。
- **可争辩性**：中。有专业门槛，但比算法更可争辩；比社区更慢、更贵。
- **典型失效**：诊断膨胀、保险驱动、文化偏差。

#### 6.4.4 三种 `Φ` 的对照

| 维度 | 算法 `Φ` | 社区 `Φ` | 专业 `Φ` |
|---|---|---|---|
| 命名者 | 检测器＋平台 | 讨论参与者 | 标准委员会 |
| 解释者 | 平台政策 | 社群指引 | 临床医生 |
| 执行者 | 推荐／限流 | 管理员 | 保险／学校／司法 |
| 争辩入口 | 申诉（难改判） | 讨论页（慢） | 第二意见（贵） |
| 证据 | 不公开 | 公开 | 临床记录 |
| 速度 | 秒级 | 周—月 | 月—年 |
| 代价落在 | 被标的人 | 被删条目的主角 | 被诊断的人 |
| 可争辩性 | 低 | 中—高 | 中 |

三种 `Φ` 的共同点：**被标的人都不在命名席上。** 不同点：算法快而不可争辩，社区慢而可争辩，专业贵而有门槛。三种都能做好事，也都能做坏事；判据不是“谁更善良”，是**可争辩性**。

### 6.5　`Φ` 的网络：谁被听见

`Φ` 不是一个人的属性，是 `A` 上的一个位置。谁的意见能被听见、谁的申诉能被转发、谁的标签能被采信，都是 `A` 的函数。

用第1章的 `w(P,A)` 读：标签改变被标的人的 `w`，也改变他的 `A`——他被限流，连接变少，于是更难被听见；越难被听见，标签越稳。**这是一个闭环：`Φ` 低 → `A` 低 → `w` 高 → 更争不过 → `Φ` 更低。**

要打断这个闭环，不能只靠“讲道理”；要动 `A`（让申诉被看见）、动 `w`（让误标有代价）、动 `Φ`（让命名、解释、执行分开）。**三样动一样，不够；只动一样，另外两样会把它拉回去。**

### 6.6　反例：没有 `Φ`，就没有公共码

`Φ` 不是坏事。没有命名权，就没有公共码；没有解释权，就没有可预期的规则；没有执行权，就没有人守规则。问题不在 `Φ` 存在，在 `Φ` **不可争辩**。

可争辩性有三个条件：

1. **证据保留**：被标的人能拿到硬日志，而不是只拿到一个分数；
2. **解释分离**：命名的人不解释，解释的人不执行；
3. **申诉有效**：申诉能改变结果，不是“维持原判”的仪式。

三条里缺一条，`Φ` 就从“权威”滑向“垄断”。**合法性不是善良，是可争辩。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `Φ` 完全集中、证据不保留、申诉无效的制度里，被标的人仍然能稳定地推翻标签，那么“可争辩性”不是必要条件；`Φ` 可以靠别的东西获得合法性。</div>

### 6.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 分开命名／解释／执行 | 可争辩性上升 | 决策速度 | 三权互相推诿时，没人负责 |
| 保留硬日志 | 申诉有据 | 存储、隐私成本 | 日志本身被改写时，证据失效 |
| 公开检测标准 | 信任上升 | 被对抗性样本钻空子 | 标准太具体，容易被游戏 |
| 独立复核 | 误标下降 | 时间、人力 | 复核者与命名者同源时，形同虚设 |
| 留出口（可离开） | 被标的人有退路 | 留下的人 | 出口太便宜，公共码碎掉 |

### 6.8　本章小结

四句。第一，贴标签是权力动作：命名、解释、执行三件事同时发生。第二，`Φ` 不是标量，是三件套；旧版的 `Φ` 是三件重合的特例。第三，三件套不是分类，是判据：`S*=1` 当 `C_Φ < w·D_error + A·voice`；三种 `Φ` 是三组取值。第四，`Φ` 的必要性不等于 `Φ` 的正当性；正当性看可争辩性：证据保留、解释分离、申诉有效。

<div class="box box-takeaway"><p><b>一句话带走：</b>谁有资格说“你是什么人”？同时握住命名、解释、执行的那双手——或者，那三双被分开的手。</p></div>

<p><b>钩子。</b>标签的权力不只在一个平台；它是一张 `Φ` 的网络。下一章：为什么核实总是追不上。</p>

## 第7章　为什么核实总是追不上

<div class="box box-takeaway"><p><b>本章主张。</b>核实追不上，不是因为真相跑得慢，是因为<b>核实的账不在跑的人身上</b>。核实时滞 `τ_v` 只是分子；分母是注意力的半衰期 `h`。当 `τ_v > h`，纠正追不上原帖，只能追上一批新观众。更麻烦的是：`τ_v` 变短，不等于信任上升；若 `ρ`（可信叙事供给）与 `Φ`（谁有资格纠正）不变，纠正只是又一条标签。</p></div>

<p class="lead" data-story="1">2023 年 5 月 22 日上午，一张“五角大楼附近爆炸”的图在 Twitter 上出现。几分钟内，转发成千；美股短暂下跌；国防部辟谣；图还在。一个事实核查员在下午写道：“我们追的不是图，是看见图的那几百万人。”（公开记录，B 级；核查员这句话是合成引语。）</p>

### 7.1　三个时钟：发现、核实、纠正

核实时滞不是一个数，是三段：

```
τ_v = τ_d + τ_f + τ_c
```

- `τ_d`：发现——从曝光到有人决定去查；
- `τ_f`：核实——查源、比对、找反证；
- `τ_c`：纠正——写出来、发出去、被看见。

三段各有各的瓶颈。`τ_d` 卡在注意力：没人注意到，就没人查；`τ_f` 卡在 `T` 与 `λ`：查证要时间、要力气；`τ_c` 卡在 `ρ` 与 `Φ`：写出来不一定有人看，发出去不一定被采信。

**“核实变快”通常只压缩了 `τ_f`，没有压缩 `τ_d` 与 `τ_c`。** 这就是为什么工具越来越强，体感却越来越追不上。

### 7.2　数据：4.4 天与 7.2 天

书里有一组真读数：PolitiFact 21,063 条核实记录，中位时滞 **4.4 天**；2016 年 7 天 → 2022 年 4 天。滞后分布还有第二个峰，落在 **7.2 天**——那不是“制度层级”，是**工作周**：周末不干活，周一补上。第9章会再讲一次这个坑：看到“恰好一周”的峰，先怀疑排班，再怀疑机制。

另一个读数更冷：核实变快，信任没跟着升。ESS 年均人际信任 2002—2023 年一直在 0.48—0.53。**`τ_v` 下降，不等于“追上”。** 如果“追上”成立，核实端与信任端应当同向动；这里只有核实端动。

所以本章不写“把 `τ_v` 压到零就好了”。本章写：**`τ_v` 只是分子；分母是注意力半衰期 `h`，旁边还站着 `ρ` 与 `Φ`。**

### 7.3　赛跑：`τ_v` 对 `h`

设一条内容的注意力按指数衰减，半衰期为 `h`。当纠正发生在 `τ_v` 之后，原帖观众还剩：

```
F = exp(−τ_v / h)
```

- `τ_v = h`：纠正只能追到约 37% 的原观众；
- `τ_v = 3h`：约 5%；
- `τ_v = 0.3h`：约 74%。

**纠正不是“追上真相”，是“追上还留在原地的人”。** 如果 `τ_v > h`，纠正主要触及的是新观众，不是被原帖说服的人。

**这个指数模型是下界，不是精确值。** 真实注意力常是重尾：少数内容被反复转发，尾部很长。重尾下，`F` 会比 `exp(−τ_v/h)` 高；所以这条公式给的是“至少还能追到多少人”，不是“一定只有这么多”。真实数据要报生存函数，不只报均值；否则会把“长尾还在”误读成“追上了”。

这给一条可判决的预言：**在 `h` 短的平台，`τ_v` 的边际收益很低；在 `h` 长的平台，`τ_v` 的边际收益高。** 同一个核查，发在短视频平台与发在长文平台，效果不该一样。

### 7.4　`ρ` 与 `p`：纠正不是唯一供给

`τ_v` 短，还要有东西可看。`ρ` 是可信叙事的供给：如果只有“这是假的”，没有“那是什么”，纠正只是拆，不是建。`p` 是惩罚概率：如果造谣被罚的概率很低，套利净收益

```
Π = B(1 − d) − c
```

就可能是正的。`B` 是收益，`d` 是检测概率，`c` 是成本。`Π>0` 时，假叙事会继续生产；`τ_v` 再短，也只是追着跑。

**这就是“核实追不上”的第二个原因：不是跑得慢，是对手一直在起跑。** 只要 `Π>0`，你压短 `τ_v`，对手就提高伪装精度；这是赛跑，不是终点。

### 7.5　`Φ`：谁有资格纠正

第6章说，标签是命名、解释、执行三件套。纠正也是。

- 核查员有 `Φ_interp`：她能说“这是假的”；
- 平台有 `Φ_enforce`：它能决定这条纠正推不推；
- 观众有 `A`：他们决定转不转。

如果 `Φ` 集中在平台，核查员的纠正只是“又一条内容”；平台不推，它就沉下去。**纠正不是“说出真相”就完了，它要过 `Φ` 的三道门。** 这也是为什么“核实变快、信任没升”：`τ_v` 动了，`Φ` 没动。

### 7.6　反例：短 `τ_v` 不总是好

核实不是越快越好。有些纠正需要时间：等第二批证据、等当事人回应、等语境补齐。太快，会把“还没查清”写成“已经查清”，制造新的错误。

书里区分过两种延迟：**给纠正用的延迟是资产；给套利用的延迟是负债。** 同样是 4 天，对核查员是查证时间，对套利者是窗口。**资产与负债的分界不在时长，在谁用这段时间：核查员用 4 天查源，是资产；套利者用 4 天做伪装，是负债。同一条 `τ_v`，两种账。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `h` 很短的平台上，`τ_v` 大幅下降而纠正到达率不变，那么 `τ_v/h` 不是主因；主因可能是 `ρ` 或 `Φ`。</div>

### 7.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 压 `τ_f`（更多核查员） | 核实更快 | 核查机构、捐款人 | `τ_d` 与 `τ_c` 没动时，边际收益低 |
| 压 `τ_d`（监测） | 更早发现 | 平台、监测者 | 误报太多时，信誉下降 |
| 抬 `ρ`（给替代叙事） | 纠正更可建 | 记者、专家 | 替代叙事本身不可信时，白费 |
| 抬 `p`（惩罚） | 套利减少 | 被罚者、执法者 | 取证太难时，罚不到 |
| 改 `Φ`（分开命名／解释／执行） | 纠正更可争辩 | 平台、机构 | 三权互相推诿时，更慢 |
| 加平台摩擦 | 传播变慢 | 普通用户 | 摩擦太高时，正常内容也死 |

### 7.8　本章小结

四句。第一，核实时滞是三段：发现、核实、纠正；工具通常只压中间那段。第二，`τ_v` 只是分子；分母是注意力半衰期 `h`；`τ_v>h` 时，纠正追不上原帖。第三，`ρ` 与 `p` 决定“有没有替代叙事”和“对手是否继续生产”；只压 `τ_v` 是追尾巴。第四，纠正要过 `Φ` 的三道门；`τ_v` 变短、`Φ` 不变，信任不会升。

<div class="box box-takeaway"><p><b>一句话带走：</b>核实追不上，不是因为真相跑得慢，是因为账不在跑的人身上。</p></div>

<p><b>钩子。</b>核实要花钱，纠正要过门；这笔钱谁出？下一章：谁在为核实付钱。</p>

## 第8章　谁在为核实付钱

<div class="box box-takeaway"><p><b>本章主张。</b>核实是<b>公共品</b>：好处散给所有人，成本落在少数人头上。于是它天然供给不足。核实的账有六张：核查员的时间、平台的审核、被指方的应对、观众的注意力、市场的波动、被误标的人。<b>谁付账，决定核实长什么样；`ν` 决定谁把别人的疼算进自己的账，`Φ` 决定谁有资格拿这份功劳。</b></p></div>

<p class="lead" data-story="1">五角大楼那张假图出来那天，账单是这样的：核查员花了四小时查源；平台审核队列多了一条；国防部新闻办发了一句辟谣；美股跌了一下又回来；几百万观众看见了一张不存在的爆炸。没有人开一张发票，但每一笔都有人付。</p>

### 8.1　核实是公共品

核实有两个特征：

- **非排他**：一个人知道“这是假的”，不妨碍别人也知道；
- **非竞争**：多一个人看见纠正，不会让纠正变少。

公共品的私人供给，通常不足。设核实的公共收益是 `B`，私人成本是 `C`：

```
V_private = ν·B − C
```

`ν` 是“别人的收益有多少进了我的账”。如果 `ν` 很小，`V_private<0`，私人不干；如果 `ν` 很大，私人才干。**核实供给不足，不是人懒，是 `ν` 小。**

这就是为什么核查机构大多靠捐款、基金会、平台补贴：它们在做一件 `ν` 被外部强行抬高的事。

### 8.2　六张账单

| 付账者 | 付什么 | 可数痕迹 | 在式子里 |
|---|---|---|---|
| **核查员** | 时间、力气、被骂的风险 | 一条核查 4 小时；一周几条 | `T`、`λ`、`w` |
| **平台** | 审核队列、误删申诉 | 人工审核分钟数；误删率 | `C`、`γ` |
| **被指方** | 应对、声誉 | 声明条数；股价/订单 | `w`、`ν` |
| **观众** | 注意力、被误导 | 停留时长；转发链 | `D`、`A` |
| **市场** | 短暂波动 | 分钟级涨跌 | `D`、`τ_v` |
| **被误标的人** | 名声、申诉时间、机会 | 申诉条数；删帖/恢复时长 | `w`、`Φ` |

六张账单里，最容易看见的是核查员的时间；最不容易看见的是观众被误导的 `D` 与被误标的人的机会。**账之所以难算，是因为最大的一笔写在没说话的人身上。**

### 8.3　`ν` 与 `Φ`：谁 internalize，谁拿功劳

`ν` 决定“别人的疼有多少进我的账”。核查员的 `ν` 高，所以她会花四小时查一张图；平台的 `ν` 低，所以它更愿意加一个便宜标签；被指方的 `ν` 高（因为疼在自己身上），所以它会发声明。

`Φ` 决定“谁有资格拿这份功劳”。核查员有 `Φ_interp`，平台有 `Φ_enforce`，观众有 `A`。如果 `Φ` 集中在平台，核查员做完四小时，功劳与流量归平台；下一次，她可能就不做了。**核实的供给，不只取决于 `ν`，还取决于 `Φ` 是否把功劳还给做事的人。**

### 8.4　核实的三角：从生产技术推出来

“快、便宜、可信，最多两个”不是假设，是三个生产函数的形状。

设核查投入为 `e`，独立度为 `s`（0—1，1 表示完全独立于被标者）：

```
a(e,s) = 1 − exp(−η e s)      准确率
τ_v(e) = τ₀ + κ / e            延迟
C(e,s) = c₀ + c₁ e + c₂ s      成本
```

- `a` 随 `e`、`s` 上升，但边际递减；
- `τ_v` 随 `e` 下降，但降不到零；
- `C` 随 `e`、`s` 线性上升。

**三角就是这三个函数的帕累托前沿**：给定预算，最大化 `a`，同时满足 `τ_v ≤ τ_max`。前沿上的三个角，是三个极端解：

| 角 | 投入 `e` | 独立 `s` | 准确率 `a` | 延迟 `τ_v` | 成本 `C` | 典型形态 |
|---|---|---|---|---|---|---|
| 快＋便宜 | 低 | 低 | 低 | 小 | 低 | 算法标签 |
| 快＋可信 | 高 | 高 | 高 | 中 | 高 | 新闻室核查 |
| 便宜＋可信 | 低 | 高 | 中 | 大 | 中 | 社区审议 |

这不是道德选择，是成本结构。平台 AI 标签选“快＋便宜”，所以它不可争辩；新闻室选“快＋可信”，所以它贵；维基百科选“便宜＋可信”，所以它慢。**三种 `Φ`，对应前沿上的三个极端解。**

**三条可判决的预言**：

1. 提高独立度 `s`，准确率上升，但成本上升；若成本不升，说明 `s` 没真独立。
2. 提高投入 `e`，延迟下降，边际弹性约为 −1（`κ/e`）；到一定程度，加人也不快。
3. 若 `s` 很低，加 `e` 对 `a` 的提升有限；先把 `s` 抬起来，再加人，才有效。

### 8.5　账本闭合：谁付、谁收

六张账单只写了“谁付”，没写“谁收”。这不是完整的账。完整的账要闭合：

```
Σ_i payment_i = Σ_j receipt_j
```

把每一笔成本写成“付方 → 收方”：

| 付方 | 收方 | 币种 | 例子 |
|---|---|---|---|
| 核查员 | 观众 | 时间 → 纠正 | 四小时查源，换来一条可读的核查 |
| 平台 | 用户 | 审核成本 → 较干净的信息流 | 审核队列、误删申诉 |
| 被指方 | 公众 | 声明成本 → 信息 | 国防部辟谣 |
| 市场 | 交易者 | 波动 → 损益 | 假图引发的短暂下跌 |
| 被误标的人 | 平台／观众 | 申诉时间 → 标签修正 | 画师贴图层、录像 |
| 观众 | 平台 | 注意力 → 广告收入 | 看纠正，也看原帖 |

**每一笔都要有对手方。** 没有收方，成本只是修辞；有了收方，才能说“动这个杠杆，谁补谁”。比如“平台付费给核查员”，不是平台“做善事”，是平台用钱买走核查员的时间，再把较干净的信息流卖给用户；账要这么记，才知道谁真正承担。

**账本闭合不是一般均衡。** 它不要求价格调整、不要求市场清算；它只要求每一笔转移有一个对手方。这是“谁付账”从道德判断变成会计的第一步。

### 8.6　为什么市场供给不足

核实的收益是公共的，成本是私人的；假消息的收益是私人的，成本是公共的。两边不对称：

- 真：`V_private = νB − C`，`ν` 小，供给不足；
- 假：`Π = B(1−d) − c`，`d` 低，供给过剩。

所以不是“真相跑得慢”，是**两边的账本不一样**。你把 `τ_v` 压短，真的一侧成本上升；假的一侧只要 `Π>0`，就继续生产。**核实要追上，不能只压 `τ_v`，还要动 `ν`、`p`、`Φ`。**

### 8.7　反例：核实也会过度

核实不是越多越好。三种过度：

1. **重复核查**：同一 claim 十家机构各做一遍，边际收益低，账单高；这是 `Φ` 争功劳，不是 `ν` 高。
2. **表演性核查**：平台加一个标签，表示“我们在行动”；标签便宜，核实没做；这是 `w` 低。
3. **过度谨慎**：为了不错，什么都不说；观众得不到替代叙事，`ρ` 下降。

判据是边际：**多一次核实的边际收益，是否大于边际成本。** 公共品的边际收益散给所有人，私人供给会停得太早；公共补贴可能停得太晚。**最优不是“最多”，是“边际相等”。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `ν` 很低、`Φ` 很集中的场景里，核实仍然供给充足，那么“公共品”解释不成立；核实可能由职业规范或法律强制驱动。</div>

### 8.8　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 公共基金（抬 `ν`） | 核实供给上升 | 纳税人／捐款人 | 资金不稳定时，机构先砍核查 |
| 平台付费（改 `Φ`） | 核查员有回报 | 平台、用户 | 平台只买“快＋便宜”时，质量降 |
| 责任规则（抬 `p`） | 假消息成本上升 | 造谣者、平台 | 取证太难时，罚不到 |
| 公开日志（降 `T`） | 核实更快 | 平台、被指方 | 日志被改写时，证据失效 |
| 分权（拆 `Φ`） | 可争辩性上升 | 决策速度 | 三权推诿时，更慢 |
| 预 bunking（抬 `ρ`） | 纠正更早 | 教育者、媒体 | 预 bunking 本身不可信时，白费 |

### 8.9　本章小结

四句。第一，核实是公共品：收益散、成本集中，`ν` 小就供给不足。第二，核实的账有六张，最大的一笔写在没说话的人身上；每笔都要有对手方，账才闭合。第三，核实三角不是假设，是 `a(e,s)`、`τ_v(e)`、`C(e,s)` 的帕累托前沿；三种 `Φ` 对应三个极端解。第四，核实也会过度；最优不是最多，是边际相等。

<div class="box box-takeaway"><p><b>一句话带走：</b>核实追不上，不是因为没人看见真相，是因为看见真相的账，没人愿意付。</p></div>

<p><b>钩子。</b>核实有账，标签有价；下一章：为什么有些标签越用越准，有些越用越偏——维护。</p>

## 第9章　为什么有些标签越用越准，有些越用越偏

<div class="box box-takeaway"><p><b>本章主张。</b>标签的准确性不是天生的，是<b>维护出来的</b>。它取决于四个量：核查投入 `e`、被标者的博弈 `g`、标签者的俘获 `c`、以及标签者自己承担的错误代价 `w`。用一个简单的漂移方程：<b>`a* = ηe / (ηe + g + c)`</b>。投入高、博弈低、俘获低，标签越用越准；反过来，越用越偏。</p></div>

<p class="lead" data-story="1">2008 年，评级机构的分析师给一份由次级抵押贷款支持的 CDO 盖上 AAA。发行人付钱，监管者采信，投资者买单。同年，米其林的检查员匿名走进一家餐厅，自己付账，吃完写报告；餐厅不能付钱买星。两个标签，都是一比特；一个越用越偏，一个越用越准。差别不在标签本身，在<b>谁维护它、谁为它付账、谁承担它错的代价</b>。</p>

### 9.1　标签会漂移：三种机制

标签不是刻在石头上的。它会漂移，常见三种机制：

1. **Goodhart**：一旦标签变成目标，行为就转向“符合标签”，而不是“符合质量”。餐厅为星做菜，学校为排名刷指标，银行为评级打包资产。
2. **自我实现**：标签改变 `w` 与 `A`，被标者于是真的变成标签说的样子。第5章的插画师被标“疑似 AI”，约稿减少，转做不露脸素材，越转越像 AI。
3. **俘获**：标签者靠被标者付钱，或者依赖被标者提供信息；`Φ` 被俘获，标签偏向被标者。评级机构的“发行人付费”是经典案例。

三种机制不是道德问题，是**维护结构**问题。标签的准确性，取决于维护结构是否让“说真话”比“说好话”更划算。

### 9.2　一个漂移方程

设 `a` 是标签的准确率（标签与真实质量一致的概率）。每个周期：

- 标签者投入核查 `e`，以效率 `η` 提升准确率；
- 被标者博弈 `g`，让标签失真；
- 标签者被俘获 `c`，让标签偏向被标者。

写成最简单的漂移方程：

```
ȧ = η e (1 − a) − (g + c) a
```

稳态：

```
a* = ηe / (ηe + g + c)
```

**这是方向模型，不是精确预测。** `a*` 是稳态，不是每一条标签的准确率；参数没有标定，只能比方向：抬 `e`、压 `g`、压 `c`，`a*` 往哪边走。真实系统里 `e` 也会边际递减，`g` 会随标签价值上升；这条式子给的是骨架，不是数值。

读法很直：

- `e` 高、`g+c` 低 → `a*` 接近 1，越用越准；
- `e` 低、`g+c` 高 → `a*` 接近 0，越用越偏；
- `g` 随标签价值上升：标签越有用，越有人博弈；
- `c` 随付费结构上升：谁付钱，标签就偏向谁。

**这条方程不是精确预测，是方向：想让标签变准，要么抬 `e`，要么压 `g` 与 `c`。** 三样都不动，只换标签的措辞，不会变准。

### 9.3　维护的四个条件

| 条件 | 含义 | 米其林 | 评级机构 | 平台 AI 标签 |
|---|---|---|---|---|
| **独立性** | 标签者不被被标者付钱 | 高（餐厅不付） | 低（发行人付） | 中（平台付，但平台也被流量驱动） |
| **可核实性** | 证据保留，可复核 | 高（匿名复访） | 中（模型与记录不公开） | 低（检测器不公开） |
| **竞争** | 多家标签者，可退出 | 中（ guides 竞争） | 低（三大机构） | 低（平台各自为政） |
| **错误代价** | 标签者承担错的成本 | 高（声誉） | 低（投资者承担） | 低（被标的人承担） |

四个条件里，**独立性**与**错误代价**最关键。评级机构不是不聪明，是它说错的代价不由它付；米其林不是更善良，是它说错的代价由自己的声誉付。**标签的准确性，跟着代价走。**

### 9.4　标签的生命周期

一个标签通常走五段：

1. **出生**：便宜、粗、有用；`e` 低，`g` 低，`c` 低，`a*` 中；
2. **成长**：大家开始信；`e` 上升，`a*` 上升；
3. **俘获**：被标者发现标签值钱，开始付钱、游说、博弈；`c`、`g` 上升；
4. **衰减**：`a*` 下降，但大家还在用，因为换标签要付 `C`；
5. **崩塌**：一次事件让标签失信；`Φ` 转移，新标签出现。

2008 年的 AAA 是“成长—俘获—崩塌”的完整样本；米其林是“成长—维护”的长样本；平台 AI 标签还在“成长—俘获”之间。**标签的年龄不决定准确性，维护结构决定。**

### 9.5　反例：标签也会变准

标签不是注定漂移。开源基准、同行评议、米其林，都有长期维护得较准的例子。条件是：`e` 持续投入、`g` 被随机复核压住、`c` 被独立付费结构切断。

所以“标签越用越偏”不是铁律，是**当 `g+c` 超过 `ηe` 时的趋势**。判据不是“标签用了多久”，是**维护方程的三个量**。

还要分清两件事：**独立付费只降 `c`，不降 `g`**；被标者仍会博弈，博弈要靠随机复核。反过来，**随机复核只降 `g`，不降 `c`**；标签者仍可能被付费结构俘获，俘获要靠独立付费。两样都要，缺一样，另一条会把它拉回去。

<div class="note"><b>这条能被怎么打掉：</b>若在 `c` 很高（被标者付费）、`e` 很低（不核查）的制度里，标签仍然长期准确，那么“维护结构决定准确性”这条不成立；准确性可能由竞争或外部审计单独撑住。</div>

### 9.6　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 独立付费（降 `c`） | 标签更准 | 用户／公共基金 | 付费方也被俘获时，白费 |
| 随机复核（降 `g`） | 博弈减少 | 标签者 | 复核太贵时，做不起 |
| 公开证据（升可核实性） | 申诉有据 | 标签者、被标者 | 证据被改写时，失效 |
| 多家标签（升竞争） | 准确性上升 | 被标者（多头认证） | 标准不一时，用户更晕 |
| 错误责任（升 `w`） | 标签者更谨慎 | 标签者 | 责任太重时，没人敢标 |
| 轮换检查员 | 降俘获 | 机构 | 轮换太频时，经验流失 |

### 9.7　本章小结

四句。第一，标签会漂移：Goodhart、自我实现、俘获。第二，漂移方程 `a*=ηe/(ηe+g+c)`：投入高、博弈低、俘获低，越用越准。第三，维护的四个条件：独立性、可核实性、竞争、错误代价；最关键的是后两个。第四，标签的年龄不决定准确性，维护结构决定；标签也会变准，只要 `ηe` 压过 `g+c`。

<div class="box box-takeaway"><p><b>一句话带走：</b>标签不是刻在石头上的；它跟着代价走——谁为错付账，它就偏向谁。</p></div>

<p><b>钩子。</b>标签会漂移，也会校准；但校准要付一次成本。下一章：改码的代价——为什么旧标签撤不掉。</p>

## 第10章　改码的代价——为什么旧标签撤不掉

<div class="box box-takeaway"><p><b>本章主张。</b>旧标签撤不掉，不是因为人固执，是因为<b>换码要付一次成本 `C`</b>；换回去还要再付一次，所以带宽是 `2C`。`C` 不只是钱：它是轨道、机车、培训、协调、身份。谁付 `C`，谁就反对换码；收益散给所有人，成本落在少数人头上。<b>改码难，不是因为道理不够，是因为账不对。</b></p></div>

<p class="lead" data-story="1">1892 年 5 月，最后一列宽轨火车从帕丁顿开出。站台上有人拍照，有人拾起一小段宽轨的钢轨。一个工人问工头：“既然宽轨更稳，为什么全拆了？”工头说：“因为回不去了。再铺回去，要再花一次钱。”那一年，距离《轨距法》已经过去四十六年。</p>

### 10.1　换码的成本不是钱

`C` 是换一次码的成本。它至少有五层：

- **硬件**：轨道、机车、站台、信号；
- **软件**：表格、流程、代码、标准；
- **学习**：培训、练习、犯错；
- **协调**：所有人同时换，不然接口对不上；
- **身份**：换了码，等于承认旧码错了；对一些人，这是面子，也是权力。

1846 年的《轨距法》只改了“新铁路不许铺宽轨”，没有一夜之间拆掉宽轨。宽轨又活了四十六年，因为 `C` 太大：不是一条法律能付的，是一代人的改造费。

### 10.2　带宽 `2C`：进去难，出来更难

设旧码 `q₀`、新码 `q₁`，收益差 `ΔF = F(q₁) − F(q₀)`。换码的条件是：

```
ΔF > C
```

换过去之后，想换回来，要再付一次 `C`：

```
−ΔF > C   ⇔   ΔF < −C
```

所以稳定区间是：

```
−C ≤ ΔF ≤ C
```

两个阈值之间就是**带宽**，宽度 `2C`。在这个带里，旧码和新码都稳；历史决定你在哪一边。**这就是迟滞：不是“最优”，是“路径”。**

### 10.3　非对易：先改价格，还是先改码

`U_w` 改价格（法律、补贴、税率），`U_q` 改码（轨道、流程、标准）。两个更新一般不对易：

```
[U_w, U_q] = U_w U_q − U_q U_w ≠ 0
```

1846 年的顺序是：先用《轨距法》改 `w`（新铁路铺宽轨的成本上升），再让市场慢慢改 `q`（轨道与机车更新）。如果反过来，先拆轨道再立法，改造费没人付，宽轨会拖得更久。

**顺序不是细节，是结果。** 同一条政策，先动价格还是先动码，落在不同的稳定点；环面积就是“谁先动”的痕迹。

### 10.4　为什么旧标签撤不掉

标签也是码。旧标签撤不掉，原因相同：

- `C` 落在换标签的人身上：被标的人要自证、机构要重新培训、平台要改模型；
- 收益散给所有人：少一个误标，大家受益，但没人愿意为它付 `C`；
- `Φ` 集中在贴标签的人手里：他们有权力贴，没有动力撤；
- `γ` 让旧标签自我维持：大家都用，你不用，你就“不合群”。

所以旧标签不是“被相信”，是“被维持”。它可能早就错了，但撤掉它要付 `C`；只要 `ΔF` 没有大到超过 `C`，它就会继续挂着。**标签的寿命，不等于标签的准确性；它等于 `C` 除以 `ΔF`。**

### 10.5　三个真实案例

| 案例 | `C` 是什么 | `2C` 体现在哪 | 结果 |
|---|---|---|---|
| **英国轨距** | 轨道、机车、站台、培训 | 宽轨拆了再铺回，要再付一次 | 1846 立法，1892 才换完 |
| **QWERTY 键盘** | 打字员训练、键盘产线 | 换回 Dvorak 要再训练一次 | 锁在 QWERTY；Dvorak 被宣称更快，但证据有争议 |
| **公制化** | 标牌、量具、教育、习惯 | 换回英制要再改一次 | 多数国家换完；美国停在“双轨” |

三个案例的共同点：`C` 不是“钱”一项，是五层成本叠在一起；`2C` 不是“再花一次钱”，是“再经历一次协调与身份”。**改码不是一次选择，是一段路径。**

### 10.6　反例：`C` 小的时候，换码很快

不是所有码都难换。软件更新、A/B 测试、临时流程，`C` 很小，换码可以在一天内完成。判据不是“旧码好不好”，是 `C` 与 `ΔF` 的比值：

- `C` 小、`ΔF` 大 → 快速换码；
- `C` 大、`ΔF` 小 → 锁死；
- `C` 大、`ΔF` 也大 → 危机驱动，一次换很多。

**“改革难”不是普适定律，是 `C` 大的时候的样子。** 把 `C` 降下来（补贴、分阶段、双轨），换码就会发生；把 `C` 抬上去（责任、身份、协调），换码就会停。

<div class="note"><b>这条能被怎么打掉：</b>若在 `C` 很大、`ΔF` 很小的场景里，旧码仍然被迅速替换，那么“带宽 `2C`”不是主因；替换可能由权力强制或外部危机驱动。</div>

### 10.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 补贴改造（降 `C`） | 换码更快 | 纳税人／平台 | 补贴停后，旧码回潮 |
| 分阶段（摊薄 `C`） | 过渡更稳 | 早期采用者 | 阶段太长，接口长期不统一 |
| 双轨并行（降 `γ`） | 两边都能活 | 维护两套的人 | 成本太高时，双轨变成永久拖延 |
| 法律统一（改 `Φ`） | 标准扩散 | 旧标准的既得者 | 法律太早，技术被锁死 |
| 培训（降学习成本） | 换码更容易 | 组织／个人 | 培训完没有配套，白学 |
| 留出口（降 `γ`） | 不换也能活 | 留下的人 | 出口太便宜，公共码不存在 |

### 10.8　本章小结

四句。第一，换码要付一次 `C`；换回去再付一次，所以带宽 `2C`。第二，`C` 不只是钱，是硬件、软件、学习、协调、身份五层。第三，旧标签撤不掉，不是被相信，是被维持；寿命等于 `C` 除以 `ΔF`。第四，改码难不是普适定律；`C` 小的时候，换码很快。

<div class="box box-takeaway"><p><b>一句话带走：</b>旧标签不是刻在石头上的，是钉在账单上的；谁付得起 `2C`，谁才改得动。</p></div>

<p><b>钩子。</b>改码的代价可以算；但有些改码，一旦发生，就回不去。下一章：临界——为什么有些变化不可逆。</p>

## 第11章　临界——为什么有些变化不可逆

<div class="box box-takeaway"><p><b>本章主张。</b>临界不是“变化很大”，是<b>稳定态的数量或位置变了</b>：原来只有一个高态，现在多了一个低态；或者高态消失了。它有三个标记：序参量跳变、临界慢化、迟滞。三者不必同时亮；但只要<b>迟滞</b>在，旧码就回不去——因为回去要再付一次 `C`。</p></div>

<p class="lead" data-story="1">1992 年 7 月，纽芬兰 Petty Harbour。一个渔民把最后一网鳕鱼拖上船，鱼不大，数量也不多。几天后，加拿大政府宣布暂停北方鳕鱼捕捞。三万人失业，整个海岸的船队停在码头。科学家说，鱼还会回来；二十年后，鱼还没回来。（历史重建，B 级。）</p>

### 11.1　临界不是“大变”，是“多了一个稳定态”

一个系统可以有很多状态，但只有少数是**稳定**的：推一下，会回来。临界发生的时候，稳定态的数量或位置变了：

- 原来只有一个高态，现在多了一个低态；
- 或者高态消失了，系统只能落到低态；
- 或者两个态之间的墙变矮了，推一下就能过去。

用势函数写：

```
V(x; q) = x⁴/4 − a(q)·x²/2 − b(q)·x
```

`x` 是资源存量（比如鳕鱼），`q` 是管理码（配额、禁渔期、准入）。`a(q)` 决定高态有多深，`b(q)` 决定往哪边推。当 `a(q)` 降到某个阈值，高态消失，系统落到低态——这就是**鞍结分岔**。

**临界不是“鱼变少了”，是“鱼少到回不来了”。** 前者是量变，后者是稳定态变了。

### 11.2　三个标记：跳变、慢化、迟滞

书里给了三个可观测标记：

1. **序参量跳变**：鱼量、股价、信任，在某个点附近突然换档；
2. **临界慢化**：靠近临界点时，系统从扰动中恢复得越来越慢；
3. **迟滞**：过去之后，条件恢复，系统不跟着恢复；要回到高态，得推得比来时更远。

三个标记不必同时亮。鳕鱼的教训是：**早期预警可能又弱又晚**。科学家在 1980 年代末就警告过配额太高；但警告是分散的、嘈杂的，决策者听到的是“还可以再一年”。等三个标记都亮了，鱼已经回不来了。

### 11.3　迟滞：回去要再付一次 `C`

设高态 `x_H`、低态 `x_L`。从高态到低态，要跨过势垒；从低态回高态，也要跨过势垒。两边的势垒不一样：

```
ΔV(H→L) = C₁,   ΔV(L→H) = C₂,   C₂ > C₁
```

所以稳定区间是 `−C₁ ≤ ΔF ≤ C₂`。带宽不是对称的：**破坏比修复便宜**。这就是为什么“禁渔”能在一夜之间宣布，“鱼回来”要等几十年。

`C` 不只是钱：是船队、码头、社区、身份。禁渔令下了，船还在，人还在，但收入没了；要恢复，不只等鱼，还要等市场和社区。

### 11.4　谁付账：鱼没有 `Φ`

鳕鱼崩溃的账单，落在：

- **渔民**：失业、转行、债务；
- **社区**：学校关闭、人口外流、身份消失；
- **纳税人**：补贴、救助、重建；
- **未来的人**：一个回不来的生态；
- **鱼**：没有 `Φ`，没有发言权。

决策者的 `w` 很低：配额高一点，今年的就业好看；鱼少了，疼在明年、在后代、在别人身上。`ν` 把成本推给了未来。**临界不是天灾，是一张跨期账单；签单的人不在场，付账的人还没出生。**

### 11.5　为什么管理码没有及时换

用第4章的 `γA d > C` 读：

- `γ`：限渔的短期代价（失业、抗议）；
- `A`：渔业社区的网络密度；
- `d`：管理码与生态现实的差距；
- `C`：换码的成本（转产、补贴、再培训）。

当 `γA d` 还没有大到超过 `C`，管理码就不换。等到鱼崩了，`C` 突然变得很大——因为换码已经不只是“改配额”，是“整个社区转产”。**越晚换，`C` 越大；`C` 越大，越换不动。** 这是一个正反馈。

### 11.6　反例：不是所有崩溃都不可逆

有些渔业恢复过：鲱鱼、鲸类、某些鳕鱼种群。不是所有“临界”都是单向门。判据是：

- 低态是不是**另一种稳定态**，还是只是高态的浅坑；
- `C` 有多大：如果 `C` 小，推回去就行；
- 是否有**替代资源**：`ρ` 高，社区能撑到鱼回来。

所以“临界”是一个**可检验的断言**，不是“事情很严重”的形容词。要证明它，得给出两个稳定态、一个阈值、一条迟滞线。给不出，就只是“变化很大”。

<div class="note"><b>这条能被怎么打掉：</b>若鳕鱼在禁渔后二十年内恢复到崩溃前水平，那么“低态是另一个稳定态”不成立；本章退回“过度捕捞＋管理滞后”的解释。</div>

### 11.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 降 `T`（更早评估） | 更早看见 | 科研机构 | 数据太晚，评估追不上 |
| 抬 `w`（配额责任） | 更早限渔 | 渔民、政客 | 执法太弱，配额是纸 |
| 降 `C`（转产补贴） | 换码更容易 | 纳税人 | 补贴停后，社区又回到旧路 |
| 改 `Φ`（分权管理） | 更可争辩 | 旧管理部门 | 分权太碎，没人负责 |
| 抬 `ρ`（替代生计） | 社区撑得住 | 公共投资 | 替代品不可持续时，白费 |
| 留出口（移民） | 个体有退路 | 留下的人 | 出口太快，社区空心化 |

### 11.8　本章小结

四句。第一，临界不是“变化大”，是稳定态的数量或位置变了；势函数有两个坑，或者一个坑消失了。第二，三个标记：跳变、慢化、迟滞；不必同时亮，但迟滞一在，旧码就难回去。第三，破坏比修复便宜：`C₂ > C₁`，带宽不对称。第四，临界是可检验的断言：两个稳定态、一个阈值、一条迟滞线；给不出，就只是“变化很大”。

<div class="box box-takeaway"><p><b>一句话带走：</b>有些变化不是“变大了”，是“回不去了”；回不去，因为回去的账比来的账贵。</p></div>

<p><b>钩子。</b>临界之后，旧码回不去；但新码不会自己长出来。下一章：转型——谁来完成它。</p>

## 第12章　转型——谁来完成它

<div class="box box-takeaway"><p><b>本章主张。</b>旧码崩了，新码不会自己长出来。转型要三样东西同时到位：<b>足够大的外部压力 `w`</b>、<b>足够密的联盟网络 `A`</b>、<b>付得起的转型成本 `C`</b>；还要压得住<b>抵抗 `R`</b>。四者合起来，才有一个可判的条件：<b>`w·A·d > C + R`</b>。谁完成它，谁就拿到 `Φ`；谁付 `C`，谁就承担代价。</p></div>

<p class="lead" data-story="1">1868 年 4 月，京都。一个下级武士在御所前读到《五条誓文》：“广兴会议，万机决于公论。”他不完全信，但他知道旧的那套已经撑不住了。三年后，废藩置县；五年后，征兵令与地租改正；一个农民在村口看见新的地券，知道自己要按新规矩交税。旧码崩了，新码不是自己长出来的；是一小群人写出来的。（历史重建，B/C 级。）</p>

### 12.1　转型不是一次事件

转型至少有三段：

1. **旧码崩**：旧的分期、旧的身份、旧的税制，不再能处理眼前的事；
2. **新码生**：一小群人写出新的分类、新的规则、新的账本；
3. **新 `Φ` 立**：谁有资格写、谁有资格解释、谁有资格执行，重新排位。

三段不是顺序发生的，常常是同时发生、互相卡住。旧码崩了，新码不一定出得来；新码出来了，`Φ` 不一定立得住。**转型的失败，多半不是“没有新思想”，是“没有联盟把新思想变成码”。**

### 12.2　谁来完成它：一个能付 `C` 的联盟

转型不是“所有人一起转”，是一小群人先转，然后逼其他人跟上。这群人要有三个条件：

- **足够密**：彼此认识、能协调、能传递消息（`A` 高）；
- **付得起**：能承担转型的成本 `C`（时间、钱、身份、旧特权）；
- **拿得到 `Φ`**：能写新码、解释新码、执行新码。

明治维新的联盟是下级武士、宫廷贵族、部分商人。他们不是“人民”，但他们有 `A`、有 `C`、有 `Φ`。**转型的完成者，通常不是旧秩序的全部受害者，而是旧秩序里“有网络、有资源、又有动机”的那一小块。**

### 12.3　一个可判的条件

把转型写成一个门槛：

```
Pr(transition) = σ( β [ w · A · d − C − R ] )
```

- `w`：外部压力（黑船、战争、危机）；
- `A`：联盟网络密度；
- `d`：旧码与新码的距离（越大，越需要动员）；
- `C`：转型成本（补偿旧特权、建新机构、训练新人）；
- `R`：抵抗（旧精英、地方势力、习惯）。

当 `w·A·d > C + R`，转型发生；否则，旧码继续撑。**这不是把历史套进公式，是公式在两段历史里给出不同的符号。**

### 12.4　明治的序列：压力、联盟、成本、`Φ`

- **1853 年**：黑船来航，`w` 突然升高；旧码“锁国”撑不住。
- **1868 年**：王政复古、《五条誓文》，新码开始写；联盟是下级武士＋宫廷贵族＋部分商人。
- **1871 年**：废藩置县，`C` 开始付：旧藩主的家禄被折成公债，地方身份被中央官僚取代。
- **1873 年**：征兵令、地租改正，`γ` 开始执行：新码落到每个人头上。
- **1889 年**：宪法，`Φ` 定型：谁有资格写、谁有资格解释、谁有资格执行，排好了。

**谁付账？** 武士失去家禄，农民按新地租交税，女性没有选举权，殖民地承担对外扩张的成本。**谁拿 `Φ`？** 一小撮 oligarchs、官僚、天皇制度。**转型成功，不等于转型公平；它只说明联盟凑够了 `C`、压住了 `R`。**

### 12.5　为什么明治成功，1848 失败

1848 年欧洲革命：`w` 也高（饥荒、金融危机、旧制度失灵），`d` 也大，但 `A` 碎——工人、学生、中产、农民各有各的组织；`C` 没人付——旧精英没有被补偿，新机构没有钱；`R` 很高——军队还在旧精英手里。结果是一个个失败。

明治的 `A` 更密：下级武士有藩校、有同乡、有共同敌人；`C` 有来源：旧藩主的家禄被折成公债；`R` 被压住：新政府掌握了军队与警察。**同一张公式，1848 的右边大于左边，明治的左边大于右边。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `w` 低、`A` 碎、`C` 无来源的案例里，仍然发生了完整转型，那么“联盟—成本—抵抗”这条不成立；转型可能由外部强加，不由内部联盟完成。</div>

### 12.6　转型之后：新码也会变成旧码

明治的新码，后来也变成了旧码：藩阀、军部、财阀，层层固化；到 1945 年，又一次崩。**转型不是一次性的；它是 `C` 的再次支付。** 每一次新码，都会长出新的 `Φ`、新的 `γ`、新的既得者；下一代人要改，还得再付一次 `C`。

这就是为什么“转型完成”不是终点，是下一轮的起点。**旧码崩、新码生、新 `Φ` 立、新码再旧——这是一条螺旋，不是一条直线。**

### 12.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 抬 `w`（外部压力） | 转型窗口打开 | 被压力波及的人 | 压力太短，联盟还没成形 |
| 织 `A`（联盟网络） | 动员能力上升 | 联盟成员 | 联盟太散，变成派系 |
| 降 `C`（补偿旧精英） | 抵抗下降 | 纳税人、新政权 | 补偿太厚，新码被旧人俘获 |
| 压 `R`（强制） | 转型更快 | 被压的人 | 强制太狠，新码失去合法性 |
| 分 `Φ`（共享权力） | 合法性上升 | 旧精英 | 分得太碎，决策不动 |
| 留出口（允许退出） | 抵抗下降 | 留下的人 | 出口太大，新码空心化 |

### 12.8　本章小结

四句。第一，转型不是一次事件，是旧码崩、新码生、新 `Φ` 立三段。第二，完成转型的，不是“人民”，是一个有 `A`、付得起 `C`、拿得到 `Φ` 的联盟。第三，条件 `w·A·d > C + R`：压力、网络、距离，压过成本与抵抗。第四，转型成功不等于转型公平；谁付 `C`、谁拿 `Φ`，是两件事。

<div class="box box-takeaway"><p><b>一句话带走：</b>新码不会自己长出来；它是一小群人付了 `C`、拿走了 `Φ` 之后，才长出来的。</p></div>

<p><b>钩子。</b>转型完成，新码变成制度；制度会保护它自己。下一章：长时段——为什么有些文明改得动，有些改不动。</p>

## 第13章　长时段——为什么有些文明改得动，有些改不动

<div class="box box-takeaway"><p><b>本章主张。</b>长时段的“改得动／改不动”，不取决于文明聪明不聪明，取决于<b>`Φ` 的集中度</b>、<b>`A` 的密度</b>、<b>`C` 的大小</b>、<b>`μ` 的合法性</b>。`Φ` 越集中、`A` 越密、`C` 越大，码越稳，也越脆；`Φ` 越分散、`A` 越碎、`C` 越小，码越容易变，也越容易碎成一地。**稳定与脆弱，是同一枚硬币的两面。</b></p></div>

<p class="lead" data-story="1">1905 年，中国最后一次科举考试。一个考生走进号舍，发现题目已经不像从前；几个月后，朝廷下诏废科举。一千三百年的选官码，在几年内被拆掉。同一时期，欧洲的大学从博洛尼亚（1088）、巴黎（约 1150）、牛津（1096）一路长出来，没有哪一个“统一标准”能管住全部；它们互相竞争，也互相打架。两套码，两种长时段。（历史重建，B/C 级。）</p>

### 13.1　长时段的码：`q`、`Φ`、`A`、`C`、`μ`

长时段的码，不是一条规则，是一套**选人、解释、执行**的制度。它由五样东西撑着：

- `q`：选什么人、考什么、怎么分类；
- `Φ`：谁定这套码、谁解释、谁执行；
- `A`：谁跟谁连着——考生、考官、书院、地方官；
- `C`：换一套码要付多少——补偿旧人、建新机构、训练新人；
- `μ`：这套码的合法性——为什么大家认它。

五样里，`Φ` 最容易被忽略。我们习惯说“制度”，但制度不是一个东西，是**三件套**：命名、解释、执行。`Φ` 集中在谁手里，决定了这套码是“稳”还是“脆”。

### 13.2　两种长时段：单中心与多中心

**单中心：科举。** `Φ` 集中在朝廷：考什么、怎么考、谁录取，最终由皇权与礼部定；`A` 很密：考生、考官、书院、地方官，形成一张全国网络；`C` 很大：废科举不是改一门考试，是拆掉一整套选人、养人、认人的制度；`μ` 很高：科举不只是选官，是“读书—做官—光宗耀祖”的合法性。

**多中心：欧洲大学。** `Φ` 分散：教皇、皇帝、国王、城市、行会，各自发特许状；`A` 碎：大学之间、大学与教会、大学与城市，各有各的网络；`C` 相对小：一所大学改章程，不必改整个欧洲；`μ` 分裂：没有一套“唯一正确”的课程，只有各自的传统与竞争。

两种长时段的结果不一样：科举稳，但脆；欧洲大学乱，但活。**稳与活，不是道德评价，是结构后果。**

### 13.3　一个可算的集中度

把 `Φ` 写成三个权力上的份额：命名 `s_name`、解释 `s_interp`、执行 `s_enforce`。每个权力上用赫芬达尔指数：

```
H = Σ_k Σ_i s_{ki}²
```

`H` 越接近 1，越集中；越接近 1/3，越分散。再定义：

- `A`：网络密度或 `λ₂(L)`；
- `C`：换码成本；
- `μ`：合法性（可以用“多少人认这套码”代理）。

长时段存活概率：

```
Pr(survive) = σ( β [ H · A · μ − C ] )
```

- `H` 高、`A` 密、`μ` 高、`C` 大 → 码稳，但一旦 `w` 越过阈值，崩得也快（科举 1905）；
- `H` 低、`A` 碎、`C` 小 → 码容易变，但很难形成统一标准（欧洲大学）；
- 中间态：稳而不僵，变而不碎——这是最难的。

**这不是“文明优劣”的公式，是“选择结构”的公式。** 单中心不是更聪明，多中心不是更自由；它们各自付不同的账。

### 13.4　为什么科举在 1905 年崩，而不是慢慢改

用第12章的门槛 `w·A·d > C + R` 读：

- `w`：甲午之后，亡国压力上升；
- `A`：改革派、留学生、新军、地方绅商，网络成形；
- `d`：科举与新学堂、新官制之间的距离，越拉越大；
- `C`：废科举的成本——旧考生的出路、旧官员的安置、旧书院的转型；
- `R`：保守派与既得利益。

1905 年的特别之处：`w` 高到足以让朝廷认为“不改就亡”；`A` 已经成形；`C` 被“立停科举、广设学堂”一次性支付；`R` 被上谕压住。**不是科举“渐渐不行了”，是门槛被跨过了。**

### 13.5　反例：多中心也会碎

多中心不是免费的。欧洲大学的多中心，带来了竞争与实验，也带来了分裂、战争、标准混乱。`H` 低、`A` 碎，意味着没有谁能统一；好处是“总有人试别的”，坏处是“谁也不能保证最低标准”。

单中心也不是一无是处。科举提供了一条全国可比的选人标准，让寒门有机会（虽然很窄），让帝国有一张统一的文官网络。**单中心的稳定，是真实的；多中心的活力，也是真实的；两者都有账。**

<div class="note"><b>这条能被怎么打掉：</b>若在 `H` 很低、`A` 很碎、`C` 很小的制度里，仍然长期无法产生任何新码，那么“多中心更容易变”这条不成立；碎片化可能直接导致瘫痪，而不是实验。</div>

### 13.6　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 集中 `Φ`（单中心） | 更稳、更快 | 边缘群体 | 过阈值时，崩得更快 |
| 分散 `Φ`（多中心） | 更多实验 | 统一性、协调成本 | 太碎时，谁都不负责 |
| 织 `A`（网络） | 动员更快 | 被连接的人 | 网络太密时，意见同质化 |
| 降 `C`（补偿旧人） | 转型更容易 | 纳税人、新制度 | 补偿太厚，旧码借壳还魂 |
| 抬 `μ`（合法性） | 码更稳 | 被说服的人 | 合法性造假时，崩得更快 |
| 留出口（允许退出） | 抵抗下降 | 留下的人 | 出口太大，公共码空心化 |

### 13.7　本章小结

四句。第一，长时段的码由 `q、Φ、A、C、μ` 撑着；`Φ` 是三件套，不是一个人。第二，单中心（科举）稳而脆；多中心（欧洲大学）乱而活；两者都有账。第三，`H·A·μ − C` 给出存活方向；`H` 越集中，越稳也越脆。第四，科举 1905 年崩，不是“渐渐不行”，是 `w·A·d` 跨过了 `C+R`。

<div class="box box-takeaway"><p><b>一句话带走：</b>稳定与脆弱是一枚硬币的两面；你想让码更稳，就得接受它崩得更快。</p></div>

<p><b>钩子。</b>长时段不是宿命；但模型有边界。下一章：这套模型在哪里停。</p>

## 第14章　边界——这套模型在哪里停

<div class="box box-takeaway"><p><b>本章主张。</b>这套模型是<b>句法完备、经验开放</b>的：每个符号有定义，方程闭合，极限能退回邻居；但参数没有标定，时刻算不出来，测量本身被 `Φ` 选择。<b>边界不是免责，是尺度</b>：每一条边界都要写清“要什么才能跨过去”，不是“以后研究”。</p></div>

<p class="lead" data-story="1">1905 年，一个考生走进最后一次科举的号舍；1992 年，一个渔民把最后一网鳕鱼拖上船；2008 年，一个分析师给 CDO 盖上 AAA；2023 年，一个插画师被平台标成“疑似 AI”。四个人的处境，模型都能说出结构；但模型说不出他们明天该做什么。**结构能指方向，不能替人走路。**</p>

### 14.1　能说的三件事

这套模型能说三件事，而且说得比旧版清楚：

1. **方向**：抬 `w` 码变细，抬 `T` 码变粗；抬 `γ` 更一致，抬 `κ` 更多新码。
2. **代价落在谁头上**：六张账单、`Φ` 三件套、`C` 的五层，都能指认付方与收方。
3. **条件**：`γA d > C`、`wAd > C+R`、`a*=ηe/(ηe+g+c)`、`C₂>C₁`；这些不是形容词，是可判的不等式。

这三件事合起来，就是“能描述，也能改造”的最小版本：描述是“为什么长这样”，改造是“动哪一格、谁疼、什么时候不灵”。

### 14.2　不能说的七件事

| # | 边界 | 能说什么 | 不能说什么 | 要什么才能跨过去 |
|---|---|---|---|---|
| 1 | **数值** | 方向、序、相对大小 | `η、κ、α、β` 的具体值 | 标定；一次准实验或一套工时数据 |
| 2 | **时刻** | 条件是否跨过 | 哪一天、哪一年发生 | 风险率 `λ(t)`；事件史数据 |
| 3 | **测量** | 模型的结构 | 样本代表谁 | 观测方程 `s(q)`；缺失机制 |
| 4 | **语义** | `I(q)` 的蕴涵集 | 为什么是这一句话奏效 | 概念格的操作化；语料实验 |
| 5 | **执行者** | 什么样的联盟能完成转型 | 为什么是这一批人 | 事件数据；人事网络 |
| 6 | **权力** | `Φ` 三件套、`C_Φ` 判据 | `C_Φ` 的具体值 | 独立复核工时、申诉时长、决策链长度 |
| 7 | **账本** | 每笔转移有对手方 | 一般均衡下的价格反馈 | 社会会计矩阵；联立方程 |

七条里，前三条是“算不出”，中间两条是“说不出”，后两条是“没闭合”。**它们的性质不同，不能混成一句“以后研究”。**

### 14.3　七条边界的真实案例

**1. 数值：2008 年的 AAA。** 模型能说 `a*` 低，因为 `c`（发行人付费）高、`e`（核查投入）低、`g`（评级 shopping）高；但模型说不出 AAA 的具体违约率，也说不出哪一天会崩。要跨过去，得估 `η、e、g、c`。

**2. 时刻：1992 年的鳕鱼。** 模型能说高态会消失、迟滞不对称；但模型说不出禁渔令会在 1992 年 7 月下，也说不出鱼什么时候回来。要跨过去，得写 `λ(t)`：压力、网络、成本随时间怎么变。

**3. 测量：2023 年的 AI 标签。** 模型能说 `S*` 低（平台误标不赔、申诉难、独立复核贵）；但模型说不出被误标的比例，因为样本是被 `Φ` 选出来的：只有申诉的人进了记录。要跨过去，得写 `s(q)`，并做一次审计。

**4. 语义：艺术与宗教。** 模型能说 `I(q)` 的蕴涵集变了；但模型说不出为什么这一句诗、这一场仪式打动人。要跨过去，得把概念格落到语料与现场，不是再加一个参数。

**5. 执行者：明治维新。** 模型能说 `wAd > C+R`，能说联盟要有 `A`、付得起 `C`、拿得到 `Φ`；但模型说不出为什么是下级武士，不是商人。要跨过去，得用事件史与人事网络，不是用公式。

**6. 权力：平台、维基、DSM。** 模型能说 `C_Φ` 高就三权合一，低就分开；但模型说不出 `C_Φ` 的具体值，也说不出三权为什么在某一年分开。要跨过去，得量独立复核的工时、申诉的时长、决策链的长度。

**7. 账本：六张账单。** 模型能让每笔转移有对手方，账本闭合；但模型说不出价格反馈：平台把核查费转给用户，用户的注意力价格会怎么变？要跨过去，得写社会会计矩阵与联立方程，不是加一张表。

### 14.4　什么会杀死这套模型

一条原理如果什么都能解释，它就什么也没解释。下面五条，任何一条成立，对应部分就当版降级：

1. **`v*` 对 `w` 不单调**（控制 `T、λ` 后，错得越疼反而越粗）→ 核心塌。
2. **`w` 对 `P` 不敏感** → 内生价格删掉，退回外生。
3. **`I(q)` 在控制 `q` 后不增加预测力** → 语义按奥卡姆剃掉。
4. **新颖度对成功度单调**（没有倒 U）→ `κ` 退回线性信息增益。
5. **顺序效应在所有设计下都为零** → `U` 的 commutator 降为形式备注。

这五条不是免责，是判决线。**模型的可信，不在于它能说多少，而在于它知道自己会被什么打掉。**

### 14.5　这本书停在这里

这本书停在这里，不是因为它什么都解释了，是因为它知道自己在哪停：

- 它能说“往哪边”，不能说“多少”；
- 它能说“什么条件”，不能说“哪一天”；
- 它能说“谁付账”，不能说“价格会怎么反馈”；
- 它能说“意义的结构”，不能说“意义的内容”；
- 它能说“什么样的联盟”，不能说“为什么是这一批人”。

**边界不是这本书的补丁，是它的签名。** 一个能说“这里我说不了”的模型，比一个什么都能说的模型更有用；但“说不了”也要分类：缺数据、缺概念、缺闭合，三种缺法的时间尺度完全不同。

<div class="box box-takeaway"><p><b>一句话带走：</b>模型停下的地方，是人继续走的地方；但停在哪里，要先写清楚。</p></div>

<p><b>钩子。</b>边界之后，还剩一件事：这些代价，最后落在谁头上。下一章：谁在承担。</p>

## 第15章　谁在承担

<div class="box box-takeaway"><p><b>本章主张。</b>代价不会消失，只会转移。转移有四条通道：<b>价格 `w`、时间 `T`、风险 `ν`、声音 `Φ`</b>。要回答“谁在承担”，得同时回答三件事：<b>谁付</b>、<b>什么时候付</b>、<b>谁被记进了账</b>。第三件最容易被漏掉：账本只记被看见的人，没被看见的人不在表里。</p></div>

<p class="lead" data-story="1">2008 年，一个分析师给 CDO 盖上 AAA；1992 年，一个渔民把最后一网鳕鱼拖上船；1905 年，一个考生走进最后一次科举的号舍；2023 年，一个插画师被平台标成“疑似 AI”。四个人不在同一张桌上，但他们的账单可以放在同一张表里：谁付、付什么、什么时候付、谁没被记进去。</p>

### 15.1　四条转移通道

代价转移不是一句“转嫁”，它有四条通道：

1. **价格 `w`**：把成本折进价格。平台把审核成本折进广告价；评级机构把核查成本折进评级费。
2. **时间 `T`**：把成本推给后来的人。渔民今天的配额，是明天鱼少的账；考生今天的功名，是下一代教育结构的账。
3. **风险 `ν`**：把不确定性推给别人。评级机构把违约风险推给投资者；平台把误标风险推给被标的人。
4. **声音 `Φ`**：把解释权收走。谁有资格说“这是假的”“这是 AI”“这是不合格”，谁就决定了账怎么记。

四条通道不是并列的，常常一起用：先收走声音（`Φ`），再把风险推出去（`ν`），再折进价格（`w`），最后把时间拉长（`T`）。**代价转移的顺滑，靠的就是这四步同时发生。**

### 15.2　一张代价转移表

| 付方 | 2008 评级 | 1992 鳕鱼 | 1905 科举 | 2023 AI 标签 |
|---|---|---|---|---|
| **机构／平台** | 评级费、声誉 | 管理配额 | 废科举的执行 | 检测与审核 |
| **直接承担者** | 投资者 | 渔民、船队 | 考生、塾师 | 被标画师 |
| **社区** | 纳税人（救助） | 海岸城镇 | 地方书院 | 创作者群体 |
| **后来的人** | 系统性风险 | 消失的鱼群 | 人才结构断层 | 训练数据与信任 |
| **没被记进去的人** | 未评级发行人 | 无证渔民 | 女性、非注册考生 | 未申诉的被标者 |

这张表不是完整的会计，是**方向表**：它告诉你，每一笔代价从哪来、往哪去、谁不在表里。

### 15.3　P1 之一：什么时候付——风险率 `λ(t)`

“谁承担”还要问“什么时候承担”。用风险率：

```
λ(t) = λ₀ · exp( β [ w(t)·A(t)·d − C − R ] )
```

- `w(t)`：当时的压力；
- `A(t)`：当时的网络；
- `d`：现状与目标状态的距离；
- `C`：切换成本；
- `R`：抵抗。

`λ(t)` 是“在 t 时刻发生”的瞬时概率。它把“会不会”变成“多快”：

- **1992 鳕鱼**：`w(t)` 是收入下降，`A(t)` 是替代生计网络，`C` 是搬家成本，`R` 是身份依恋。`λ(t)` 在 1990—1992 年上升，渔民先退出，再是社区。
- **1905 科举**：`w(t)` 是亡国压力，`A(t)` 是改革派网络，`C` 是旧考生安置，`R` 是保守派。`λ(t)` 在甲午后跳上去，1905 年跨过。
- **2023 AI 标签**：`w(t)` 是丢约稿，`A(t)` 是同行转发，`C` 是申诉成本，`R` 是平台惯性。`λ(t)` 在“标签影响收入”后才上升；之前，大多数人不会申诉。
- **2008 评级**：`w(t)` 是评级费与声誉，`A(t)` 是监管依赖，`C` 是改模型，`R` 是发行人关系。`λ(t)` 在房价下跌后才跳，但那时已经晚了。

**风险率让“谁承担”有了时间：不是“谁最终付”，是“谁先付、谁后付、谁来不及”。**

### 15.4　P1 之二：谁被记进账——观测方程 `s(q)`

代价表最容易被漏掉的一列，是“没被记进去的人”。补一个观测方程：

```
observed q = q       if s(q)=1
             missing  otherwise
s(q)=1{ γ(q)·ẑ(q) > δ(q) }
```

`ẑ(q)` 是“能被指认的偏离”；`s(q)=1` 才进档案。于是：

- **AI 标签**：只有申诉的人进记录；没申诉的被标者，不在分母里。**你以为误标率是 5%，其实分母只是“申诉者”。**
- **鳕鱼**：只有持证渔民的捕捞进统计；无证、自用、副渔获，不在账里。**鱼少了，账上可能还很好看。**
- **科举**：只有注册考生进记录；女性、非注册读书人，不在“录取率”里。**一个制度的“公平”，只对它记录的人公平。**
- **评级**：只有被评级的发行人进表；影子银行、未评级产品，不在表里。**风险不在表内，不等于不存在。**

**观测方程不是技术细节，是“谁承担”的一部分：不被记录的人，不会出现在任何比例、任何处方里。**

### 15.5　P1 之三：标签怎么转移代价——`I(q)` 的概念格

标签转移代价，靠的是蕴涵。以 AI 标签为例，给一个形式背景：

- 对象：`w₁` 人手作品、`w₂` AI 作品、`w₃` AI 辅助的人手作品、`w₄` 被误标的人手作品；
- 属性：`A`＝被标 AI，`O`＝原创，`C`＝可版权，`M`＝可约稿。

关系大致是：

```
w₁: O, C, M
w₂: A
w₃: A, O
w₄: O, C, M   但观测为 A
```

蕴涵集 `I(q)` 里最要命的一条是：

```
A ⇒ ¬O ⇒ ¬C ⇒ ¬M
```

这条不是事实，是**标签授权的推理**。它把代价从平台转移到画师：画师要证明“我不是 AI”，而证据恰好是标签不采信的笔触。概念格上，`w₄` 本来在 `O,C,M` 的概念里，被标签推到 `A` 的概念里；**一次归类，四次转移**：原创性、版权、约稿、举证责任。

法律里的“规则⇒标准⇒举证责任”也是同一结构：规则越细，举证越靠前；标准越粗，举证越靠后。`I(q)` 不是装饰，它是代价转移的语法。

### 15.6　反例：转移不都是坏事

保险、 pooled risk、公共品，都是代价转移；它们不是“转嫁”，是**分担**。判据不是“有没有转移”，是：

1. 承担者能不能**同意**；
2. 承担者能不能**争辩**（`Φ` 是否可分）；
3. 转移有没有**收方**（账本是否闭合）。

三条里缺一条，转移就从“分担”滑向“转嫁”。**不是所有代价转移都坏；坏的转移，是被藏起来的转移。**

<div class="note"><b>这条能被怎么打掉：</b>若在承担者不能同意、不能争辩、账本不闭合的场景里，转移仍然长期稳定且被视为正当，那么“三条判据”不成立；正当性可能来自传统或强制，不来自同意与争辩。</div>

### 15.7　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 抬 `w`（让错有代价） | 转移减少 | 决策者 | 责任太泛时，没人认 |
| 降 `T`（缩短账期） | 代价更可见 | 后来的人 | 账期太短，长期问题被忽略 |
| 降 `ν`（减少外置） | 风险回到决策者 | 决策者 | 竞争太强时，外置又回来 |
| 分 `Φ`（让声音进来） | 被标者可争辩 | 平台、机构 | 分权太碎时，没人负责 |
| 补 `s(q)`（记录缺失） | 账本更全 | 记录者 | 记录成本太高时，做不起 |
| 闭合账本（收方） | 转移可追踪 | 收方 | 收方匿名时，追不到 |

### 15.8　本章小结

四句。第一，代价转移有四条通道：价格、时间、风险、声音。第二，风险率 `λ(t)` 让“谁承担”有了时间：谁先付、谁后付、谁来不及。第三，观测方程 `s(q)` 让“谁被记进账”可见：不被记录的人，不会出现在任何比例里。第四，`I(q)` 的概念格让“标签怎么转移代价”可算：一次归类，四次转移。

<div class="box box-takeaway"><p><b>一句话带走：</b>代价不会消失，只会转移；最容易被漏掉的，是那些没被记进账的人。</p></div>
