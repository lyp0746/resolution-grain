# 从变分泛函到各学科：一棵推导树，六个遗落领域

> 作者问：**变分是怎么推出模型、再统摄四门学科的？还有没有遗落但实际可描述的领域？**
> 答案分两半：前半是一棵树（每个学科定律 = 泛函在某个参数区域的极限）；后半是六个新领域，
> 每一个都能挂上去，其中四个是**可推**（不只是对应）。

---

## 0 那棵树

```
公设  P1 最小化  ·  P2 规则=划分  ·  P3 一致性代价  ·  P4 换码成本  ·  P5 事件=算子
   │
   └─ 泛函  𝓕[P] = ∫[wD+(T+λ)R]P + (γ/2)∬D P P − (1/β)H(P)
        │
        ├─ δ𝓕/δq = 0        →  v*=(T+λ)/(2w)，δ=Δ/2^R      【个体驻点】→ 比较静态（符号）
        ├─ δ𝓕/δP = 0        →  ESS / 纳什                   【群体均衡】→ 多重均衡、协调结构
        ├─ dP/dt = −∇𝓕      →  复制子 / Fokker–Planck        【动力学】  → 选择速度、极化阈值 γ*=δ
        └─ 势垒 Δ𝓕          →  跳变、迟滞                    【相变】    → 崩、反转、不可逆
```

**关键在于**：学科定律不是四个不同的理论，是**同一条泛函在不同参数区域的形状**。
所以"统摄"的具体含义是：**给出该定律所在的极限，并说出极限之外它会怎么变。**

## 1 一张极限表（这是全书统摄的骨架）

| 极限 / 参数区域 | 码的表现 | 对应的学科现象 |
|---|---|---|
| `w → ∞`（错一点都不可接受） | **极细码**、逐条列举 | 法律条文、会计准则、诊断标准、形式证明 |
| `w → 0` 或 `T → ∞`（无所谓、来不及） | **极粗码**、一两个标签 | 口号、"少许"、MBTI、刻板印象 |
| `γ > δ`（一致性代价 > 准确度差） | **更差的码被维持** | 习俗、教义、行话、党派标签 |
| `C` 大 | **迟滞**：错了也不改 | 制度惯性、身份、职业路径 |
| `β` 小（选择噪声低） | **双稳 + 突变** | 革命、抛弃、崩盘、雪崩 |
| `β` 大（噪声高） | 渐变、无阈值 | 渐进改革、缓慢污名化 |
| 时间尺度分离（`η_v^{-1}≈年`） | 稳态分析可用 | 人格"稳定性"、制度"路径依赖" |
| 时间尺度混杂 | 只能用数值解 | 危机期（周级）的一切判断 |

**一句话**：**学科之间的差别，大多不是机制差别，是"落在哪个极限附近"的差别。**
这句话本身就是这本书的核心主张，而它在表里是**可核的**（每一行都能指到一个式子）。

## 3 六个遗落领域（都能挂上，四个可推）

### 3.1 语言学：Grice 的会话含义 = **发送端省码率，接收端补解码**

Grice（1975）说：人说话不把话说全，听者按"合作原则"补足。
在我们的式子里这是**一条外部性**：

> **说话者用一个更粗的码（`R` 小），把解码成本推给听者（`D` 由听者承担）。**

**这正好是 `REWALK` §3 的"失真未被定价"，换到了语言场景。**

**可推的新预言**：**说话者省码的程度应与听者的"补码能力"（`R_听`）成反比，而不是与亲密程度成正比。**
→ 可测：同一组说话者，对"高能力听者"与"低能力听者"说话的省略量差异；
若省略量与能力无关、只与关系亲密度有关，这条作废。

**第二个接口：语义扩张 = Sartori 的概念拉伸在词上的版本。**
"Literally"从"字面上"扩到"强调"、中文"内卷"从学术到泛用——都是 `Δ↑` 而 `R` 不变 ⇒ `δ↑` ⇒ 区分力下降。
→ **可测**：一个新词从出现到"什么都不再区分"的时间，应与其外延扩张的速度成反比。**这是可数的。**

### 3.2 法学：规则 vs 标准（Kaplow 1992）＝ **细码 vs 粗码**

法经济学有一个现成二分：

| | 我们的读法 | 代价结构 |
|---|---|---|
| **规则**（rule，如"限速 60"） | **事前细码**：写死，`R` 高、`D` 低 | 制定成本高、适用成本低 |
| **标准**（standard，如"合理注意"） | **事后粗码**：留给裁判，`R` 低、`D` 高 | 制定成本低、适用成本高 |

**这几乎是把我们的 `w·D+(T+λ)R` 逐项对上。** 可推的推论：

> **行为发生的频率越高，越该用规则（因为固定成本可摊薄）；频率越低，越该用标准。**

这正是 Kaplow 的结论，但我们多给一条：**当裁判能力（`R_裁判`）下降时，标准应大规模转向规则**——
因为事后补码的人变贵了。→ 可测：司法资源紧张的地区，判例/细则的数量应上升。

### 3.3 医学：诊断分类的粒度、分诊、过度诊断

| 现象 | 我们的读法 | 可推 |
|---|---|---|
| **DSM 的分类增删** | 划分块数 `|A|` 与边界 `δ` 的变动 | 可推：类别数与诊断者间一致性成反比 |
| **分诊（triage）** | 资源约束下 `T` 极高 ⇒ 粗码（"红黄绿"三格） | 可推：分诊级数应随资源紧张度下降 |
| **过度诊断** | **伪分辨率**：声称的 `δ` 小于证据能支撑的 `δ` | 可推：新增亚型越多，治疗效应量越小 |
| **临床 GRADE 分级** | 就是我们的 A/B/C | 同构 |

**过度诊断这条最有用**：它把"伪分辨率"从 MBTI 那种调侃变成**可算的临床问题**——
`log₂(亚型数)` 与"证据强度"的比值，可以作为一个筛查指标。

### 3.4 军事：任务式指挥（Auftragstaktik）＝ **给 `μ`，不给 `δ`**

德军条令与法军条令的经典差别：

| | 我们的读法 |
|---|---|
| **命令式**（法 1940） | 给**细码**：`δ`（每小时到哪、炮往哪打） |
| **任务式**（德） | 给**粗码的锚 `μ`**（"拿下这个高地"），`δ` 交给下级 |

**推导**：战场信息在 `τ` 级的延迟内失效 ⇒ 上层的 `q` 一定过时；
所以**最优做法是把码率分配给 `μ`（意图），把 `δ` 留给信息最近的人**。

**可推的新预言**：**通信中断时，任务式指挥的表现下降幅度应小于命令式**——
因为它的关键码（`μ`）不需要实时更新。→ 这是可以在兵棋/仿真里做的一次对照。

### 3.5 音乐：十二平均律 = 一场持续的码率交易

纯律的音程是**连续**的、极准的（`δ` 小）；十二平均律把它切成 **12 个固定格**：
音程变粗（`δ` 变大、有微小失谐），换来**任意转调**（`γ` 提高——所有人共享同一套格）。

**这就是 `δ = Δ/2^R` 的一次历史交易**：固定 `R`（12 格/八度），用 `δ` 换 `γ`。
**可推的推论**：**转调需求越强的音乐传统，音阶越倾向于等分**（平均律、甘美兰的斯连德罗）。
→ 可测：跨文化的音阶等分程度与该传统转调频率的相关。**这是一个干净、可做的比较研究。**

### 3.6 人工智能：**一切超参数都是我们的量**

| 机制 | 我们的量 | 备注 |
|---|---|---|
| **tokenization** | **划分 `q`** | BPE = 贪心选最省码的划分，**就是 P1+P2 的直接实现** |
| **上下文窗口** | `T`（带宽价格） | 越长越便宜 ⇒ `v` 越小（越能分辨细节） |
| **temperature** | `β`（噪声） | 见 `FIRST-PRINCIPLE` §3.1 的陷阱：**不是 `T`** |
| **RLHF** | 改 `w` | 把某些错误变得"贵" |
| **系统提示** | 给 `μ`（锚） | 与"任务式指挥"同构 |
| **蒸馏** | 强制降 `R` | 学生模型被迫用更粗的码 ⇒ `δ↑` |

**这一节直接接上《开明君主与两层竞争》**：那篇的"重放—判断价差"（RJS）
在本框架里就是**"重复码"与"重新编码"的价差**——
缓存读 = 用旧码，输出 = 重新编码。**RJS 越高，说明重新编码越贵，系统的分辨率越被锁死。**

### 3.7 附带：会计的 materiality ＝ 显式的 `C`

会计上的"重要性原则"（materiality）是**明文写出的阈值**：小于它就忽略。
在我们这里是 `C` 的**制度化**——把"换不换码"的门槛写进规则。
→ 可推：`C` 一旦被明文设定，**报表的 `δ` 分布会出现截断**（低于阈值的差异不再被区分）。可测。

## 4 为什么这些领域"可描述"：四条准入判据

一个领域能被这套框架描述，当且仅当四条都成立：

| # | 判据 | 反例 |
|---|---|---|
| **① 有划分** | 有类别、规则、标签、音阶、token | "意识的主观感受"没有划分 |
| **② 有代价** | 错分有后果（可以是小的，但不能为零） | 纯逻辑演绎（无失真成本） |
| **③ 有观测** | 能数：类别数、条款数、词频、格数 | "文化气质"数不出来 |
| **④ 有不换码的阻力** | `C > 0`（否则无迟滞，只是一次性重新优化） | 完全自由的实验选择 |

**这四条同时是"可证伪性"的操作定义**：四条的每一条都对应一个可测的量。

## 5 不能描述的五个领域（必须写在第 26 章）

| 领域 | 缺什么 |
|---|---|
| **规范性/伦理** | "应该"不在泛函里。我们能说"这样做代价由谁承担"，**不能说"这样不对"** |
| **意识的第一人称** | `D` 是第三人称的错分率，qualia 不进去 |
| **审美判断的独特性** | 能描述美的**传播**（`γ`），不能描述**为什么美** |
| **权力 / 场域** | 缺"谁设定 `w`"这一维（`SUBSUMPTION-SOC` 的布迪厄缺口） |
| ~~公共品供给~~ | **已补上（条件命题）**：`FIRST-PRINCIPLE` §5.5（爱＝`θ`、好奇＝`|∂D/∂R|`）＋ `DERIVATION-REPLICATOR` §6（给 P3 加邻接矩阵；六机制→三落点；阈值按连通分量成立）。**规模只是代理变量**；仍缺 `p_ij` 映射与动态网络 |
| **创新的来源** | 复制子只解释**选择**，不解释**变异**；新码从哪来是第五个口子 |

| 领域 | 最便宜的检验 | 数据 |

| 军事 | 通信中断时两种指挥方式的性能差 | 兵棋仿真 |
| 音乐 | 音阶等分程度 vs 转调频率 | 民族音乐学数据库 |
| 人工智能 | RJS 高 ⇒ 系统在新任务上的 `δ` 更低 | 已有价目表 + 基准分数 |

**六件里最便宜的是音乐**：两个列（等分程度、转调频率）就能做一个跨文化相关。
**最贵的是军事**，但它是唯一能做因果（不是相关）的一个。

## 8 一句话

**统摄不是"我的理论也能解释你的现象"，而是"你的定律是我这条泛函在你那个极限上的形状"。**
上面那棵树给出了极限，那张表给出了形状，六个新领域给出了"这也算"的证据。
