## 0 结论先行

旧版的六个标签，真正独立的只有**一条**：

> **有限区分原理**：一个系统要在环境中持续存在，必须在有限预算下把环境分成可行动的状态；分得越细，代价越高；只有“省下的错”不少于“多花的区分”的划分，才会被保留。

一句话：**不是“人有六种机制”，而是“有限区分在四个位置上必须长成这四样”。**

## 0.1 验收：描述与改造

第二版的验收不是“数值精确”，是**能描述并改造社会与文明现象**。具体三条：

1. **不造真空里的球形鸡。** 每个符号必须绑定一个真实案例和一个可动杠杆；绑不上的，进附录，不进正文。
2. **预言写成三元组**：`（杠杆，方向，谁付账）`＋一个案例。写不成三元组的，不是结论，是备注。
3. **描述与改造同一条**：描述是“这个案例为什么长这样”，改造是“动哪个杠杆、往哪边变、谁承担、什么时候失效”。

杠杆表（第二版的“操作面”）：

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 降 `T`（省时间） | 码变细 | 被要求更细的执行者 | `w` 太低时，细码没人用 |
| 抬 `w`（加利害） | 码变细 | 被错误影响的人 | `w` 被外置时，疼不到决策者 |
| 降 `C`（降换码成本） | 换码更快、迟滞更窄 | 旧码的既得者 | 网络效应太强时，降 `C` 也换不动 |
| 抬 `γ`（加一致性） | 更一致、更粗 | 少数派／偏离者 | 连通分量断开时，`γ` 管不到 |
| 改 `A`（加边／抬 `λ₂`） | 跨群体影响上升 | 被同化的一方 | 桥太窄没用，太宽压平多样性 |
| 抬 `κ`（奖励新） | 新码更多 | 观众／核实者 | `ρ` 太高时，新码看不懂 |

**这张表就是“改造现实”的最小形式。** 它不承诺“按下去一定怎样”，它承诺“按下去往哪边、谁疼、什么时候不灵”。

## 2 一条原理

### A1　有限区分原理

> 一个系统要在环境中持续存在，必须在有限预算下把环境分成可行动的状态；分得越细，代价越高；只有“省下的错”不少于“多花的区分”的划分，才会被保留。

这句话里有三个不可省的部分：

1. **有限预算**：时间、力气、注意力、算力，至少有一项是紧的。
2. **区分有价**：划分不是免费的；切得越细，码率越高，维持成本越高。
3. **选择**：划分不是一次选定的；它在反馈中被保留、复制、修改、淘汰。

“持续存在”不是形而上学，它是一个可操作的门槛：**一个码的长期净收益小于零，它就会消失。** 这就是选择，不需要另设一条公设。

### 2.1 为什么是“一条”，不是“三条”

“有限性”“区分”“选择”听起来像三条。它们其实是一条的三个分句：

- 没有有限性，“区分”不必付代价，粗细问题不存在；
- 没有区分，预算没有对象；
- 没有选择，划分只是一次性描述，不会稳定，也不会有四层。

所以第二版把它们写成一句，而不是三条。**少一条假设，就少一个可以藏错的地方。**

## 3 五个定义

### D1　状态空间与码

设环境的状态空间为 `X`，一个码是 `X` 上的有限划分：

```
q = {C₁, …, C_k},  C_i ∩ C_j = ∅,  ∪C_i = X
```

`k` 是格数。码不是“标签”，标签只是码的一个可见表面；码的实质是**哪些状态被当成同一件事**。

### D2　失真

设 `μ` 是状态分布，`w(x)` 是错分的代价，`c_i` 是第 `i` 格的代表，则

```
D(q, μ) = Σ_i ∫_{C_i} w(x) · d(x, c_i) dμ(x)
```

`d` 是状态之间的距离。`D` 不是“错误率”，是**错分的加权代价**；同一个错误率，在 `w` 高的地方更疼。

### D3　码率与精度

```
R(q) = log₂ k,        δ = Δ / 2^R
```

`Δ` 是覆盖宽度，`δ` 是刻度。覆盖面翻倍，精度减半；这是一份预算的两个出口，不是两条经验规律。

### D4　预算

```
B = (T, λ, M)
```

`T` 是时间价格，`λ` 是疲劳／剩余力气，`M` 是可用算力（人或模型）。三者在不同层可以互换，但不能同时无限。

### D5　持续存在（选择）

一个码 `q` 被保留，当且仅当在预算内它的长期净收益非负：

```
E[ w·D(q,μ) + (T+λ)R(q) ] ≤ E[ w·D(q₀,μ) + (T+λ)R(q₀) ]
```

`q₀` 是当前码。这条不是公设，是“被保留”的定义；它把选择写成了一个不等式，而不是一句“适者生存”。

## 4 五个定理（可推的，不是假设的）

### T1　驻点

把 `D` 写成 `δ` 的函数，对 `δ` 求一阶条件，得

```
v* = (T + λ) / (2w)
```

`v` 是分辨率（码的宽度）。`w` 在分母：错得越疼，码越细；`T+λ` 在分子：工夫越贵，码越粗。**它是解出来的，不是假设的。**

### T2　精度—覆盖

由 `δ = Δ/2^R` 直接得：`R` 每加一比特，`δ` 减半。这条没有自由参数。

### T3　标度律

若 `D ∝ k^{-2}`，则 `k* ∝ (w/(T+λ))^{1/2}`；若 `D ∝ k^{-3}`，则 `k* ∝ (w/(T+λ))^{1/3}`。赌注抬十倍，类别数涨 `√10` 或 `∛10`。**两种指数对应两种失真形状，不是两个可调参数。**

### T4　带宽

换码要付一次成本 `C`。去程付一次、回程再付一次，所以两个阈值之差是 `2C`。这是迟滞的宽度，不是“惯性”的形容词。

### T5　块分解

把一致性代价写成 `γ qᵀL(A)q`，`L` 是图拉普拉斯。若 `A` 有 `k` 个连通分量，`L` 的零特征值重数是 `k`，一致性项在分量之间不耦合。于是群体层至少可以同时存在 `k` 套互不施压的码；桥的容量是 `λ₂(L)`。

**这五条是这条原理的“内容”。** 一条原理如果能推出五条不显然的结论，它就不是同义反复；如果推不出，它就该被扔掉。

## 5 四个算子（不是四条公设）

### Π　注意：意识到才能看到

只有被注意到的维度进入划分：

```
q = q ∘ Π
```

`Π` 是一个选择算子，`supp(Π)` 是“看见的范围”。没有被 `Π` 覆盖的维度，不是“分得粗”，是**分辨率为零**——它不在码里。这解释了“意识到才能看到”：不是先看见再注意，而是注意决定了什么算“看见”。

**可查：** 同一个任务，若把某个维度标为“与后果无关”，`Π` 会把它关掉，`q` 在该维度上退化为常数；若标为“高 `w`”，`Π` 会打开它。**这不是“注意力不集中”，是最优选择。**

### q　划分：码本身

`q` 是四层共用的对象。个人层是“一个人怎么切”，群体层是“共享的切法”，社会层是“制度化的切法”，文明层是“长期稳定的切法”。四层不是四个对象，是同一个 `q` 的四种约束。

### U　顺序：非对易

`U_w` 改价格，`U_q` 改码。若目标函数对 `(q,w)` 不可分，两个更新一般不对易：

```
[U_w, U_q] = U_w U_q − U_q U_w ≠ 0
```

环面积就是“谁先动”的痕迹。`2C` 是它在二维截面上的投影。**这不是量子**；非对易是线性算子的一般性质，不需要普朗克常数。

### I　推理：语义反身性

一个划分本身不构成意义；意义是“这套划分允许你推出什么”：

```
I(q) = { A ⇒ B : 由 q 的格间关系授权的推理 }
```

语义是 `(q, I(q))` 的不动点：

```
q* ∈ argmin F(q, μ(q), I(q))
I* ∈ argmin C(I, q*)       (C 是推理的维持成本)
```

同一个 `q`、不同的 `I`，会给出不同行为。**可查：** 两套培训材料，类别完全相同，只改“从 A 能推出 B”的规则；若行为随规则变，`I` 不是 `q` 的附属品。

### ν／κ　偏好：爱与好奇

它们不是算子，是目标函数里的两个权重：

- **爱**：`ν > 0` 把别人的失真记进自己的账。`ν` 有范围 `φ_ij` 与期限；所以爱是集中的，不是均匀的。
- **好奇**：`−κ·IG(q;e)`，`IG` 是码对环境的信息增益。好奇是“对不确定性的定价”，不是“喜欢新东西”。

**可查：** 照护与教学时长应当是重尾的（爱集中）；好奇应当随先验不确定性呈倒 U（信息缺口），不是越多越好。

## 6 一个联合泛函

把上面五样写在一起：

```
min_{Π,q,I}  Σ_i [ w_i + ν Σ_j φ_ij w_j ] D_i(q∘Π, μ)
           + (T+λ) R(q)
           − κ · IG(q; e)
           + γ · qᵀ L(A) q
```

约束：

```
I ∈ I(q),     q 是有限划分,     Π 是选择算子
```

读法：

- 第一项：错分的疼，含“别人的疼”被 `ν` 记进来多少；
- 第二项：分细的钱；
- 第三项：好奇的收益；
- 第四项：偏离共享码的罚；
- `Π` 决定哪些维度进入前三项；
- `I` 决定同一个 `q` 能推出什么。

**这就是“四层一张网”的句法形式。** 四层不是四个方程，是同一泛函在四种约束下的四个解：个人固定 `P` 选 `q`；群体固定个体选 `P`（复制子）；社会加 `L(A)` 与 `ν`；文明加慢变量 `Φ`、`μ` 与长期约束。

---

### 6.5 四层＝重整化流

把四层写成四次粗粒化：

```
q_{l+1} = R_l(q_l),     w_{l+1} = Z_l w_l,     T_{l+1} = Y_l T_l
```

`R_l` 是第 `l` 层的粗粒化算子。固定点 `R_l(q*)=q*` 就是稳定的制度／文化码；在固定点附近线性化，得到相关算子与无关算子——**相关算子就是“改一层会带动几层”的那些量**，无关算子就是“怎么改都会被洗掉”的那些量。

这把 A.14 的“四层是网络”升级为“四层是重整化流”：上行是粗粒化，下行是阈值处的重置。它也是“标准模型”野心的真正数学入口：不是四个比喻，是一个流。

**强度声明：** 这是**形式类比**，不是物理同构。它没有局域对称性、没有守恒律、没有可测的 `β` 函数。它的用处是给出固定点、普适类与相关／无关算子的语言，不是宣称社会=物理。

### 6.6 强度阶梯：不要把“像”说成“是”

系列里的《同构的强度》给了四级阶梯：**严格同构／伴随对偶／函子式类同构／只是比喻**。第二版的每一条跨层映射都要标级：

- 个体→群体：**函子式**（同一个 `q`，约束不同）；
- 群体→社会：**函子式**（加 `L(A)`、`ν`）；
- 社会→文明：**比喻／半形式**（`Φ`、`μ` 仍外生）；
- 四层→重整化流：**形式类比**（有方程，无守恒律）。

标级不是谦辞，是**防止负迁移**：系列的数据说，最危险的不是“比喻”，是“看起来像证明”的伴随／函子档（负迁移率 60%／50%）。第二版宁可把话说低一档，也不让读者把“像”当成“是”。

## 7.0 对标标准模型：抄架构，不抄本体

物理标准模型的结构是：**规范对称性 → 场内容 → 拉格朗日量 → 参数表 → 精确预言 → 重整化群**。它能被当作标杆，不是因为它“终极”，而是因为它把“少假设、多预言”做到了极致。

第二版可以抄这个**架构**：

| 标准模型的部件 | 第二版的对应 | 现状 |
|---|---|---|
| 规范对称性 | 重标号不变＋尺度不变 | 重标号不变已有（A.2）；尺度不变待写 |
| 场内容 | `q, Π, I, A, w, T, λ, ν, κ` | 已定义；`I` 还要代数化 |
| 拉格朗日量 | 联合泛函 | 已写出候选 |
| 参数表 | 每个参数的代理与量纲 | 待建；不能有自由函数 |
| 精确预言 | 12—20 条带判决线的预言 | 已有雏形；待登记 |
| 重整化群 | 四层粗粒化流 | 6.5 刚写出形式 |

**不能抄的：** 局域规范不变性、守恒律、可重整性、基本本体论。社会系统是开放的、非平稳的、反身的；把社会学做成“标准模型”是范畴错误。**能做的是“分辨率的有效场论”**：一个小参数集、一个流、一组可判决预言，知道自己只是有效理论。

## 7 统摄表：旧理论是新模型的哪个极限

“统摄”不是并置。判据只有一条：**把新模型的某个参数取极限，旧理论的核心结论必须原样出现；若出现不了，就不算统摄。**

| 旧理论 | 极限 | 旧结论 | 新模型多给什么 |
|---|---|---|---|
| Shannon 率—失真 | `w→∞`, `T→0`, `q` 连续 | `R(D)` 曲线 | 离散划分、价格、群体一致性 |
| Sims 理性疏忽 | 高斯、连续、无群体 | 信号精度随 `w` 升 | 可数块、换码成本、四层 |
| Granovetter 阈值 | `q` 二元、`γ` 固定 | 阈值分布决定集体行为 | `γ` 的三根轴、`z` 的执行范围 |
| North 制度变迁 | `C` 固定、`q` 制度化 | 路径依赖 | `C` 可算、带宽 `2C`、桥容量 |
| Bourdieu 场域 | `w,λ` 由场域给定 | 场域塑造判断 | 场域＝`w,λ` 的参数化，可测 |
| Wittgenstein 用法 | `q` 固定、`I` 为主 | 意义即用法 | `I(q)` 的可算形式、固定点 |
| Spence 信号 | `ν` 固定、`q` 二元 | 信号可信度 | `ν` 可正可负、代价可外置 |
| Hamilton／Trivers | `ν>0`, `φ` 固定 | 亲缘／互惠利他 | `ν` 的范围与期限、预算集中 |
| Loewenstein 信息缺口 | `κ` 固定、`IG` 单峰 | 好奇倒 U | `κ` 与 `T` 的交换、可模拟 |
| Simon 满意化 | `T` 极高、`q` 粗 | 满意解 | 满意化是 `v*` 的一个角点 |

**随机游走检验：** 把这张表打乱，随机抽一条，按“极限→旧结论”走一遍；走不通的，要么补条件，要么从“统摄”降为“并置”。这张表不是荣誉榜，是待验清单。

## 8 新预言（可判决的）

### 8.1 DSH 插件社区

把插件看成码的变体，平台注意力是 `T`，人类投喂／弃养是 `w`／`ν`。复制子—变异方程：

```
ṗ_a = p_a(π_a − π̄) + μ(·)
```

`π_a` 是插件 `a` 在平台上的净收益。**三条可查：**

1. 先传播的插件，应当是**降低 `T` 但抬高 `D`** 的那一类；提高 `R` 的记忆插件会晚一步。
2. “弃养”应当是**阈值／迟滞**，不是线性衰减；同一个插件，在 `w` 下降后不会立刻被弃，要等它跨过 `2C`。
3. 求偶等群体行为，应当先在**连通分量内部**稳定，再跨分量扩散；`λ₂(L)` 低的社区先出现“方言化”的求偶脚本。

### 8.2 缩放与涌现

模型容量 `M` 降低细码成本：

```
T(M) = T₀ M^{-α}
```

代入 `v*`：`v* = (T₀M^{-α}+λ)/(2w)`。**规模变大只在 `w` 高的任务上产生“变细”；`w` 低的任务上，规模只让粗码跑得更快。**

涌现的判决在任务容差 `δ_task`：

```
成功 = 1{ δ(q) ≤ δ_task }
```

若 `δ_task` 分布很窄，能力曲线是阶跃；若 `δ_task` 是渐变的，能力曲线是平滑的。**所以“涌现”不是规模的固有属性，是任务容差的形状。** 这条可以直接打掉“涌现 vs 渐变”的争论：两边测的是不同的 `δ_task`。

### 8.3 爱与好奇

- 爱：`ν` 集中，照护时长重尾；跨物种比较（田鼠配对、鸟类合作育幼、灵长类安抚）应当在同一算子上不同参数，而不是“动物也有爱”的拟人化。
- 好奇：`κ` 与先验不确定性呈倒 U；`T` 越低，`κ` 越能起作用。**可查：** 给同一批人同一套材料，只改“下一步有多确定”，好奇投入应当先升后降。

### 8.4 注意与语义

- 注意：未被 `Π` 覆盖的维度，分辨率是零，不是“粗”。**可查：** 在注意盲视实验里，被忽略的维度不是被低估，而是根本不进入 `q`。
- 语义：同一个 `q`、不同的 `I`，行为应当分叉。**可查：** 两套培训材料，类别相同，推理规则不同；若行为不变，`I` 是多余的，按奥卡姆剃掉。

## 9 什么会杀死这套地基

一条原理如果什么都能解释，它就什么也没解释。下面是五条能杀死它的判决线：

1. **若 `v*` 对 `w` 不单调**（在控制 `T`、`λ` 后，错得越疼反而越粗），T1 不成立，核心塌。
2. **若 `δ=Δ/2^R` 在小 `k` 处系统性失效**，T2 要加条件；旧版已知 `k≤3` 有破缺，第二版要把它写成边界，不是补丁。
3. **若缩放产生的“涌现”在渐变任务上仍然尖锐**，8.2 的 `δ_task` 解释失败。
4. **若 `I(q)` 在控制 `q` 后不增加任何预测力**，语义这条按奥卡姆剃掉；本书退回“码有多粗”。
5. **若顺序效应在所有设计下都为零**，`U` 的 commutator 在实践中不可测，A.20 降为形式备注。

这五条里任何一条成立，第二版都要改；不是“以后研究”，是当版改。

## 11 写作：钩子、回扣、真善美

### 11.1 一条脊梁

全书只问一个问题：**同一份力气，为什么有人分得细，有人分得粗？** 答案只有一句：**因为区分有价，而价由谁付、什么时候付、付给谁，决定了码的粗细。** 四层是这句话的四个尺度；四个算子是这个句话的四个位置；案例是这句话的十五次现场；预言是这句话的判决；边界是这句话停下的地方。

### 11.2 每章一个钩子，每部分一次回扣

每章开篇的场景段必须含一个**未答的问题**；本章的机制回答它；章末的“一句话带走”留下**下一个问题**。每部分末章把这个部分的问题收成一个“账单”，再把下一部分的问题抛出去。

| 部分 | 开篇钩子 | 收束回扣 |
|---|---|---|
| I 舞台 | “谁赔钱？” | 类型不是人的属性，是位置 |
| II 个人 | “他围着什么分？” | `μ` 是轴，不是粗细 |
| III 爱与好奇 | “码为什么会自己变？” | 两个引擎：`ν` 与 `κ` |
| IV 群体 | “为什么必须共用？” | 共用不是善意，是账单 |
| V 社会 | “为什么核实追不上？” | 账不在跑的人身上 |
| VI 文明与历史 | “谁在历史里？” | 切线决定谁被写进主角 |
| VII 边界 | “在哪里停？” | 表的边缘，下一本的入口 |

### 11.3 四个人物，一条暗线

老陈（窄而深）、小林（宽而浅）、阿伟（细而不核）、小吴（窄而负责）。他们在每一部分换一次位置：老陈在五金店是细码，到社保窗口是粗码；小林在选题会是细码，在合同上是粗码；阿伟在直播里是细码，在赔偿时是粗码；小吴在诊断上是细码，在政策宣讲上是粗码。**读者在最后一章认出自己站在哪张脸上，而不是被分类。**

### 11.4 真善美

- **真**：每条断言带判决线；每部分最多一处“这条到此为止”；不防御性写作。
- **善**：每个约束章写“谁在承担代价”；不写“他们活该”，写“这笔账记在谁名下”。
- **美**：一个泛函，四个算子，十五个领域，不堆术语；句子短，例子实，转折干净。

### 11.5 逻辑顺序

地基 → 四层 → 四个算子 → 案例 → 预言 → 边界。这个顺序不能换：先有“为什么需要区分”，再有“四层怎么用同一个泛函”，再有“四个位置怎么长出来”，再用案例检验，再用预言判决，最后说边界。把案例放前面会变成散文，把预言放前面会变成宣言。
