## 0 一张图

三个缺口分别对应联合泛函里的三处：

```
F = Σ_i [ w_i(P,A) + ν Σ_j φ_ij w_j ] D_i(q∘Π, μ)
    + (T+λ) R(q)
    + (T_I+λ_I) |I(q)| + w_I D_I(q,I)
    - κ · A(q, q₀; e)
    + γ · qᵀ L(A) q
```

- `w_i(P,A)`：内生价格（缺口 1）；
- `I(q)`：推理代数（缺口 2）；
- `A(q,q₀;e)`：novelty／压缩进展（缺口 3）。

三项都不是新公设；它们是“有限区分”在**价格、推理、创新**三个位置上的展开。

## 1 内生 `w`：`w = w(P,A)` 的不动点

### 1.1 定义

设 `P = (P_1,…,P_k)` 是码在人群中的份额，落在单纯形 `Δ` 上；`A` 是影响矩阵，`A_ij ≥ 0`，`Σ_j A_ij = 1`，`A_ij` 读作“`j` 的选择对 `i` 的错分代价有多大影响”。

取线性响应：

```
w_i(P,A) = w_i⁰ + α (A P)_i − β P_i
```

其中 `(A P)_i = Σ_j A_ij P_j`。

- `α > 0`：**协调／互补**——别人用这套码，我用它的价值上升（网络外部性、共同语言、正统）；
- `α < 0`：**对抗／拥挤**——别人用这套码，我的相对价值下降（军备、竞争、同质化）；
- `β > 0`：**拥挤**——我自己这套码的份额越大，边际价值越低（资源被摊薄）。

这就是“价格随分布变”的最小形式：一个线性响应，两个通道，三个参数。

### 1.2 四个领域的特殊化

| 领域 | `A` | `α` | `β` | `w_i` 读作 |
|---|---|---|---|---|
| 生态 | 斑块连通 | 0 | >0 | 斑块适合度（logistic） |
| 经济 | 网络外部性 | >0 | >0 | 采用某标准的边际收益 |
| 军事 | 威胁邻接 | <0 | >0 | 安全／被打击的代价 |
| 历史 | 联盟／传播 | >0 | >0 | 正当性／被承认的收益 |

四个领域不是四个模型，是同一式的四组符号。**这就是“内生 `w`”的用处：它把“价格”从背景变成了分布的函数。**

### 1.3 不动点

码的分布按复制子方程走：

```
Ṗ_i = P_i ( w_i(P,A) − w̄ ),   w̄ = Σ_j P_j w_j
```

不动点满足：在支撑上 `w_i = w̄`，不在支撑上 `w_i ≤ w̄`。

**命题 1（存在）**：若 `w(P,A)` 连续，复制子方程在单纯形上至少有一个不动点。证明是 Brouwer：右端映射连续，把单纯形映到自身。

**命题 2（唯一／稳定）**：令 `W_P = α A − β I`。若 `W_P` 的谱半径 `ρ(W_P) < 1`，则不动点局部唯一且稳定；若 `ρ(W_P) > 1`，则出现多个不动点或分岔。`ρ(W_P)` 就是“价格反馈”的增益。

**命题 3（迟滞）**：当 `α` 增大或 `β` 减小时，`ρ(W_P)` 穿过 1；系统从唯一均衡进入多稳。此时外部冲击撤去后，系统不回到原点——带宽由换码成本 `2C` 决定。

这三条不是新数学；它们是复制子＋线性响应的标准结论。**但它们把“内生 `w`”从一句愿望变成了可判的条件：看 `ρ(αA−βI)`。**

### 1.4 可判决预言

1. **`w` 随 `P` 变**：控制 `A` 后，`w` 对 `P` 的偏导不应为零。若在生态、经济、军事、历史四个场景里都测不到，内生项就是多余的，退回外生 `w`。
2. **`A` 的外生冲击改变 `w`**：平台改推荐、联盟改通信、关税改网络——`A` 一动，`w` 应当动；`P` 的响应应当有迟滞。
3. **DSH 弃养是分岔，不是线性衰减**：当 `α`（社区协调收益）下降或 `β`（拥挤）上升，`ρ(W_P)` 穿过 1，插件份额从一个稳定点跳到另一个；弃养曲线应当是台阶，不是指数衰减。
4. **军事与生态的符号相反**：同一式，`α` 的符号决定“跟风”还是“对冲”；这是可查的跨域判别。

### 1.5 什么会杀死它

- 若 `w` 对 `P` 的偏导在四个领域都为零，内生项删掉；
- 若 `ρ(W_P)` 永远小于 1，系统没有多稳，迟滞只能来自 `C`，不能来自 `w` 的反馈；
- 若 `A` 不可测，命题 2 只是形式；这时只能写“方向”，不能写“阈值”。

**强度：** 生态／经济是**函子式**；军事是**函子式（有向图）**；历史是**比喻／半形式**。不要把四者说成严格同构。

## 2 语义 `I(q)`：可复合的推理代数

### 2.1 形式背景与概念格

用一个形式背景 `K_q = (G, M, R)`：

- `G`：对象（被分类的事例）；
- `M`：特征／命题；
- `R ⊆ G × M`：对象 `g` 是否具有特征 `m`。

对 `A ⊆ G`，定义 `A' = {m ∈ M : ∀g∈A, (g,m)∈R}`；对 `B ⊆ M`，定义 `B' = {g ∈ G : ∀m∈B, (g,m)∈R}`。

一个**形式概念**是 `(A,B)`，满足 `A' = B`、`B' = A`。所有概念按 `(A₁,B₁) ≤ (A₂,B₂) ⇔ A₁ ⊆ A₂` 构成一个**完全格**（概念格）。

码 `q` 的格 `C_1,…,C_k` 是 `G` 的一个划分；每个格 `C_i` 对应概念格里的一个概念（或一组概念）。**`I(q)` 就是这套划分授权的蕴涵集**：

```
I(q) = { A → B : A, B ⊆ M, 在 K_q 中 A' ⊆ B' }
```

读法：只要对象具有 `A` 里的特征，它就必然具有 `B` 里的特征。`I(q)` 对合取封闭、对蕴涵传递——这就是“可复合”的最小代数。

### 2.2 意义＝`(q, I(q))`

一个码本身不构成意义；意义是“这套划分允许你推出什么”：

```
意义(q) = ( q, I(q) )
理解(q) = 重建 q 与 I(q)
```

同一个 `q`、不同的 `I`，是两个不同的意义。**这就是“同词不同义”的数学位置：不是词变了，是蕴涵集变了。**

### 2.3 复合：推演与拼接

- **推演**：若 `A→B` 与 `B→C` 在 `I(q)` 中，则 `A→C` 在 `I(q)` 中（传递闭包）。
- **拼接**：两套码 `q₁,q₂` 的推理集合并后，取蕴涵的传递闭包；这给出一个可结合的复合 `I(q₁) ⊔ I(q₂)`。它不一定是一个格的正合上确界，但它是**可计算、可比较**的；在需要更强结构时，用概念格的并。
- **翻译**：若 `q₁≠q₂` 但 `I(q₁)=I(q₂)`，则两套码可互译；若 `q₁=q₂` 但 `I(q₁)≠I(q₂)`，则是“假朋友”——同词不同义。

这给出一个 2×2 诊断：

| | `I` 相同 | `I` 不同 |
|---|---|---|
| `q` 相同 | 共享意义 | **假朋友**（同词不同义） |
| `q` 不同 | 可翻译 | 不可通约 |

### 2.4 语义也有预算

`I(q)` 不是免费的：推理要学、要记、要执行。给它两项成本：

```
(T_I + λ_I) |I(q)|  +  w_I · D_I(q,I)
```

`|I(q)|` 是蕴涵条数；`D_I` 是“按这套蕴涵行动却出错”的失真。**语义不是额外的一层，它是预算里的另一笔账。**

### 2.5 可判决预言

1. **同 `q`、不同 `I`，行为分叉**：两套培训材料，类别完全相同，只改“从 A 能推出 B”的规则；若行为不变，`I` 是多余的，按奥卡姆剃掉。
2. **假朋友可测**：两个共同体用同一批词，但蕴涵集不同；跨共同体沟通的失败率应当与 `|I₁ Δ I₂|` 成正比，而不是与词汇差异成正比。
3. **语义预算可测**：`|I(q)|` 越多，学习时间越长；但 `D_I` 越低。最优 `|I|` 随 `w_I/(T_I+λ_I)` 上升。
4. **宗教／法律／艺术**：仪式、法条、流派都可以写成“`q` 相同、`I` 不同”的案例；判决线是“改蕴涵不改类别，行为是否变”。

### 2.6 什么会杀死它

- 若 `I(q)` 在控制 `q` 后对行为没有增量预测力，删掉；
- 若 `D_I` 与 `D` 完全共线，语义只是失真的另一种写法，不必单列；
- 若概念格在所有案例里都退化为一个概念，`I` 是空的。

**强度：** 语言学／法律是**函子式**；宗教是**半形式**；艺术是**比喻**。`I(q)` 能说“意义的结构”，不能说“审美体验”。

## 3 novelty `κ`：压缩进展与 Wundt 曲线

### 3.1 为什么“信息增益”不够

`κ·IG` 只说“减少不确定性有收益”，说不出“为什么有些新东西被保留，有些被扔掉”。艺术、科学、好奇的共同点不是“新”，是**新得可压缩**：新码必须把旧经验压缩得更好，否则只是噪声。

### 3.2 定义

设 `q₀` 是当前码，`q` 是候选码。定义：

- **压缩进展**：`C(q,q₀) = L(q₀) − L(q)`，`L` 是描述长度（MDL）；`C>0` 表示新码更省。
- **新颖距离**：`N(q,q₀) = 1 − |q ∩ q₀| / |q ∪ q₀|`（Jaccard 距离；也可用分区的传输距离）。
- **审美值**：

```
A(q,q₀) = C(q,q₀) − ρ · N(q,q₀)
```

第一项是“更省”，第二项是“太陌生要付的理解成本”。`ρ` 是理解成本系数。

- **Wundt 曲线**（可选的非线性版）：

```
A(N) = N · exp(−N/N₀)
```

它先升后降：太熟＝无聊，太陌生＝看不懂。`N₀` 是“最能被接受的新颖度”。

### 3.3 创新阈值

采纳新码的条件：

```
F(q) − F(q₀) + κ · A(q,q₀)  >  C_switch
```

即：

```
A(q,q₀) > (C_switch − ΔF) / κ
```

- `κ` 越大，越愿意为“新”付钱；
- `C_switch` 越大，越需要新码“更省”或“更有审美值”；
- `A` 是倒 U，所以存在一个**最优新颖度** `N*`：太熟不采纳，太陌生也不采纳。

### 3.4 艺术、科学、好奇

- **艺术**：`κ_art` 高、`ρ` 中；作品的成功应当与“相对流派的中间新颖度”相关，而不是越新越好。可查：用流派距离做 `N`，用观众/评论做成功度。
- **科学**：`κ_sci` 中、`ρ` 高（理解成本高）；论文的影响应当与“重组度”呈倒 U。可查：参考文献组合的新颖度 vs 引用。
- **好奇**：`κ` 是学习进展的权重；`A` 的压缩进展项就是“学到了”。`T` 越低，`κ` 越能起作用。可查：先验不确定性 vs 探索时间，倒 U。
- **被埋没的理论**：`SleepingResidue` 的“解码器”不是提高 `κ`，是**降低 `ρN`**——新工具让旧理论变得可理解。所以“重新发现”不是审美变了，是理解成本降了。

### 3.5 三者：审美判断、创造、保留

`κ` 不能只写成一个权重。要让它能描述社会与文明现象，至少要有三件东西：**怎么判断“好”**、**怎么生成“新”**、**为什么“新”被留下**。

#### 3.5.1 审美判断：压缩 × 连贯 × 新颖

设 `q₀` 是当前码，`q` 是候选码，`e` 是环境。

- **压缩**：`C(q) = max(0, L(q₀) − L(q))`，`L` 是描述长度（MDL）；
- **连贯**：`K(q) = exp(−D_I(q,I(q)) / D_I^max)`，`D_I` 是推理违例的代价；
- **新颖**：`N(q,q₀) = d(q,q₀)`，`W(N)=N·exp(−N/N₀)`（Wundt 曲线）。

审美值取**乘积**：

```
A(q;q₀,e) = C(q) · K(q) · W(N(q,q₀))
```

乘积不是修辞：三项缺一，审美值为零。

- 只有压缩、没有新颖 → 旧码的复述，不叫美；
- 只有新颖、没有压缩 → 噪声，不叫美；
- 只有压缩与新颖、没有连贯 → 看不懂，也不叫美。

**这就是“美＝可压缩的新，且能自洽”的数学写法。** 它不是审美哲学，是一个可测的三因子模型：`C` 可用模型/压缩器估，`K` 可用推理违例数估，`N` 可用分区距离估。

#### 3.5.2 创造：四种生成算子

新码不是从天上掉下来的。给它一个生成语法 `G = {R, A, M, L}`：

| 算子 | 动作 | 例子 | 成本 |
|---|---|---|---|
| **R 重组** | `q' = q_i ⊕ q_j`，把两套码的格/特征拼起来 | 爵士＝蓝调＋欧洲和声；板块构造＝大陆漂移＋海底扩张 | 中 |
| **A 类比** | `q' = F(q)`，从另一个领域搬一个函子 | 把“市场”搬到“婚姻”；把“生态”搬到“平台” | 中—高 |
| **M 变异** | `q' = q ⊕ ε`，局部改一格 | 新词、新规格、新仪式细节 | 低 |
| **L 松弛** | `q' = q \ {约束}`，丢掉一条约束 | 朋克丢掉技术门槛；现代艺术丢掉再现 | 低—中 |

生成概率：

```
Pr(q' | q₀) ∝ Σ_g π_g · exp(−c_g) · 1{ q' ∈ G_g(q₀) }
```

`π_g` 是某个领域的先验（科学偏 `R/A`，艺术偏 `M/L`，制度偏 `R/L`），`c_g` 是生成成本。**这条式子解释“为什么创新总是组合式的”：不是人只会组合，是 `R` 的成本最低、先验最高。**

#### 3.5.3 保留：选择与扩散

一个新码被保留，要过两道：

**个体采纳**：

```
Pr(adopt) = σ( β [ F(q) − F(q₀) + κ·A(q;q₀,e) − C_switch ] )
```

**群体扩散**：采纳之后，码的份额按复制子走，`w = w(P,A)`：

```
Ṗ_i = P_i ( w_i(P,A) − w̄ ) + μ (生成项)
```

`A` 在这里有两个身份：它既进 `w(P,A)`（价格），又进 `qᵀL(A)q`（一致性）。**同一个网络，既是价格，也是约束。** 这就是“为什么偏离能被保留”的完整答案：不是因为它新，是因为它同时过了**审美判断**、**个体采纳**、**群体扩散**三关。

#### 3.5.4 三者合起来：novelty loop

```
q₀ → G → q → A(q;q₀,e) → Pr(adopt) → P → w(P,A) → q₀'
```

这是一个**变异—判断—选择**的闭环。它把“创造”从灵感变成了三个可测的环节：

- 生成：`G` 的四种算子，哪个被用得多；
- 判断：`C、K、N` 三个因子，哪个是瓶颈；
- 保留：`κ`、`C_switch`、`A` 网络，哪个在挡路。

#### 3.5.5 真实案例：不是球形鸡

| 案例 | 生成 `G` | 审美判断 `A` | 保留 |
|---|---|---|---|
| **爵士** | `R`：蓝调＋欧洲和声 | 压缩高（即兴空间大）、连贯中、`N` 中 | 俱乐部—唱片—电台网络 |
| **朋克** | `L`：丢掉技术门槛 | 压缩低、连贯高、`N` 高 | 场景／DIY 网络，`C_switch` 低 |
| **哥白尼** | `A`：日心类比；`R`：本轮＋观测 | 压缩高（行星运动更省）、连贯高、`N` 高 | 天文共同体＋仪器；`ρ` 随时间下降 |
| **板块构造** | `R`：大陆漂移＋海底扩张 | 压缩高、连贯高、`N` 中 | 数据（古地磁、洋中脊）＋共同体 |
| **文字** | `M/R`：记号系统 | 压缩高（外置记忆）、连贯高、`N` 高 | 官僚／祭祀／贸易网络 |
| **DSH 插件** | `R/M`：记忆＋行为模块 | 压缩中、连贯低、`N` 高 | 平台反馈＋人类投喂；弃养＝`ρ` 升或 `A` 断 |

**这张表是判决表，不是装饰。** 每个案例都要能指出：用了哪个生成算子、三个审美因子里哪个是瓶颈、保留靠哪个网络。指不出的，案例就不算用上了模型。

### 3.6 可判决预言

1. **倒 U**：艺术／科学／好奇三个场景里，成功度对新颖度应当是倒 U，不是单调。
2. **κ 可操纵**：提高 `κ`（奖励探索）应当让最优 `N*` 右移；提高 `ρ`（提高理解成本）应当让 `N*` 左移。
3. **压缩进展可测**：新码的 `L(q)` 应当比旧码低；若新码只是“不同”而不“更省”，它不会被保留。
4. **被埋没的理论**：解码器出现后，`ρ` 下降，旧理论的“审美值”上升；不需要假设“真理终将被承认”。

### 3.7 什么会杀死它

- 若成功度对新颖度单调（没有倒 U），Wundt 项错，退回线性 `κ·IG`；
- 若 `κ` 与 `w` 不可分（探索收益与错误代价完全共线），`κ` 不是独立偏好，删掉；
- 若 `L(q)` 不可估，`C` 只是隐喻；这时只能写“方向”，不能写“阈值”。

**强度：** 科学是**函子式**；艺术是**比喻**；好奇是**半形式**。`A` 能说“为什么中间新颖度最容易被接受”，不能说“为什么这一笔是美的”。

---

## 4 三项怎么接进联合泛函

```
F = Σ_i [ w_i(P,A) + ν Σ_j φ_ij w_j ] D_i(q∘Π, μ)
    + (T+λ) R(q)
    + (T_I+λ_I) |I(q)| + w_I D_I(q,I)
    - κ · A(q, q₀; e)
    + γ · qᵀ L(A) q
```

约束：

```
w = w(P,A),  P = BR(w)  （复制子不动点）
I = I(q)                （概念格蕴涵集）
A = C(q,q₀) − ρN(q,q₀)  （压缩进展 − 新颖成本）
```

这三项让泛函从“给定价格选码”变成“价格、意义、创新一起定”。句法上，每个符号都有定义；经验上，每一项都有一个可测代理。**这就是“句法完备”的意思，不是“全都算得出”。**

## 6 一句话

**内生 `w` 让价格变成分布的函数；`I(q)` 让意义变成可复合的蕴涵集；`κ` 让创新变成“压缩进展减理解成本”。** 三项都写完，第二版的句法骨架就闭合了；经验上仍然开放，这是它该有的样子。
