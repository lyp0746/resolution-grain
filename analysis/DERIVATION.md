# 从第一性原理到可用模型：一次完整推导与可识别性审计

> 目的：把对话里 27 轮的公式串成一条链，标出**哪一步是推导、哪一步是建模选择、哪一步是事后拟合**。
> 结论先说：链条有 5 步，2 步是公设；3 个参数只能识别比值；4 个参数目前是事后拟合。
> 这不是否定模型，是给它划出"能主张 / 不能主张"的边界。

---

## 0 链条全图

```
公设        约束自由能 F[K] = 预测误差 + λ·能量代价 − T·熵
  │
推导 ①      个体核：二次代价 + 高斯似然 ⇒ K* = N(μ, v),  v = T/(λc'')
  │
公设 ②      群体势：G = ∫F dP − E[π_S] + τ·D_KL(P‖P₀)        ← 强假设
  │
推导 ③      群体演化：∂ₜP = ∇·[P∇(F − π)] + TΔP              ← 需修正 π 的定义
  │
选择 ④      策略集 {C, H, A} + softmax + 三个无量纲数
  │
公设 ⑤      E_t, θ_t, π_L, μ_R 各自带方程（不从前四步导出）
```

**关键判断**：这不是"一个公式推出一切"。它是**一个个体层推导 + 一个群体层势函数 + 四个外生状态变量**的耦合系统。把它说成"单一第一性"会过度承诺。

---

## 1 第一性：约束自由能（公设，不是推导）

$$\mathcal{F}[K]=\underbrace{\mathbb{E}_{q}[-\log p(S\mid K)]}_{\text{预测误差}}+\underbrace{\lambda\,\mathbb{E}_{K}[c(x)]}_{\text{能量代价}}-\underbrace{T\,H(K)}_{\text{探索熵}}$$

**三项的来历**：第一项是交叉熵（标准），第二项是约束（拉格朗日乘子的常规用法），第三项是熵正则（最大熵文献的常规用法）。每一项都常见，**三者的加权组合是一个建模选择**，不是从更基本的东西推出来的。

**必须写清的两件事**

1. **与 Friston 的关系**：Friston 的变分自由能是 ELBO，关于**隐状态的后验**；这里的 F 是关于**响应核**的变分，是行为动力学版本。二者共享"最小化自由能"这个名字，但不共享数学对象。不写清这句，等于把最大的合法性来源变成最大的误读入口。
2. **量纲**：`−T·H(K)` 中 H 以 nat 计，λ·c 以"代价"计。因此 **T 的单位必须是"每 nat 的代价"**，否则三项不能相加。文档里 T 被叫作"情绪温度"，从未给单位——这是一个必须补的定义。

## 2 个体层：唯一一段真正可推的（推导 ①）

**假设**：`c(x) = c₀ + ½c''(x−x₀)²`；似然 `p(S|K)` 对 K 为高斯；K 取高斯族 `N(μ,v)`。

**文档里的写法**（只对"能量代价"与"熵"两项配平，略去数据项）：

$$v^{*}=\frac{T}{\lambda\,c''}$$

均值由数据项决定：`μ* = argmin E_q[−log p(S|N(μ,v))]`，即响应峰落在信号最密处。

**把推导做完整，文档的公式差一项。**

把 K 读作"预测分布"（`p(S|K)=K(S)`），令 `D ≡ σ_s²+(μ−μ_s)²`（信号本身的方差加峰位错配），则

$$\mathcal{F}(v)=\tfrac12\log(2\pi v)+\frac{D}{2v}+\lambda\Big(c_0+\tfrac12c''v\Big)-\frac{T}{2}\log(2\pi e v)$$

令 `∂F/∂v=0`，得到二次方程

$$\lambda c''v^{2}+(1-T)v-D=0$$

$$\boxed{\,v^{*}=\frac{(T-1)+\sqrt{(T-1)^{2}+4\lambda c''D}}{2\lambda c''}\,}$$

**三条后果：**

1. **文档的 `v=T/(λc'')` 是 `D→0` 且把熵常数并入 T 的极限。** 更准确的形式是 `(T−1)`，那个 1 来自高斯归一化，不是笔误。
2. **`v` 随信号模糊度 D 上升。** 这是原公式没有的一个**新可检验预言**：同一批人看模糊信号时核更宽、看清晰信号时更窄。原公式说 `v` 只由人决定，与刺激无关——这一条可以直接用实验否证。
3. **`T` 与 `λc''` 在单一情境下不可分，在跨情境下可分。** 令 D 变化两次，得到两个方程，就能解出两个未知数：

$$\lambda c''=\frac{D_2v_1-D_1v_2}{v_1v_2(v_2-v_1)}\;(>0),\qquad T=1+\lambda c''v_1-\frac{D_1}{v_1}$$

> 所以正确的说法不是"只有比值可识别"，而是：**单一情境只有组合可识别；改变信号模糊度 D 之后，T 与 λc'' 可以分开。**

文档里"用睡眠债校准 λ、用探索性量表校准 T"之所以在数学上站不住，是因为它没有改变 D——没变 D，就只有一个方程。

## 3 群体层：一个势函数，但有两处漏洞（公设 ② + 推导 ③）

$$\mathcal{G}[\sigma,P]=\int\mathcal{F}\,dP-\mathbb{E}_{\sigma,P}[\pi_S]+\tau D_{\mathrm{KL}}(P\|P_0)$$

**漏洞一：这是"位势博弈"假设，不是定理。**
把个体自由能与发送端收益放进同一个泛函并要求鞍点，等价于假设两者可以互相抵消。只有当**接收端的收益恰好等于发送端收益的负值**（零和）时，这个写法才自洽。真实的舆论套利是正和（平台赚流量、接收端得到情绪），所以严格说 `G` 不是一个势函数，只是一个"伪势"。
**处理**：要么明确写出"假设零和"，要么把 `G` 改成双层：发送端最大化自己的 π_S，接收端最小化自己的 F − π_R，二者通过市场出清耦合。后者更接近真实，也更难算。

**漏洞二：`∇(F − π_S)` 里 π_S 的自变量错了。**
π_S 是发送端的收益，取决于策略 m 与接收端核 K 的**匹配**，不直接是 K 的函数。写成对 K 的梯度，等于假设发送端能对每个 K 单独定价。
**修正写法**：引入接收端收益 `π_R(m,K)`，演化写成

$$\partial_t P=\nabla_K\cdot\Big[P\,\nabla_K\big(\mathcal{F}-\mathbb{E}_{m\sim\sigma}\pi_R(m,K)\big)\Big]+T\Delta_K P,\qquad \sigma^*=\mathrm{BR}(P)$$

这样两层通过 `σ*` 与 `P` 的不动点耦合，而不是通过一个共享的标量势。**这是链条上第一个必须补的推导。**

## 4 参数模型：能算，但有两处量纲错误（选择 ④）

**三策略收益**

$$\pi(C)=\beta E_t b\,h_C-(1-q_C)p,\qquad q_C=1-e^{-\tau_C/\phi_C}$$

**错误一：`τ/φ` 量纲不成立。** τ 是时间（天），φ 是"识破难度"（无单位或成本），二者不能相除。
**修正**：把 φ 重新定义为**"识破所需的特征时间"（单位：天）**，而不是"难度"。则

$$q=\frac{\phi}{\phi+\tau}\quad(\text{单调、有界、量纲一致})$$

极限检查：`τ→0 ⇒ q→1`（即时核实）；`φ→∞ ⇒ q→1`（无法伪造）；`φ→0 ⇒ q→0`（一眼假但没人查）。三条都对。

**代入后得到一个更干净的形式**：

$$\Pi_C=\frac{\beta E_t b h_C}{(1-q_C)p}=\frac{\beta E_t b h_C}{p}\left(1+\frac{\phi_C}{\tau}\right)$$

> **套利利润 = 单位流量收益 × (1 + 识破时间 / 核实延迟)。**

这个形式直接给出可检验的比较静态：惩罚 `p` 抬升只压前因子；`φ` 与 `τ` 的比值才是"窗口"本身。美国侧实测 `τ=6 天`，若 `φ≈τ`，则窗口因子约 2——**不是"无人核实"，而是"核实慢两天"**。

**错误二：softmax 的温度 θ 与自由能的 T 用了同一个字母族。** 选择强度 θ 与情绪温度 T 是两个东西，文档里符号混用。**改名为 κ 或 β_s。**

**三个无量纲数**（结构正确，值得保留）

$$\Pi_C=\frac{\beta E_t b h_C}{(1-q_C)p},\qquad \Pi_H=\frac{\beta E_t b h_H}{(1-q_H)p},\qquad \Phi=\frac{\kappa\Delta_A}{\phi_0}$$

阈值 `Π=1` 的推导是对的：策略份额 `s(m) ∝ exp(θπ(m))`，当且仅当 `π(H) > π(C)` 时 H 份额上升，即 `Π_H > Π_C`；`Π` 穿 1 只是"净收益为零"的记账线。**这一条可以保留。**

## 7 事后拟合清单（必须降级或删掉）

按严重程度：

1. **`α<1`**：已实测，CI 横跨 0 到 0.8。**降 C 级情景假设。**
2. **`Φ`（技术弹性）**：无估计，且完整 GDELT 显示 +40% 而非爆炸。**"套利端比模型更灵活"应改成"未观测到指数级上升"。**
3. **`δ`**：完全没有。而 `E_t` 的动力学整个依赖它。**这是最脆弱的一环**：E_t 是模型的核心状态，却没有任何一条方程的参数被估计过。
4. **`θ_c`**：为了让"塔西佗陷阱"成立而设的阈值。没有任何独立测量。
5. **`h_C / h_H`**：命中率没有定义也没有测量。
6. **`π_renqing`**：来自一个县的单案例，却被写成社会级参数。
7. **"吸收态 vs 临界慢化"二分**：美国数据已经推翻了原版"接近阈值 → 慢化"的预测，改成"已锁定 → 刚性"是事后修正。

## 9 结论：模型现在能主张什么

**能主张（A/B 级）**
- 表征轴 + 核 + 匹配的结构，能解释"同一人不同场景落入不同标签"。
- 三个无量纲数（`Π_C, Π_H, Φ`）的存在，以及"惩罚只动 p、不动 ρ"这一条政策判断。
- 美国侧 `θ` 的锁定（28%）与代际迟滞，有数据。
- 规则形式化不是现代现象（Seshat，−2700 起），两条线**一起跳**（p<0.01）。

**不能主张（C 级或不可识别）**
- `α<1` 的加速耗竭（CI 跨 1）。
- `Φ` 的具体大小、`θ_c` 的位置、`Π` 的数值阈值。
- "单一第一性导出一切"——个体核是推导的，群体是公设的，`E_t/θ/π_L` 是外加的。

**一句话**：这是一个**骨架清楚、肌肉未长**的模型。骨架够写方法论文；肌肉（`δ, α, κ, θ_c`）要等上面第 1—3 项数据。在那之前，任何"三十年预测"都应写成情景，不写成结论。

## 10 可以补上的第一性：率—失真（rate–distortion）

前面说"F 是公设"。这个判断可以再往下一层——**F 不是公设，它是有限分辨率编码问题的拉格朗日量。**

### 10.1 更底层的那句话

> **任何有限分辨率的编码器，都在解同一个问题：在码率约束下最小化失真。**

这是香农率—失真定理的内容（不是假设）：给定信源与失真度量，存在率—失真曲线 `R(D)`；任何最优编码器都落在这条曲线上。写成拉格朗日形式：

$$\min_{q}\ \underbrace{w\,D(q)}_{\text{失真}}+\underbrace{\lambda\,c(q)}_{\text{分辨率的代价}}+\underbrace{T\,R(q)}_{\text{码率的价格}}$$

三项各有明确身份：**失真**（目标）、**分辨率成本**（约束）、**码率价格**（乘子）。文档里的 `F` 就是它的特例——所以"三项加权是任意选择"这个批评，在更底层不成立。

### 10.2 一推就得到核，而且比原来干净

取高斯信源、高斯编码器 `q=N(0,v)`：`D=v`，`R=½log(σ²/v)`。求驻点：

$$w+\lambda c''-\frac{T}{2v}=0\ \Longrightarrow\ \boxed{\ v^{*}=\frac{T}{2\,(w+\lambda c'')}\ }$$

比 `v=T/(λc'')` 干净：多了 `w`（对准确度的在意程度），少了那个来源不明的 `−1`。三项各自可解释、可操纵。

### 10.3 方向性：只靠符号，不需要数值

对 `v*` 求偏导，全部是单调的：

| 变化 | 对 `v` 的符号 | 直觉 | 可否证方式 |
|---|---|---|---|
| 码率变便宜（`T↑`） | **+** | 有闲工夫就看得更细 | 给时间/带宽，核应变宽 |
| 更在意准确（`w↑`） | **−** | 怕错就收窄 | 提高利害，核应变窄 |
| 分辨率变贵（`λc''↑`） | **−** | 累的时候只能粗看 | 睡眠债→核窄（有实验支持） |
| 信号变模糊（`D↑`） | **+** | 看不清就只能摊开 | 模糊刺激→响应变宽 |
| 群体分辨率↑（教育） | 失真 **−** | 编码细，误解少 | ESS8：教育解释力是年龄的 20—230 倍 |

这五条**只要符号对**就算过，不需要 `α、δ、κ` 那些测不出的量。

### 10.4 "分辨率"的两层意思，正好接上

1. **个体的分辨率** = `v`。这是模型里的核宽。
2. **我们描述系统的分辨率** = 粗粒化层级。个体是快变量，`E_t、μ_R` 是慢变量；对快变量做**绝热消去**（adiabatic elimination），就得到群体方程。这才是"个体是 δ 峰、群体是分布"的正当理由——它是同质化极限，不是比喻。

### 10.5 这一步换来了什么，没换来什么

**换来**：F 从"公设"升为"定理的拉格朗日量"；`v*` 有了三个可解释的参数；五条符号预言，全部可否证；粗粒化有了数学依据。

**没换来**：`δ、α、κ` 仍然测不出；内容（哪条规则）仍然推不出；规范问题仍然不处理。
**代价**：多了一条假设——"心智接近最优编码器"（efficient coding hypothesis，Barlow 1961；Wei & Stocker 2015）。定理只管编码界，不管心智是否真的贴着界走。这条假设可以被证伪：若人的响应系统性偏离 R–D 曲线，框架就倒。

**一句话**：第一性不在 `F`，在 `F` 下面那一层——**有限分辨率下的率—失真最优化**。它给的是符号，不是数值；要的也正是符号。
