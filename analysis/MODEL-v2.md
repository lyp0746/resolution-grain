# 模型 v2：从率—失真到三层动力学

> 相对 v1 的三处改动：① `F` 改为率—失真拉格朗日；② `v*` 换成 `(T+λ)/(2w)`（修掉疲劳的符号错误）；
> ③ 承认文档里其实有**两个 `v`**，本文件只处理其中一个。

---

## 1 第一性方程

$$\min_{q}\ \underbrace{w\,D(q)}_{\text{失真}}+\underbrace{(T+\lambda)\,R(q)}_{\text{码率的总价格}}$$

- `D(q)`：编码失真（规则被理解成什么 vs 它是什么）
- `R(q)`：码率（分辨率越高越贵）
- `w`：对准确度的加权（利害、在意程度）
- `T`：带宽价格（时间、注意力）
- `λ`：认知成本（疲劳、负荷）

高斯信源、高斯编码 `q=N(μ,v)`：`D=v`，`R=½log(σ²/v)`。求驻点：

$$w-\frac{T+\lambda}{2v}=0\quad\Longrightarrow\quad\boxed{\,v^{*}=\frac{T+\lambda}{2w}\,}$$

**这一步修掉了 v1 的符号错误。** v1 的 `v=T/(λc'')` 说"疲劳 → 核变窄"；实验（睡眠剥夺 → 常规隐喻↑、新颖隐喻不变）说的是"疲劳 → 处理变粗"。`v*=(T+λ)/(2w)` 与实验同向：**`λ↑ ⇒ v↑`（变粗）**。

---

## 2 一个必须承认的问题：文档里有**两个 v**

| | v1 的 `v` | v2 的 `v` |
|---|---|---|
| 是什么 | 响应核在**抽象度轴**上的宽度 | 编码在**信号空间**上的分辨率 |
| 大 = | 对很多抽象层级都起反应 | 码粗、失真大 |
| 小 = | 只对很窄的一段起反应 | 码细、成本高 |

这两个不是一回事。文档把它们当同一个用了：
"老辈子型 = 窄核" 用的是第一个；"信息容量小" 暗示的是第二个。

**本文件只处理第二个。** 第一个（调谐宽度）需要另一个方程，暂缺。
这是 v2 最大的未解问题，不是可以糊过去的技术细节。

---

## 3 个体层：五个状态变量

| 变量 | 含义 | 方程 |
|---|---|---|
| `v_i` | 码的分辨率 | `dv/dt = η_v[(T+λ)/(2w) − v]` |
| `μ_i` | 码的中心 | `dμ/dt = η_μ (x_s−μ) e/(v+ε)` |
| `w_i` | 在意准确的程度 | `dw/dt = α_w[stakes_i − w_i]` |
| `λ_i` | 认知成本 | `dλ/dt = α_L (L_i − R_i)` |
| `T_i` | 带宽价格 | 慢变量，视为外生 |

**关键结构**：`w` 是**状态**，不是常数。它随"后果"更新——这就是"利害"进入模型的方式。

**驻点**：`v* = (T+λ)/(2w)`；`μ*` 在信号最密处；`w*` 在 stakes 的水平上。

---

## 4 群体层：分布的漂移 + 一个未定价的外部性

$$\partial_t P_t(v,w)=-\partial_v\!\left[P_t\,\eta_v\!\left(\frac{T+\lambda}{2w}-v\right)\right]+\partial_w\!\left[P_t\,\alpha_w(w-\text{stakes})\right]+D_v\,\partial^2_{vv}P_t$$

发送端：`max_m π_S(m) − c(m)`，`π_S` 随"信号与接收端码的匹配"上升。

**核心**：接收端承担的失真 `D` 没有价格。发送端只需要自己的信号"能匹配粗码"，不需要它"准确"。
这是**外部性**，不是博弈技巧。原文的 `Π = βEbh/[(1−q)p]` 是它的一个特例记账式。

**福利含义**：社会最优要求给 `D` 定价（标注、摩擦、降权）；只封号（`p`）只让发送端换一个码。

---

## 5 社会层：四个慢变量

| 变量 | 含义 | 方程 |
|---|---|---|
| `w̄_t`（= 原 `E_t`） | 群体的平均在意程度 | `dw̄/dt = −δ s(C) w̄ + ρ(1−w̄)`（**无 α**） |
| `μ_R,t` | 规则谱的抽象度 | `dμ_R/dt = χ(μ̄−μ_R) − ψ π_renqing μ_R + ω q_tech μ_R` |
| `θ_t` | 制度信任 | `dθ/dt = η q [1−θ]`，`θ_c = f(w̄ D̄/τ)` |
| `π_L,t` | 标签使用 | **读数**：`π_L ≈ g(v̄)`，`v̄ > v_c` 时标签变便宜 |

**三处简化**：`α` 删了（`w̄` 单调下降即可）；`π_L` 从状态降为读数；`θ_c` 从外生变为推导。

## 6 相空间

**个体/群体切片**：`(w, T+λ)` 平面。等分辨率线是双曲线 `T+λ = 2w·v`。

```
  T+λ 高 ┌───────────────┐
         │  粗码区        │  ← 疲劳、时间紧、不在意
         │  (v 大、失真大) │
         ├───────────────┤
         │  精编区        │  ← 有闲、在意、低负荷
         └───────────────┘
            w 低        w 高
```

图：`analysis/figures/phase_w_T.png`

**社会切片**：`(w̄, τ)` 平面。
- `w̄` 低 + `τ` 长 → 套利持续 → 标签稳态
- `w̄` 高 + `τ` 短 → 核实便宜 → 可信稳态
- `w̄` 低 + `τ` 短 → 强制核实，但失真仍高 → 高摩擦稳态（成本外部化）

**临界线**：`w̄ · D̄ = τ · c_ignore`（信任崩塌线）。左侧信任维持，右侧进入吸收态。

## 7 证否条件：文献里找到了什么

**① 真反例：动机性知觉（motivated perception）**
Ditto、Kunda 一系（"Motivated perception of probabilistic information" 2014；"Whites' Motivated Perceptions of Racial Privilege" 2007，244 引）：
人**不**最小化准确度失真，而是最小化**效用加权**的失真——看见自己想要的。
→ 这是对"`w` 只关心准确"的直接反例。
→ **修法**：让 `D` 变成效用加权误差，`w` 随结果符号变化。这样**顺带推出损失厌恶**（损失域的 `w` 更高）——比 v1 的"窄核边界偏置"干净得多。
→ 状态：**框架可吸收，但"准确度失真"的版本被否**。

**② 假反例（已在文献里被解决）：反贝叶斯错觉**
Wei & Stocker 2015（419 引）"A Bayesian observer model constrained by efficient coding can explain 'anti-Bayesian' perceptual illusions"：
看似偏离贝叶斯最优的知觉偏差，**恰是率—失真约束的预言**。
→ 这不是反例，是支持案例。
→ 但它也划了边界：率—失真解释的是**偏差的方向**，不解释具体大小。

**③ 边界条件（零结果）**
"Cognitive load does not increase reliance on speaker information in phonetic categorization"（2022）：
负荷并不总让人变粗——**域依赖**。
→ `λ↑ ⇒ v↑` 不是普适律，只在"需要主动维持精细码"的任务上成立。
→ 预注册时必须限定域，不能写成全局。

**④ 支持性证据（顺带）**
- Schwabe & Wolf 2010（208 引）：应激 → 习惯压过目标导向。`λ↑ ⇒ 粗码` ✓
- "Habits under stress" 2017（133 引）✓
- 社会分类在认知负荷下加剧（1999）✓

## 8 统摄：换成 `(w, T+λ)` 之后

| 理论 | 在 v2 里的位置 | 是推导还是翻译 |
|---|---|---|
| 理性选择 | `w→∞`（零失真容忍）、`T+λ→0` ⇒ `v→0` | 极限，可写 |
| 前景理论 | `w` 在损失域更高（动机性知觉的修法） | **可推**（新） |
| 双加工 | 系统2 = 低码价 + 高 w；系统1 = 高码价 + 低 w | 参数区域，半推 |
| 习惯 | `w→0` + `λ` 高 ⇒ 粗码、线索触发 | 半推（需定义"线索"） |
| 布迪厄惯习 | 场域设定 `w` 与 `λ` | 翻译 |
| 沉默螺旋 | `w` 含社会赞许项，失真变成效用加权 | 需加项 |
| 阈值模型 | 粗码 = 离散类别 ⇒ 自然产生阈值动力学 | **可推**（新） |

**新变化（2026-11-16 二修）**：把"统摄"当**推导**逐条兑现后，**12 条里 8 条可推**：

| 升为可推的 | 怎么推 | 多给的预言 |
|---|---|---|
| 概念拉伸（Sartori） | `δ=Δ/2^R` 求导：`∂δ/∂Δ>0` | 外延扩 m 倍要补 `log₂m` 比特，否则退化为标签 |
| 泛化定律（Shepard） | 异质高斯码求和 ⇒ 指数尾 | 群体梯度尾部指数 `b` 是宽度异质性 `k` 的单调函数 |
| 谣言公式（Allport–Postman） | `w·D/v` 就是 `重要性×模糊性÷批判能力` | `c` 可被 `T+λ` 操纵：疲劳提高谣言强度 |
| 国家简化（Scott） | 国家的 `w` ≠ 公民的 `w` ⇒ 外部性 | 可治理性↑ ⇒ 公民侧失真↑、国家侧↓ |
| 建构水平（CLT） | 远距离细码成本↑ ⇒ 最优码上移 | 抽象度**先升后崩**：末端掉进标签，不只"升" |

## 8b 两个 `v` 的解法：同一个码率预算的两种花法

把码写成两个数：**支撑宽度 Δ**（能覆盖多少抽象层级）与**档内分辨率 δ**（档内分得多细）。
固定码率 `R` 时，三者绑死：

$$\delta=\frac{\Delta}{2^{R}}\quad\Longleftrightarrow\quad R=\log_2\frac{\Delta}{\delta}$$

失真 = 档内量化误差 `δ²/12` + 档外漏掉的代价 `(|x−μ|−Δ/2)²`。

**这直接解掉了两个 v 的矛盾：**

| 省码率（疲劳、时间紧）时 | 结果 | 对应文档里的 |
|---|---|---|
| 环境**窄**（信号集中） | 缩 `δ↑`，支撑不变 | "弥散、低幅"——**变粗** |
| 环境**宽**（信号分散） | 缩 `Δ↓`，只守最密的一段 | "窄峰、高幅"——**变窄** |

> **同一次"没力气"，在宽环境里表现为隧道视野，在窄环境里表现为糊成一片。**

这就是为什么睡眠剥夺实验看到"处理变粗"，而文档的"老辈子型"看起来"核很窄"——**不是两种人，是同一种节省在两种环境下的两种分配。**

**三条新预言**

| # | 预言 | 检验 |
|---|---|---|
| T1 | 疲劳 × 宽环境 ⇒ 支撑变窄（隧道），峰变尖 | 2×2：负荷 × 环境宽度 |
| T2 | 疲劳 × 窄环境 ⇒ 分辨率变粗，峰变钝 | 同上 |
| T3 | 专家（Δ 小）的跨域迁移成本更高 | 跨域任务 |

## 8c 漏掉的祖先：理性疏忽（rational inattention）

这一步必须写明，否则会被审稿人一句话打死：

> **`min wD + (T+λ)R` 就是 Sims (2003) 的理性疏忽模型。**
> 不是新的第一性，是一个已有第一性在社会规则上的应用。

Sims 的设定：行为人通道容量有限，选择把注意力分配给哪些信号——正是上面的式子。
差别只在：本框架把"信号"定为**规则**，把"失真"定为**规则被理解成什么**，并加了分类/标签这一层。

**这不削弱它，反而救它**：
- 有了文献锚点（Sims 2003；Maćkowiak & Wiederholt 的经济应用；Barlow/Wei–Stocker 的知觉应用）
- 新颖性收到一个诚实的位置：**不是新原理，是新应用**（规则、分类、代际）
- 可借用的工具：理性疏忽有一整套现成的识别策略与实验范式

**同一层还有三个可统摄但文档没提的**：
- **建构水平理论（CLT, Trope & Liberman）**：心理距离 → 抽象水平。这就是 `μ` 轴，已有大量实验。
- **原型/基本层次范畴（Rosch）**：原型 = 码的中心，基本层次 = 最优粗码——可直接从 R-D 推出。
- **信号检测论（SDT）**：`d' ~ 1/√v`，判据 ~ 先验；SDT 是 `v` 与 `μ` 的一个特例。
