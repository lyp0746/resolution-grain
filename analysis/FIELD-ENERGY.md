# 场能模型：同化、品味与文明特质的统一写法

> 2026-11-19。**设计稿，不是正文，不是读数。**
> 用途：把“同化／品味／文明特质”放进同一个能量函数里；**不是电磁场**，是图上的标量场。
> 状态：C 级形式类比；最小模拟已跑（`SIM-FIELD-ENERGY.md`），只支持方向，不支持量级。

---

## 0 一句话

**同化与品味可以是同一个自由能的两个参数区：** `h` 高、`γ` 低 → 均匀（同化）；`h` 低、`γ` 高、双井 → 分相（品味）。  
这比“同化一个模型、品味一个模型”少一套装置；代价是要多一个势函数 `V(φ)` 与一个可测的场变量 `φ`。

---

## 1 方程

设 `φ_i` 是 agent `i` 的码位置（风格、变体、`μ`；可标量，也可向量）。图 `A` 是关系网。定义能量：

```
E[φ] = (γ/2) Σ_ij A_ij (φ_i − φ_j)^2 + Σ_i V(φ_i) − h Σ_i φ_i
```

自由能：

```
F = E − Θ S
```

- 第一项：**耦合能**。邻居的 `φ` 差得越远，能量越高；`γ` 是一致性压力。这一项就是书里的 `γ qᵀL(A)q`（图拉普拉斯二次型），不是新东西。
- 第二项：**局部势** `V(φ)`。单井 → 一个偏好；双井 → 两种风格；多井 → 多种品味。
- 第三项：**外场** `h`。平台、国家、市场、`Φ`；它把场往一个方向拉。
- `Θ`：社会温度／噪声；`S`：熵。`F` 不是“平均能”；只看 `E` 选不出相，熵项才决定井深与相变。

梯度流：

```
dφ_i/dt = − ∂F/∂φ_i + noise
```

这就是同化、分相、摆动、文明特质的同一套动力学。

---

## 2 四个现象，一个能量

| 现象 | 参数区 | 场的样子 | 读法 |
|---|---|---|---|
| **同化** | `h` 高、`γ` 低、单井 | `φ` 走向均匀 | 外场把大家拉到一个码；差异被抹平 |
| **品味** | `h` 低、`γ` 高、双井 | `φ` 分成两团 | 对称破缺；一团在这个井，一团在那个井 |
| **社会摆动** | 井底附近，`h(t)` 周期或 `γ` 滞后 | `φ` 在井底来回 | 不是一条正弦曲线，是势场里的振荡 |
| **文明特质** | 慢变量 | 序参量 `m = mean(φ)`，方差 `χ` | 五量里的 `μ`、`H`、`C` 可以从 `m/χ` 读 |

**关键**：同化与品味不是两个机制，是同一个 `F` 的两个参数区。`h` 把场拉平，`γ` 把场分开；`V` 决定分开后有几口井。

---

## 3 映射到书里的量

| 场能 | 书里的量 | 说明 |
|---|---|---|
| `φ_i` | `μ_i`／风格／变体 | 码的位置；可标量，也可向量 |
| `A_ij` | 关系网 | 谁看得到谁、谁影响谁 |
| `γ` | 一致性压力 | 已在 `γ qᵀL(A)q` 里 |
| `V(φ)` | `Cmp·Coh·W(Nov)` 的局部版 | 压缩／连贯／新颖决定井的形状 |
| `h` | `Φ`／平台／国家／市场 | 外场；谁有资格把场拉向哪边 |
| `Θ` | 噪声／社会温度 | 不是时间价格 `T`；符号要分开 |
| `C` | 势垒高度 | 换码成本；井与井之间的坎 |
| `ν_ij` | 局部边界条件 | `ν>0` 降低边界能，`ν<0` 抬高边界能 |
| `VOI`／`κ` | 横向场／扰动 | 把系统踢出井口；与 `h` 不是一回事 |

**爱／战争**在这个写法里是边界条件：`ν>0` 让两个组的边界能下降（容易混），`ν<0` 让边界能上升（容易裂）。这不是把爱还原成场，是把爱读成“边界上的耦合符号”。

---

## 4 为什么不是电磁场

电磁场的平均能是：

```
U = ½ ∫ (ε E² + B²/μ) dV
```

它有两个矢量场 `E/B`、规范对称、波动方程。社会场是**标量、耗散、无规范**的；硬套电磁场，会得到一个漂亮但不工作的比喻。

**可以借的**是“场能”这个数学形式：二次梯度能＋局部势＋外场。这是 Ginzburg–Landau／Ising 的写法，不是麦克斯韦。书里已经有 `γ qᵀL(A)q`，那就是离散的 Dirichlet 能；场能只是把它读成能量，再把 `Cmp·Coh·W(Nov)` 读成 `V(φ)`。

**不能借的**：`E/B` 的矢量性、光速、规范场、辐射。若要用“电磁平均能”，先给出 `E/B` 的对应量与波动方程；给不出，就只是比喻。

---

## 5 它买什么，卖什么

**买到的：**

1. **少一套模块**：同化、品味、文明特质共用一个 `F`，不用三套方程。
2. **一个判决线**：同一个 `γ/A` 变化，应当同时改变同化速度与品味极化；若两者互不相干，统一失败。
3. **一个可测的序参量**：`m`、`χ`、域尺寸；可用风格／名字／标签的分布去估。
4. **一个临界点**：`γ` 过 `γ_c` 时，`χ` 或域尺寸会跳；这是可查的相变，不是形容词。

**卖掉的：**

1. **`V(φ)` 是新假设**：单井、双井、多井，要有理由；不能事后画。
2. **`φ` 的可测性**：风格、变体、`μ` 都要代理；代理脏，场就脏。
3. **“什么都是场”的风险**：若每个现象都能换一套 `V/h/γ` 去拟合，它就退化成比喻。

---

## 6 三条可查的预言

1. **同化—品味联动**：在同一网络中，提高 `γ` 应当同时（a）加快同化、（b）加剧分相；若只发生一个，统一失败。
2. **外场压制分相**：提高 `h`（平台/国家/市场）应当降低品味多样性、加快同化；若 `h` 提高反而分相，`h` 的符号或 `V` 的形状错了。
3. **临界跳变**：`γ` 跨过 `γ_c` 时，`χ` 或域尺寸应当跳；若平滑无跳，`F` 的势形式要改。

---

## 7 与 VOI 的关系

VOI 是“信息值”，场能是“位置能”。两者不是一回事：

- `VOI` 决定一个人**要不要看**；
- 场能决定一个人**站在哪个井**；
- `VOI` 高的人先动，场能决定他动到哪个井；
- `ν` 是边界条件，`h` 是外场，`γ` 是耦合，`C` 是势垒。

若把 `VOI` 写成“横向场”，它可以踢动井口；但不要把它和 `h` 混成一个符号。
