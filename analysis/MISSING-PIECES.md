# 未自然涌现的章节：缺了什么

> 2026-11-19。回答一个问题：为什么第6章（`Φ` 三件套）与第8章（核实三角）读起来还是“分类＋案例”，而不是“公式生成故事”？
> **2026-11-19 已补**：第6章加了 `H`／`C_Φ` 判据；第8章加了 `a(e,s)`／`τ_v(e)`／`C(e,s)` 生产函数与账本闭合。P1 已在样章第15/16章使用（方向级：`λ(t)`、`s(q)`、`I(q)`）；标定与 P2 仍开放。
> 结论先说：不是缺案例，是缺三个**生成机制**——`Φ` 的分离成本、核实的生产技术、账本的闭合。再加一个更深的：**时间**。

---

## 0 一句话

第6章与第8章现在都是“把案例装进一个盒子”；要让它们自然涌现，得让盒子本身由成本与网络**推出来**。

- `Φ` 三件套：缺 `C_Φ`（分离成本）与 `H`（集中度），所以只能分类，不能预测“哪种更可争辩”。
- 核实三角：缺 `a(e)`、`τ_v(e)`、`C(e,s)`（核实的生产技术），所以三角是启发式，不是前沿。
- 两章共同的深层缺口：模型给“会不会”，不给“什么时候”；叙事要顺序，顺序要**风险率** `λ(t)`。

## 1 第6章 `Φ`：从分类到生成

### 1.1 现在缺什么

第6章把 `Φ` 拆成命名、解释、执行三件套，然后用平台／社区／专业三个案例填表。问题是：

- 没有**集中度**：三件套在一个人手里，与在三群人手里，差别有多大？没有数。
- 没有**分离成本**：为什么有些制度把三权分开，有些合在一起？没有解释。
- 没有**预测**：给定一个制度，能不能说它更可争辩还是更不可争辩？现在只能事后贴标签。

### 1.2 补什么：`H` 与 `C_Φ`

**集中度**：每个权力上用赫芬达尔指数：

```
H = Σ_k Σ_i s_{ki}²,   k ∈ {name, interp, enforce}
```

`H` 越接近 1，越集中；越接近 1/3，越分散。再定义**分离度**：

```
S = 1 − overlap(Φ_name, Φ_interp, Φ_enforce)
```

**分离成本** `C_Φ`：把三权分开要付的成本——时间、协调、责任推诿、决策变慢。

**分离条件**：

```
S* = 1  if  C_Φ < w·D_error + A·voice
S* = 0  otherwise
```

读法：

- 错误代价 `w·D_error` 高 → 值得分权，因为一个人错一次太疼；
- 声音 `A·voice` 强 → 值得分权，因为被标的人能申诉；
- 分离成本 `C_Φ` 高 → 不分，因为分权太慢、太贵。

**这就能推出三种 `Φ`**：

- 平台 AI 标签：`w·D_error` 对平台低（误标不赔），`A·voice` 低（申诉难），`C_Φ` 高（要建独立复核）→ `S*` 低，三权合一。
- 维基百科：`w·D_error` 中（删错条目有成本），`A·voice` 高（讨论页），`C_Φ` 中（共识慢）→ `S*` 中高，三权分开。
- DSM：`w·D_error` 高（误诊代价），`A·voice` 中（第二意见），`C_Φ` 高（专业门槛）→ `S*` 中，部分分开。

**预测**：

1. 误标代价上升（平台被罚）→ 分权上升；
2. 申诉网络变密（`A` 上升）→ 分权上升；
3. 分离成本下降（独立复核变便宜）→ 分权上升。
这三条都可以在平台治理改革里查。

### 1.3 还缺什么

`C_Φ` 本身没有代理。候选：独立复核的工时、申诉处理的时长、决策链的长度。需要一次平台／机构的比较研究。

## 2 第8章 核实三角：从启发式到前沿

### 2.1 现在缺什么

“快、便宜、可信，最多两个”是一个启发式。它好用，但没有**生产技术**：

- 为什么快与可信不能兼得？因为核查要时间；
- 为什么便宜与可信不能兼得？因为独立核查要钱；
- 为什么快与便宜能兼得？因为自动标签便宜、快，但不可信。

这些都能从三个函数推出来，不需要三角假设。

### 2.2 补什么：三个生产函数

设核查投入为 `e`，独立度为 `s`（0—1，1 表示完全独立于被标者）。

**准确率**：

```
a(e,s) = 1 − exp(−η e s)
```

**延迟**：

```
τ_v(e) = τ₀ + κ / e
```

**成本**：

```
C(e,s) = c₀ + c₁ e + c₂ s
```

三角就是这三个函数的**帕累托前沿**：

- 要 `τ_v` 小 → `e` 大 → `C` 大；
- 要 `a` 高 → `e` 大、`s` 高 → `C` 更大；
- 要 `C` 小 → `e` 小、`s` 低 → `a` 低、`τ_v` 大。

**三角不是假设，是三个函数的形状。** 这就能解释：

- 平台 AI 标签：`e` 中、`s` 低、`C` 低 → `a` 低、`τ_v` 小；
- 新闻室：`e` 高、`s` 高、`C` 高 → `a` 高、`τ_v` 中；
- 社区审议：`e` 低、`s` 高、`C` 中 → `a` 中、`τ_v` 大。

### 2.3 预测

1. 提高独立度 `s`，准确率上升，但成本上升；若成本不升，说明 `s` 没真独立。
2. 提高投入 `e`，延迟下降，但边际递减；`τ_v` 对 `e` 的弹性约为 −1（`κ/e`）。
3. 自动标签若 `s` 低，`a` 不会随 `e` 线性上升；加人复核才有效。

### 2.4 还缺什么

`η`、`κ`、`c₁`、`c₂` 没有标定。需要一次核查机构的工时与准确率数据；平台不会公开，但新闻室与社区有公开记录。

## 3 三个更深的缺口

### 3.1 时间：模型给“会不会”，不给“什么时候”

`wAd > C+R` 是一个门槛，不是一个时点。叙事要顺序：先什么、后什么、多久。现在只能写“条件到了”，不能写“哪一天到”。

补一个**风险率**：

```
λ(t) = λ₀ · exp( β [ w(t)·A(t)·d − C − R ] )
```

`λ(t)` 是“在 t 时刻发生转型”的瞬时概率；生存函数 `S(t)=exp(−∫λ)`。这样：

- `w(t)` 上升 → `λ(t)` 上升 → 转型更可能在近期发生；
- `A(t)` 织密 → `λ(t)` 上升；
- `C` 下降 → `λ(t)` 上升。

**这把“阈值”变成“时序”，把“会不会”变成“多快”。** 第12章明治与1848的对比，可以从“过/不过”升级为“1848 的 λ 一直很低，明治的 λ 在 1868 年跳上去”。

### 3.2 账本闭合：谁付、谁收，必须相加为零

“谁付账”表现在是会计描述，不是一般均衡：成本列出来了，但没有说谁收到。真实的账必须闭合：

```
Σ_i payment_i = Σ_j receipt_j
```

补一张**社会会计矩阵**：每一笔成本，有付方、收方、时间、币种（钱、时间、身份、风险）。没有闭合，成本只是修辞；闭合了，才能说“动这个杠杆，谁补谁”。

这也是“改造现实”的前提：你不能只说“谁疼”，还要说“疼的钱进了谁的口袋”。

### 3.3 测量反身性：模型看到的数据，是 `Φ` 选出来的

A.11 有一条：能被记进档案的，只能是共同体内能被指认的切点。新地基里，`q` 是被某人测量的；如果 `Φ` 控制测量，数据就是被选过的。

补一个观测方程：

```
observed q = q   if s(q)=1
             missing   otherwise
s(q)=1{ γ(q)·ẑ(q) > δ(q) }
```

这意味着：**模型的样本不是随机的，是 `Φ` 的产物。** 不补这一条，模型会把“被记录下来的”当成“发生的”，把“没被记录的”当成“没发生”。这是社会与文明现象最深的坑。

## 4 其他缺口（次要，但要登记）

| 缺口 | 现状 | 补法 |

| `I(q)` 未操作化 | 第5、6章用 `I(q)` 讲蕴涵，但没有真的画出一个概念格 | 用一个真实案例（AI 标签：AI⇒非原创⇒无版权）画格，给出蕴涵集 |
