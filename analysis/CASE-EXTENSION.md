# 扩展：把同一套分析搬到别国有争议的历史段

> 唐宋这段之所以能用，不是因为它特殊，而是因为它把三个量（`μ`、`γ`、`C`）都摆在了明面上。
> 换成别处也能用——只要那里同时满足三件事：**划分在换、群体在竞争、代价可核**。
> 这份文件给一套可移植的作业流程，并列出五个可移植的候选段。

---

## 1 可移植性判据（先过这一关，再谈分析）

| 判据 | 问题 | 不过关会怎样 |
|---|---|---|
| **① 划分在换** | 那段时间里，"谁是正当的"这个划分有没有真的变过？ | 码没变，就只是权力更替，模型退化为叙事 |
| **② 群体在竞争** | 有没有**公开可核的竞争**（交战、选举、市场、审判），而不是纯密室？ | `γ` 无法观测，"思想的作用"只能猜 |
| **③ 代价可核** | 有没有能数的东西（伤亡、席位、份额、法条数、判例数）？ | 只能写 C 级情景，进不了正文的数据段 |

**三条全过 = 可以进正文；过两条 = 进附录；过一条 = 只当脚注。**

## 2 五步作业流程（唐宋就是按这个走的）

| 步 | 做什么 | 输出 |
|---|---|---|
| 1 | **切段**：按"合法性划分换没换"切，不按王朝切 | 3—5 段 |
| 2 | **写每段的划分 `q`**：块有哪几块、边界在哪 | 一张表 |
| 3 | **定每个人的型**：`μ`／`v`／`γ`／`C` 哪个动 | 传记四栏（`CASE-BIOGRAPHY.md`） |
| 4 | **找 `γ` 的执行方式**：交战？投票？审判？市场？ | 一句话 + 一个可核指标 |
| 5 | **数 `C` 的变化**：换码变便宜还是变贵，谁在抬它 | 一条时间线 |

**第 4 步是最容易漏的**，也是最关键：`γ` 靠什么执行，决定了"说出一句话"是陈述还是冒犯。

## 3 五个候选段（按可核材料的密度排）

### 3.1 罗马共和末期 → 元首制（前 133—公元 14）

| 判据 | 状况 |
|---|---|
| 划分在换 | 是：`{血统·元老院·军权}` → `{军权·庇护·元首权威}` |
| 群体竞争 | **交战 + 公开审判 + 选举**，三种都在（可核） |
| 代价可核 | 有：军团数、土地分配、元老院席位、法条 |

**对应人**：格拉古兄弟（`μ` 冲突）、马略与苏拉（`C` 崩溃）、凯撒（收窄型，`REWALK` §6 已写）、屋大维（**换码型**：抬高 `C`，把兵变制度化地变贵）。

#### `C` 的三因子分解（作者要求：规模、性质、频率）

`C` 不是"政变次数"，它至少是三个因子的积：

$$C_{\text{eff}}=\frac{c_{\text{规模}}\cdot \phi_{\text{性质}}}{1+\lambda_f\, n_{\text{近}}}$$

| 因子 | 含义 | 罗马的读数 |
|---|---|---|
| **规模** `c_规模` | 一次换码的赌注（死亡数、军团数、没收财产） | 苏拉→凯撒→屋大维**递增** |
| **性质** `φ_性质` | 换码的方式：暴力型贵、程序型便宜但门槛高、市场型最便宜 | 罗马全程**暴力型** ⇒ `φ` 高 |
| **频率** `n_近` | 近期换码次数——它**降低**有效成本（预期形成、准备成本摊薄） | 频繁 ⇒ 分母变大 ⇒ `C_eff` 下降 |

**这条分解推出一个新预言**：

> **换码频率有正反馈（自激）。** 换过一次，下一次就更便宜；所以政权更替的时间间隔应当**聚集**（bursty），比泊松过程更聚集。

**可测**：罗马内战的间隔分布、拉美 1930—1990 政变间隔分布——用**过度离散指数**（Fano 因子 / 变异系数）与泊松比较。
**若间隔接近泊松**，频率项不成立，`C` 就退回纯规模—性质。

（这也顺手解释了拉美那段：政变常态不是"文化"，是 `C_eff` 被频率压低了。）

### 3.2 法国 1789—1880：五个政体的反复

| 判据 | 状况 |
|---|---|
| 划分在换 | 是：`{王权·教会·等级}` → `{人民·宪法·派系}` |
| 群体竞争 | **选举 + 街垒 + 公投**，全部可核 |
| 代价可核 | 有：选举结果、公投票数、伤亡、政变次数 |

**这段是全套里最好的"失败对照"**：同一个划分被换了五次，说明 **`C` 没有被真正抬高**——
每次都能被翻回去。用模型的话：**这是"没有抬高 `C` 的换码"**，与宋初正好互补。
**可测**：政体存续时长（1789—1880 平均约 18 年）× 宪法改写次数。

### 3.3 明治日本 1868—1900：**最快的换码**

| 判据 | 状况 |
|---|---|
| 划分在换 | 是：`{武家·藩·家格}` → `{天皇·官僚·学历}`，**在 30 年内完成** |
| 群体竞争 | 有内战（戊辰）、有报纸论战、有士族叛乱（西南战争） |
| 代价可核 | 有：地税、学制年限、征兵令、爵位册封数 |

**为什么有用**：它是**同一个换码过程的加速度版本**——宋用了 70 年，日本用了 30 年。
**若我们的公式对，加速度应当来自 `w` 的突变**（外压＝被殖民的利害），而不是"民族性"。
**可测**：`w` 的代理是国防开支与不平等条约数；`C` 的代理是士族叛乱的规模衰减。

### 3.4 苏联 1985—1999：**`C` 已经被抬到极高却仍翻了**

| 判据 | 状况 |
|---|---|
| 划分在换 | 是：`{党·计划·阶级}` → `{市场·民族·主权}` |
| 群体竞争 | 部分（选举、公投、民族冲突），但核心是密室 |
| 代价可核 | 有：GDP、通胀、寿命、加盟共和国退出顺序 |

**已升为正文**（作者定）：见 `CASE-USSR.md`。核心是从 P3 推出的 D1—D6 六步——
**高 `C` 防的是单个人换码，不防两套码并存的长期积累；它买到的是时间，而时间在积累失真。**

### 3.5 拉美 1930—1990：**政变作为常态**

| 判据 | 状况 |
|---|---|
| 划分在换 | 反复换，但没有稳定新码 |
| 群体竞争 | 政变（封闭）+ 选举（开放）交替 |
| 代价可核 | 有：政变次数、通胀、选举舞弊率 |

**用途**：这是"`γ` 在两种执行方式之间来回跳"的样本——
**交战/选举（公开可核）时码清晰，政变（密室）时码模糊**。
正好用来检验 §4.4 那条区分（公开可核 vs 封闭默契）。

| 苏联 | **正文第 20 章第二节** | 迟滞的极端案例：`C` 高只买到时间，买到的是失真累积 |
| 拉美 | 附录 C（稳健性） | `γ` 执行方式的切换 |

**一条纪律**：**每多一个案例，就要多一条"我们没解释的地方"**。
否则六个案例会变成六次事后拟合——这正是 `CLAIMS-AUDIT` 判"案例类只能当插图，不能当证据"的原因。
