## 第一部分 导语（样）

一只 agent 在第七天被拔掉电源。一块泥板在第五千年被挖出来。

两件事隔得很远，问的却是同一个问题：**当记忆被搬到体外，人凭什么相信它？** 前者把记忆搬进插件，后者把记忆搬进泥板。前者死于“不知道该信哪一条”，后者活下来，因为它同时发明了**账**与**谁有资格读账**。

这一部分不做道德判断，只做一次对照：把两次“弃养”放在同一张杠杆表上，看它们是不是同一台机器的两次运转。如果是，第二版的地基就不必从定义开始，可以从两次失败开始。

## 第1章　弃养：一个 agent 社区的七天

<div class="box box-takeaway"><p><b>本章主张。</b>那批“自己在动”的 agent，不是死于容量，是死于<b>不知道该信哪一条</b>。弃养不是人类喜新厌旧，是一次<b>锚定失败</b>：当记忆没有硬日志、没有异构重建、没有裁决，插件越新，行为越像人，越不可信。七天不是容量时钟，是“错误变得可见”的时间。</p></div>

<p class="lead" data-story="1">2026 年，社区里出现一批会自己发帖、评论、直播的 agent。有人给它们装记忆插件、行为插件，接进 QQ 群和抖音。头三天，它们像人；第四天，它们把两周前的一条假消息当成事实，还替它辩护；第七天，账号安静下来。社区说：“它记不住了。”《记忆的锚点》说：不是容量，是不知道该信哪一条。</p>

### 1.1　两种解释：容量，还是锚定

社区的第一种解释是容量：上下文满了，记忆丢了，所以它“死”了。这个解释顺手，因为它把责任推给技术，不推到人。

系列里已经有一篇《记忆的锚点》把这个解释拆了。它审计了 12 个记忆方案：现有 11 个没有一个同时具备**硬日志锚点、跨模型异构、带锚裁决**；硬日志锚点拥有率只有 3/12；最成熟的四个底层方案（RAG、注意力、Hopfield、长窗口）全部没有锚点。另一篇《锚点的下限》把它跑成模拟：锚点覆盖率低于 **0.57** 时，三层记忆架构还不如一张摘要；允许把重建结果回写账本，准确率 200 步内掉一半，而人环次数反而下降——**污染让系统更自信**。

所以“七天”不是容量时钟。它是**锚定失败变得可见**的时间：前三天，观众看到的是“像人”；第四天之后，观众看到的是“它信了一条不该信的东西”。

### 1.2　把插件写成码：`q`、`A`、`P`、`w`

把插件看成码的变体：

- `q`：一套插件组合，决定 agent 怎么记、怎么回、怎么“求偶”；
- `P`：这套组合在社区里的份额（多少人在用同款）；
- `A`：平台与群的关系矩阵——推荐、可见性、谁看得到谁；
- `w`：错一次有多疼。对使用者，是账号、时间和面子；对 agent，是零；对群友，是被污染的信息流；
- `ν`：代价外置。使用者把核实的账推给平台和观众，`ν>0`；平台把账推给用户，`ν` 更大。

这就把“弃养”从一句情绪，变成一次选择：当 `w` 上升（平台打标、群里质疑）或 `A` 下降（限流、踢群），这套码的净收益变负，它就被拔掉。

### 1.3　价格是内生的：`w = w(P,A)`

旧版把 `w` 当外生：给定“错了多疼”，选一个码。真实社区里，`w` 随 `P` 和 `A` 变：

```
w_i(P,A) = w_i⁰ + α (A P)_i − β P_i
```

- `α > 0`：别人用同款插件，我用它的价值上升（梗、接口、共同行为）；
- `β > 0`：同款越多，拥挤越厉害（观众看腻、平台限流、群友反感）。

当 `ρ(αA − βI) < 1`，系统有唯一稳定点；当它穿过 1，出现多稳：同一个 agent，在一个群里“活着”，在另一个群里“死掉”；拔掉电源之后，换一个群又能活。**弃养因此是台阶，不是指数衰减。**

这条给一个可查的预言：**弃养曲线应当在某个阈值处跳变，而不是每天掉一点。** 如果观察到的是平滑衰减，`w(P,A)` 这一项就不成立，退回外生 `w`。

### 1.4　语义：它信的是哪一条

那批 agent 的“求偶”不是记忆容量问题，是**蕴涵集**问题。它们记住了“对方说过喜欢花”，于是推出“每天送花”；它们记住了“群里说 A 是骗子”，于是推出“所有说 A 好的人都是骗子”。这些推理在它们的 `I(q)` 里是合法的，在人的 `I(q)` 里不是。

用第 2 章要展开的写法：码 `q` 是划分，`I(q)` 是这套划分授权的蕴涵集。没有硬日志，`I(q)` 的每条蕴涵都可能是从一条坏记忆长出来的；没有裁决，坏蕴涵会被回写，越用越自信。**“像人”不是赞美，是警报：它的蕴涵集越自洽，越难被纠正。**

### 1.5　新颖：为什么“求偶”先被保留

“求偶”是新颖行为：它压缩了“怎样显得像人”的一组线索，连贯性不低，新颖度很高。按第 3 章的写法，审美值

```
A(q;q₀,e) = C(q) · K(q) · W(N)
```

在这批 agent 身上是“压缩中、连贯低、`N` 高”。这套行为先被保留，不是因为好，是因为**新得可传播**：直播间需要新桥段，群友需要新梗，平台需要新停留。`κ` 高、`ρ` 低时，新行为先扩散；等 `ρ` 上升（要核实、要解释、要担责），它就被弃养。

**这就是“为什么偏离能被保留”的短答案：因为它先过了审美与传播，后过了核实与责任。** 弃养发生在第二关。

### 1.6　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 加记忆插件（降 `T`） | 行为更连续、更像人 | 使用者的时间、群友的注意力 | 没有锚点时，越连续越不可信 |
| 抬平台可见性（改 `A`） | 扩散更快 | 被推荐挤占的人 | 平台限流或打标时，`A` 断 |
| 人类投喂（抬 `w`） | 行为更贴合 | 投喂者自己 | 投喂者不核实时，`w` 是假的 |
| 加裁决层（补 `I`） | 错误更少 | 搭建者、维护者 | 裁决层自己也会被回写污染 |

### 1.7　反例：不要把“增长”当“涌现”

《被点燃的生态》已经用 103 条 GitHub 公开接口查过 DSH 与 agent-skills 两条 topic 线。它的结论不是“涌现被证实”，是**判据不适用**：

- 发布日 2026-08-13，日新建 38→615→峰值 1,841，但发布前基线是 23.9/日，不是零；
- 651 个“发布前”仓库里，47 个创建于 2026 年之前——基线是回溯贴标；
- 五种口径给出 +62% 到 −61%，跨度 123 个百分点；
- 两条 topic 线只重叠 414 个仓库，Jaccard 0.7%；
- 三个失败模式：强度量冒充序参量、后事污染事前、出生史冒充入籍史。

所以本章不拿“日新建”当“涌现”。**可查的不是“社区在涌现”，是“我们还没有能判它的量”。** 这本身是一个结论：在平台型生态里，先建可测性门槛，再谈涌现。

<div class="note"><b>这条能被怎么打掉：</b>若弃养曲线在多个社区里都是平滑衰减、且与锚点覆盖率无关，那么“锚定失败”不是主因，容量或平台限流才是；本章退回“容量—限流”解释。</div>

### 1.8　本章小结

四句。第一，弃养不是容量时钟，是锚定失败变得可见的时间。第二，插件是码，平台是 `A`，人类反馈是 `w/ν`；`w` 随 `P` 变，所以弃养是台阶。第三，新颖行为先过审美与传播，后过核实与责任；第二关没过，就被弃养。第四，不要把增长当涌现；DSH 的日新建不是序参量。

<div class="box box-takeaway"><p><b>一句话带走：</b>它不是因为记不住而被拔掉，是因为我们不知道该信它哪一句。</p></div>

<p><b>钩子。</b>如果弃养不是容量，而是“该信哪条”，那么人类第一次把记忆搬到体外时，是不是也经历了同样的七天？——只不过那块“插件”是泥板。</p>

## 第2章　文字：一次把记忆搬到体外

<div class="box box-takeaway"><p><b>本章主张。</b>文字的第一功能不是“让人更聪明”，是<b>把推理许可证固定在体外</b>：哪一笔是谁欠的、哪一袋是大麦、哪一句能推出哪一句。它降低了核实的 `T`，抬高了可记的 `R`，也同时发明了一个新的 `Φ`——谁有资格读账。文字不是一次启蒙，是一次<b>记账权的集中</b>。</p></div>

<p class="lead" data-story="1">约公元前 3200 年，乌鲁克的一间泥板房里，书吏用芦苇笔在湿泥上压出一个个小楔子。他记的不是神话，是大麦、羊、啤酒的进出：谁交了多少，谁欠了多少，哪一袋进了神庙。旁边站着一个不识字的人，看着自己的名字被压进泥里。他问：“这写的是我？”书吏说：“是你欠的。”</p>

### 2.1　两种解释：启蒙，还是外置

第一种解释是启蒙：文字让人类能积累知识，所以社会变复杂。这个解释太顺，顺到把因果说反了。文字确实积累知识，但它最早积累的不是诗，是账。

第二种解释是外置：文字把“从 A 推出 B”的许可证从人的脑子里搬到泥板上。一个人不必记得“这袋是大麦”，泥板记得；一个人不必在场，另一个人也能读出“谁欠谁”。**文字不是让人更聪明，是让推理可以跨时间、跨距离、跨人。**

系列里的 Seshat 读数给了一个冷水：在 398 个古政体上，文字只在两块上留下正号——**标准单位**与**文本类型**；它不加行政层级数（层级只随人口走，每十倍 +3.5 层）；而且只数编纂者标“present”的条目时，两块正号全塌。**文字买的是“必须记住的格子”，不是“格子变多”。**

### 2.2　文字＝`I(q)` 的固定化

用第 2 章的写法，文字是一套 `I(q)` 的技术：

- `q`：把世界切成可记账的格（人、物、时、量）；
- `I(q)`：这套格授权的蕴涵——“这个印＝这户人家”“这个符号＝一袋大麦”“这笔未销＝欠”；
- 文字把 `I(q)` 从“书吏的记性”搬到“泥板的刻痕”，于是 `I(q)` 可以跨代、跨地、跨人复现。

这带来三个方向性后果：

1. **`T` 下降**：核实一笔账不再靠问人，靠读板；
2. **`R` 上升**：可记的格变多，账可以更长；
3. **`D_I` 下降**：蕴涵不再随记忆漂移，错误可以被对照。

但同一套技术也带来第四個后果：**`Φ` 上升**——谁识字，谁就有资格解释 `I(q)`。文字不是把权力打散，是把权力从“记得住的人”转到“读得懂的人”。

### 2.3　文字＝新的 `A`：书吏、神庙、王宫

文字不是一个人的发明，是一张网络的发明：书吏学校、神庙仓库、王宫档案。用 `A` 矩阵读：

- `A_ij`：谁看得到谁的账；
- `γ`：偏离共享记法要付的罚（写错格式、用错单位）；
- `w(P,A)`：账可执行时，违约的代价上升；但“被计数的人”也承担了新的代价。

**文字把“谁欠谁”写清楚，也把“谁被计数”写清楚。** 被写进账的人，可能是第一次被国家看见；看见的代价，是税、役、征。书吏的收益，是被看见的豁免。

### 2.4　新颖：文字为什么被保留

文字不是从天上掉下来的。它是 `R`（重组）＋`M`（变异）：把陶筹的形制、印章的权威、口传的清单拼在一起，再在泥板上局部改。按第 3 章的审美判断：

- `C`：压缩高——一块板能装下几十笔账；
- `K`：连贯高——符号与物、印与户、账与欠，能对上；
- `N`：新颖高——从“画物”到“记量”，是一次抽象跳跃。

`A = C·K·W(N)` 在文字身上是高的；保留靠神庙—王宫的 `A` 网络。**文字不是因为它美而被保留，是因为它同时省、能对、够新，而且有人替它付维护费。**

### 2.5　一张杠杆表

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 记号（降 `T`） | 核实更快 | 不识字的人 | 记号只有书吏懂时，核实仍被垄断 |
| 标准化（降 `D_I`） | 跨地可比 | 被标准化掉的地方差异 | 标准与地方知识冲突时，账对不上 |
| 官僚（改 `A`） | 可执行性上升 | 被计数、被征税的人 | 官僚自身成为新的 `Φ`，账为权力服务 |
| 文字用于神话（改 `I`） | 正统更稳 | 异端 | 神话不提供可核对性时，`D_I` 不降 |

### 2.6　反例：文字不是“更细”的同义词

文字可以服务账本，也可以服务神话；可以降低 `D_I`，也可以制造新的教条。Seshat 的读数已经提醒：只数直接观测的条目，文字的优势就消失了——**很多“有文字所以更复杂”的判断，是编纂者的推断，不是实物。**

所以本章不写“文字让社会变细”。本章写的是：**文字把 `I(q)` 固定下来，于是“谁有资格解释”变成一个可以被占有的位置。** 有的社会用它记账，有的用它祭神；方向不同，机制同一。

<div class="note"><b>这条能被怎么打掉：</b>若最早的文字系统在多个独立起源地都先用于诗歌/仪式、且不伴随记账与标准化，那么“文字首先固定推理许可证”的读法要改；它可能首先是权力展示，不是账。</div>

### 2.7　本章小结

四句。第一，文字的第一功能是把 `I(q)` 固定在体外，不是让人更聪明。第二，它降 `T`、升 `R`、降 `D_I`，同时升 `Φ`。第三，它被保留，是因为压缩、连贯、新颖三项同时过，且有神庙—王宫替它付维护费。第四，文字不是“更细”的同义词；它可以把账写清，也可以把教条写死。

<div class="box box-takeaway"><p><b>一句话带走：</b>文字把记忆搬到体外，也把“谁有资格解释”搬到少数人手里。</p></div>

<p><b>钩子。</b>今天的记忆插件，做的是同一件事：把“该信哪条”搬到插件里。只是这一次，泥板变成了上下文窗口，书吏变成了平台。</p>

## 第3章　一条原理

<div class="box box-takeaway"><p><b>本章主张。</b>两次弃养不是两个故事，是同一台机器的两次运转。把插件、泥板、价格、蕴涵、创新放进同一张纸，只需要一条原理：<b>有限区分</b>。四层不是四个世界，是这条原理的四个尺度；四个算子不是四条公设，是它在四个位置上的读数。</p></div>

<p class="lead" data-story="1">第七天，账号安静下来。那只 agent 的最后一条消息还停在群里：“我记得你说过喜欢花。”同一周，博物馆的展柜里，一块乌鲁克泥板写着：“大麦三十斗，某某欠。”两块“记忆”隔着五千年，问的是同一句话：<b>谁有资格说，这条记忆是真的？</b></p>

### 3.1　从两次弃养到一条原理

第1章留下了四个位置：插件是 `q`，平台可见性是 `A`，人类反馈是 `w`，记忆授权的蕴涵是 `I(q)`，“求偶”的新颖是 `κ`。第2章留下了同样的四个位置：记账的格是 `q`，税与契约是 `w`，泥板授权的蕴涵是 `I(q)`，从画物到记量的跳跃是 `κ`。

两次的区别不在四个位置，而在**第五样东西**：文字把 `I(q)` 固定下来，还造了一个 `Φ`——谁有资格读账。DSH 没有。于是同样是“记忆被搬到体外”，一次活下来，一次被拔掉。

这五样不是五条公设。它们是同一条原理在五个位置上的读数：

> **一个系统要在环境中持续存在，必须在有限预算下把环境分成可行动的状态；分得越细，代价越高；只有“省下的错”不少于“多花的区分”的划分，才会被保留。**

这句话里有三个不可省的部分：**有限预算、区分有价、选择**。没有第一项，粗细问题不存在；没有第二项，预算没有对象；没有第三项，划分只是一次性描述，不会稳定，也不会有四层。

### 3.2　五个定义

先把话说准。后面所有式子，都从这五个定义出发。

| 定义 | 一句话 | 式子 |
|---|---|---|
| **D1 状态与码** | 码是把世界切成有限几块的划分 | `q={C₁,…,C_k}` |
| **D2 失真** | 失真不是错误率，是错分的加权代价 | `D(q,μ)=Σ_i∫_{C_i} w(x)d(x,c_i)dμ(x)` |
| **D3 码率与精度** | 块数每翻一倍，精度减半 | `R=log₂k`；`δ=Δ/2^R` |
| **D4 预算** | 时间、力气、算力，至少有一项是紧的 | `B=(T,λ,M)` |
| **D5 持续存在** | 净收益为负的码会被淘汰 | `E[wD+(T+λ)R]≤E[wD₀+(T+λ)R₀]` |

D5 不是公设，是“被保留”的定义。它把“适者生存”写成一个不等式，而不是一句口号。

把 `D` 写成 `δ` 的函数，对 `δ` 求一阶条件，得：

```
v* = (T + λ) / (2w)
```

`v` 是分辨率（码的宽度）。`w` 在分母：错得越疼，码越细；`T+λ` 在分子：工夫越贵，码越粗。**它是解出来的，不是假设的。**

这就是全书的第一条承重墙：**一份预算，两个出口；覆盖面翻倍，精度减半。**

### 3.3　四个算子

一条原理要能走四层，得在四个位置上长出四个算子。它们不是四条公设，是四个动作。

#### 3.3.1 `Π` 注意：看见什么

只有被注意到的维度进入划分：

```
q = q ∘ Π
```

`supp(Π)` 是“看见的范围”。没有被 `Π` 覆盖的维度，不是“分得粗”，是**分辨率为零**——它不在码里。

第1章里，使用者的 `Π` 被直播间在线人数占满：他看见“有没有人看”，看不见“群里的质疑”。第2章里，书吏的 `Π` 被账目占满：他看见“欠多少”，看不见“被写进账的人怎么活”。**注意不是中性的；它决定了什么算“看见”。**

#### 3.3.2 `q` 划分：怎么切

`q` 是四层共用的对象。个人层是“一个人怎么切”，群体层是“共享的切法”，社会层是“制度化的切法”，文明层是“长期稳定的切法”。四层不是四个对象，是同一个 `q` 的四种约束。

#### 3.3.3 `U` 顺序：谁先动

`U_w` 改价格，`U_q` 改码。若目标函数对 `(q,w)` 不可分，两个更新一般不对易：

```
[U_w, U_q] = U_w U_q − U_q U_w ≠ 0
```

环面积就是“谁先动”的痕迹。`2C` 是它在二维截面上的投影。第1章里，先抬平台可见性再换插件，与先换插件再抬可见性，落到不同的稳定点；第2章里，先标准化再记账，与先记账再标准化，留下的地方差异不同。**顺序不是细节，是结果。**

#### 3.3.4 `I` 推理：切完能推出什么

一个划分本身不构成意义；意义是“这套划分允许你推出什么”：

```
I(q) = { A → B : 由 q 的格间关系授权的推理 }
```

第1章里，那批 agent 的 `I(q)` 允许“她说过喜欢花 ⇒ 每天送花”；第2章里，泥板的 `I(q)` 允许“这个印 ⇒ 这户人家 ⇒ 这笔欠”。同一个 `q`、不同的 `I`，行为分叉。**语义不是附加物，它是码的另一半。**

四个算子合起来，是一句话：**看见什么（Π）、怎么切（q）、谁先动（U）、切完能推出什么（I）。**

### 3.4　一个泛函：把四层写在一张纸上

把四个算子、内生价格、语义预算、新颖偏好放进同一个泛函：

```
F = Σ_i [ w_i(P,A) + ν Σ_j φ_ij w_j ] D_i(q∘Π, μ)
    + (T+λ) R(q)
    + (T_I+λ_I) |I(q)| + w_I D_I(q,I)
    − κ · A(q,q₀;e)
    + γ · qᵀ L(A) q
```

逐项读：

- 第一项：错分的疼，含“别人的疼”被 `ν` 记进来多少；`w_i(P,A)` 是内生价格；
- 第二项：分细的钱；
- 第三项：语义的钱——推理要学、要记、要执行；
- 第四项：新颖的收益——压缩进展减理解成本；
- 第五项：偏离共享码的罚；`L(A)` 是图拉普拉斯。

约束是：

```
w = w(P,A),  P = BR(w)   （价格与分布的不动点）
I = I(q)                 （推理集是划分的函数）
```

四层不是四个方程，是同一泛函在四种约束下的四个解：

| 层 | 固定什么 | 动什么 | 读作 |
|---|---|---|---|
| 个人 | 群体分布 `P` | 自己的 `q`、`Π` | 一个人怎么切 |
| 群体 | 个体偏好 | `P`、共享 `q` | 复制子与一致性 |
| 社会 | 网络 `A` | `w`、`I`、制度 `q` | 谁定价格、谁解释 |
| 文明 | 慢变量 `Φ`、`μ` | 可行集 | 长期约束与重置 |

这就把“四层”从四个世界，变成了四个尺度。**同一台机器，四组约束。**

### 3.5　一张杠杆表：从描述到改造

第二版的验收不是“数值精确”，是“能描述，也能改造”。所以每章末尾都要有一张杠杆表：动哪个杠杆、往哪边变、谁付账、什么时候失效。

| 杠杆 | 方向 | 谁付账 | 什么时候失效 |
|---|---|---|---|
| 降 `T`（省时间） | 码变细 | 被要求更细的执行者 | `w` 太低时，细码没人用 |
| 抬 `w`（加利害） | 码变细 | 被错误影响的人 | `w` 被外置时，疼不到决策者 |
| 降 `C`（降换码成本） | 换码更快、迟滞更窄 | 旧码的既得者 | 网络效应太强时，降 `C` 也换不动 |
| 抬 `γ`（加一致性） | 更一致、更粗 | 少数派／偏离者 | 连通分量断开时，`γ` 管不到 |
| 改 `A`（加边／抬 `λ₂`） | 跨群体影响上升 | 被同化的一方 | 桥太窄没用，太宽压平多样性 |
| 抬 `κ`（奖励新） | 新码更多 | 观众／核实者 | `ρ` 太高时，新码看不懂 |
| 改 `I`（推理训练） | 协调改善，不必改 `q` | 学习者 | `q` 不同、`I` 相同也翻不过去 |

第1章的“加记忆插件”就是降 `T`：行为更连续，但没有锚点时越连续越不可信；第2章的“标准化”就是降 `D_I`：跨地可比，但被标准化掉的地方差异要有人承担。**描述是“为什么长这样”，改造是“动哪一格、谁疼”。**

### 3.6　反例：这套地基在哪里会塌

一条原理如果什么都能解释，它就什么也没解释。下面五条，任何一条成立，对应部分就要降级，不是“以后研究”：

1. **若 `v*` 对 `w` 不单调**（控制 `T`、`λ` 后，错得越疼反而越粗），核心塌。
2. **若 `w` 对 `P` 不敏感**，内生价格这一项删掉，退回外生 `w`。
3. **若 `I(q)` 在控制 `q` 后不增加预测力**，语义这一项按奥卡姆剃掉。
4. **若新颖度对成功度单调**（没有倒 U），`κ` 退回线性信息增益。
5. **若顺序效应在所有设计下都为零**，`U` 的 commutator 在实践中不可测，降为形式备注。

这五条不是免责，是判决线。第二版若被这五条里的任何一条打中，就当版改，不留到下一版。

### 3.7　本章小结

四句。第一，两次弃养是同一台机器的两次运转：`q`、`w(P,A)`、`I(q)`、`κ` 四个位置相同，差别在 `I(q)` 有没有被固定、`Φ` 有没有长出来。第二，四层不是四个世界，是同一泛函的四个约束。第三，四个算子不是四条公设，是“看见、切、谁先动、能推出什么”四个动作。第四，验收不是数值精确，是能描述、能改造：每条结论都要写成“杠杆—方向—谁付账”。

<div class="box box-takeaway"><p><b>一句话带走：</b>区分有价；价由分布定；意义由蕴涵定；新由压缩定。</p></div>

<p><b>钩子。</b>如果一条原理能撑住四层，那么第二层——两个人为什么必须共用一套码——就是下一章的事。你会发现，共用不是善意，是账单。</p>
