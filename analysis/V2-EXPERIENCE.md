# V2 写作经验（第七十八—七十九轮，二十章实测）

> 不是编年史，是**可复用的手法与坑**。每条都来自这二十章的一次具体返工。
> 新会话开工前读这一页，比读十份交接更省时间。

---

## 1 字数与节奏

| 经验 | 依据 |
|---|---|
| **下限 8,000 汉字／章，不设上限**（作者定） | 二十章实测 8,056—10,829；平均 8,600 |
| **写到 8,000 的路径是“加一层”，不是“加一句”** | 每章从初稿 4,000—5,000 补到 8,000，靠的是加**机制层**（为什么这个式子长这样、参数依赖、三个可查推论），不是加形容词 |
| **每节 800—1,000 字，段 120—180 字** | 段太短会碎；太长会闷。二十章里被改得最多的就是“一段一句话” |
| **补字最容易的三个位置** | ①“这个式子为什么长这样”（推导一步）②“这一条什么时候误报/失效”③“可查痕迹与数据要求” |

## 2 开头：用真实案例，不用合成人物

- **第 I／II 部分**（个人轨）可以用人物；**第 IV 部分之后必须用有日期、有出处的案例**。
- 已用的真实开头：1956 纽瓦克港集装箱（11）／2026 插画师被标 AI（12）／工伤认定三方（13）／97 年弗朗提努斯接手罗马水道（14）／一块招牌换三次（15）／一家超市的十年（16）／县城快递网点（17）／2008 AAA 与米其林星（18）／1888 打字比赛与 QWERTY（19）／1992-07-02 鳕鱼禁捕（20）。
- **反面教材**：ch11—13 初稿用老陈货车／小林选题／小吴诊室开场，被作者判为“用错轨”，全部重写。

## 3 腔调：客观描述，不做评价

- 禁词之外，还有一类“评价腔”要改：**“赔的是命”“账本藏起来一半”“最伤人”**。
- 替换公式：**把评价句换成“谁付、付多少、怎么数”**。
- 机制句留（“这叫账被推给了不参与定价的一方”），道德句删（“这很残忍”）。
- 自我检查：每章读一遍，凡句子里有“应该／不应该／荒谬／可怜”，标出来重写。

## 4 V1 迁移：重构改写，不搬表

| 做法 | 反例 |
|---|---|
| 表随文走，表号按 V2 章重排 | 保留 V1 原号（4.4 出现在 4.1 之前） |
| 出处只写在 `datasrc` | 表题里写“（接 V1 表 3.1）” |
| 每处多写一层表外结论 | 把表贴上去就完事 |
| 跨章重复的写进正文，不单设表 | 同一张表在 ch04 与 ch06 各出现一次 |

**判据**：把这张表遮住，这一节的论证还站得住吗？站不住 → 表是论证环节；站得住 → 表是装饰。

## 5 图：按版心画，不按屏幕画

- 版心 **140 mm**；10 in 宽的图排进去只剩 52%，图内 8 pt 变 4 pt。
- **6.4 in 是最稳的画布**；内部字号 ≥7 pt（排进版心后约 6.5—7 pt）。
- 每张图三句话：左幅说什么、右幅说什么、**这一区分本身就是方法**。
- **`figure { break-inside: avoid }` 必须写在 `paper.css` 里**（此前图与图注会分页，已修）。

## 6 公式：`.mblock`，不用裸 `<pre>`

- 裸 `<pre>` 不设样式会撑宽 min-content，Chrome 打印时整册缩放。
- 多行式子用 `<br>`，不要用空格对齐。

## 7 常见返工（都发生过）

1. **表号与物理顺序不一致**（ch04：4.4 在 4.1 前）→ 用“按出现顺序重编号”脚本一次改完。
2. **`**` 残留**：写作时手滑写成 Markdown 粗体 → 收口必跑检查。
3. **`id` 重复**（ch08 两个 `sec8-2`）→ 检查器已加“id 唯一”。
4. **禁词误伤**：`必然` 出现在“必然结果”“统一必然发生”里 → 逐处改成“直接后果”“自然结果”。
5. **插入块把锚点吃掉**（ch01 的 `<h3 id="sec1-7">`）→ 插入脚本必须“先取出锚点、再放回”。
6. **`figure`/`figcaption` 分页** → 见 §5。
7. **图内文字重叠**：标注放四角、legend 放空处；每次改完肉眼看一遍渲染。

## 9 一句话

**每章三件事：一个真的开头、一条能数的机制、一处说得出的边界。三件齐了，8,000 字自然够；缺一件，写到 10,000 也空。**
