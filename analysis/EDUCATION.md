# 教育学：人文关怀那一侧的最佳落点

> 作者的直觉是对的，而且比"加一节教育讨论"更深：**教育学是这本书里"格由环境与预算给予"
> 最可见、最要命的地方**。它给第 27 章（代价由谁承担）提供了唯一能落到具体人身上的材料。
>
> 这份文件只做一件事：把四对教育学概念挂到 P1—P4 上，每对给一个可测差别。

## 0 为什么教育学是最好的人文落点

这本书的冷的一侧是码率与失真；**热的一侧必须回答"谁在承担"。**
而"谁在承担"最容易被看见的地方不是舆论场，是教室：

- 一个孩子分辨率的高低，**被时间（`T`）、睡眠（`λ`）与利害（`w`）同时决定**；
- 这三项的可支配量在人群里分布极不均，
- 所以**分辨率的不平等不是能力不平等，是预算不平等**。

这一句如果写实了，第 27 章就有了骨头；写虚了，就是 philanthropy 口吻。

## 1 四对概念，四张式子

### 1.1 皮亚杰：同化 / 顺应 = **不换码 / 换码**

| 皮亚杰 | 我们的量 | 判据 |
|---|---|---|
| **同化**（assimilation） | 保持 `q`，把新经验塞进旧划分 | `D(q,真)` 上升但 `D < C` |
| **顺应**（accommodation） | 换一个新 `q`，付一次性成本 | `D(q,真) > C` |

**这不是类比，是同一条不等式 `[P4]`。** 皮亚杰的贡献在于**时序**：他观察到顺应发生在某些年龄段。
我们能加的是一句可测的话：**顺应发生的时刻应由 `D/C` 的比值预言，而不是由年龄预言。**
→ 可测：同一批孩子里，"旧规则失效到换新规则"的间隔，应与该孩子累积的错误率成正比，
而不是与月龄成正比。**若月龄解释力远高于错误率，这条挂接就不成立。**

### 1.2 维果茨基：最近发展区 = **值得换码的那一段**

ZPD 是"自己做不到、有人扶就能做到"的区间。在式子里它就是：

$$C_{\text{在扶助下}} < D < C_{\text{独立}}$$

**扶助降低的正是 `C`**（失败的代价、试错的羞耻），不是提高 `D`。
**这就把"脚手架"翻译成了一个量：脚手架 = `C` 的临时下调。**

**可推的新预言**：`C` 越高的学习者，ZPD 越**窄**（因为窗口宽度 = `C_独立 − C_扶助` 的可达区间被压缩）。
→ 而"习得性无助"恰好是 `C` 被反复抬高后的结果：**它不是动机问题，是窗口关闭。**
→ 可测：连续失败后的再尝试率，应与 ZPD 宽度的收缩同步，而不是与情绪评分同步。

### 1.3 马顿：变式理论 = **训练分布决定 `δ` 的分配**

变式理论说：要让学生分辨某个维度，必须让**那个维度**变化，其他维度不变。
在式子里这是直接的 `[P1]`：最优码把比特分配给**信号分布里方差大的维度**。
**训练分布里没有变化的维度，最优码不会在那里花比特。**

**可推的新预言**：一个只在单一变式上练习的学生，其 `δ` 在**未变化的维度上是零**
（即：他分不出那些维度）。这不是"没学会"，是**最优码没理由学**。
→ 可测：同一知识点，用"单一变式"与"多变式"训练，测**未训练维度**上的迁移——后者应显著更好，
且差距 ∝ 该维度的方差差。

**这一条同时是教育公平的机制**：预算紧的学校只能提供单一变式（一种例题、一个语境），
于是学生的码在这些维度上**必然**是零——**不是天赋差，是训练分布的方差差。**

### 1.4 布卢姆：认知层级 = **`R` 的阶梯，不是难度阶梯**

记忆→理解→应用→分析→评价→创造，常被读成"由易到难"。在我们的式子里它是**码率阶梯**：

| 层级 | 我们的读法 | 码率 |
|---|---|---|
| 记忆 | 存**样本**（不压缩） | `R` 极高、`Δ` 极小（只覆盖见过的） |
| 理解 | 存**划分**（压缩） | `R` 低、`Δ` 宽 |
| 应用 | 把划分搬到新样本 | `Δ` 的检验 |
| 分析／评价 | 增加划分的**维度** | `R` 上升（多一维） |
| 创造 | 在**低 `w`、高 `T`**下重新分配比特 | 见 `REWALK` §7 |

**关键**：**记忆与理解不是难度不同，是"花码率的方式"不同**——一个是存样本，一个是存划分。
**这就解释了应试与理解的对立**：考试把 `w` 抬得很高（错一题代价大），
而 `v*=(T+λ)/(2w)` 说 `w↑ ⇒ v↓` ⇒ 码变细 ⇒ **在训练分布内更准、分布外更差**。

> **过拟合不是坏习惯，是高 `w` 下的最优码。**

→ 可测：高利害考试体系应在**训练分布内**表现更好、**分布外**更差。
这是一个可以用 PISA 数据与题型迁移测试直接检验的差别。

## 2 三条能写进第 27 章的话（都带限定）

1. **分辨率的不平等是预算的不平等**：`T`（有没有整块时间）、`λ`（睡够没有）、`w`（错了有没有人兜）
   三项都可测，且都可被政策直接改变。**这是这本书唯一能给出的可行建议。**
2. **"因材施教"的模型含义是高 `θ` + 高 `R`**：教师把每个学生的失真当成自己的失真（`θ`），
   并为此多花码率（`R`）。→ 班额是 `R` 的硬约束，不是态度问题。
3. **不要用"更努力"替代"换训练分布"**：按 §1.3，缺维度变化时，努力只会把 `δ` 在已有维度上继续压，
   **换不来新维度上的分辨力**。这句是本书对"鸡娃"最直接的回答。

## 3 与教育学既有结论的关系（不冒认）

| 既有结论 | 我们给的 | 档 |
|---|---|---|
| 变式理论（马顿） | 训练分布的方差决定 `δ` 的分配 | **可推**（P1 的直接推论） |
| 最近发展区（维果茨基） | ZPD = `C` 被下调后的窗口；习得性无助 = 窗口关闭 | **可推** |
| 同化/顺应（皮亚杰） | `D<C` / `D>C` | **可推**（P4） |
| 布卢姆层级 | 记样本 vs 存划分的码率差 | **对应**（层级内部的边界不清） |
| 文化资本（布迪厄） | —— | **不能**（缺"谁设定 `w`"这一维，见 `SUBSUMPTION-SOC`） |
| 成长型思维（Dweck） | 对应 `C` 的可塑性信念 | 对应，不可推 |

**教育学的可推率（3/6）介于社会学与心理学之间**，原因也一致：它有"划分"的对象（知识点＝划分），
但也依赖语义框（"什么算理解"）。
