## 0 一句话

V1 里至少有 **四种** 不同的“摆”，不是一种：

1. **`ν` 的摆**（波兰尼的双向运动）——爱／保护把代价拉回来；
2. **误解不对称的摆**（两个阵营，你硬我就软）——没有共同码；
3. **监管—分类的周期 2**（查得细则码细，查贵了则放松）——制度层的反相；
4. **“厌倦”的阈值反转**（求序压过求胜，过了阈值不回头）——注意／权重的台阶。

V2 第三部分若只写“`κ` 与 `γ` 的相位差”，会把四种摆压成一种。**正确做法是：先认出这是哪一种摆，再决定用哪个量。**

## 2 四种摆，不是一种

### 2.1 `ν` 的摆：代价推出去，再拉回来

波兰尼的“双向运动”在 V1 里已经被读成 `ν` 的摆动：市场把代价推出去（`ν` 下降、外置上升），社会用保护性立法把它拉回来（`ν` 回升）。这不是人心摇摆，是**迟滞环在时间上的重复**：推出去要付一次成本，拉回来也要付一次；两次成本之间，就是“摆”的幅度。

**V2 写法**：第 7 章讲爱时，不要把波兰尼写成“历史规律”，写成“`ν` 的一个可查形状”：保护性立法出现的时点，应当滞后于代价外置的峰值；滞后长度与 `C` 同向。**不能主张**：这个周期有多长（V1 ch04 已说“给不出周期为什么是这个长度”）。

### 2.2 误解不对称的摆：你硬我就软

ch06 的摆不是 `ν`，是**两套码的反对称误解**：A 眼中的 B 与 B 眼中的 A 不是同一个量；若反对称部为主，双方的最优回应不会收敛，会周期性摆动。政治学的“政策摆荡”、舆论场的“三天一变”，都可以用这个机制读，不必用“情绪”解释。

**V2 写法**：第 8 章讲好奇时，把“摆”分成两种：一种是 `ν` 的摆（爱／保护），一种是误解的摆（两套码）。**不能主张**：我们测过反对称部——V1 明说“没有测”；这条只能算“机制上说得通”。

### 2.3 监管—分类的周期 2：查得细则码细

ch20 的摆是**制度层的反相**：检查者查得细，被检查者的码就细；查得贵，检查者放松，码又变粗；码粗了又值得查细。两方交替最优回应，跑出周期 2，幅度很小（0.07 格），但形状可判：监管强度与分类粒度应当反相运动。`C`（改分辨率的成本）会把摆动压小。

**V2 写法**：这是“摆”的第三种，和第 8 章的“好奇—从众”不是同一个东西。它可以作为“制度也会摆”的实例，但不要把它硬塞进 `κ/γ` 的相位差。**不能主张**：现实里的监管一定周期 2；V1 说的是“交替最优回应的形状”，不是历史读数。

### 2.4 厌倦的阈值反转：不是周期，是台阶

ch22 的“厌倦”不是情绪，是**过了阈值之后不再回头的权重反转**：冲击被卷积、积分、过阈值，“求序”压过“求胜”，然后不回头；形状是台阶，不是斜坡；阴影带是 `C` 撑出的迟滞区。

**V2 写法**：第 8 章要把“回摆”与“不回头”分开：`ν` 的摆和误解的摆是“来回”；厌倦是“过去就不回来”。两者都用 `C`，但一个是环，一个是台阶。**不能主张**：厌倦一定有固定周期；V1 明说它是 C 级示意，参数未估。

## 3 和 E4 的关系

E4 是这次最小模型补的一条：

```
γ_t = γ0 + b·(novelty_{t−lag} − 0.5)
```

它给出**周期 18／28 步**（`b=2`，lag=5／10），但它不是 V1 四种摆中的任何一种。它更像 **ch22 的“厌倦”** 的连续版：新奇高→下一期从众升；从众高→下一期新奇又升。区别是：ch22 是阈值反转（台阶），E4 是滞后反馈（周期）。

**所以 V2 正文要写清三件事：**

1. **V1 已经有四种摆**，不要假装“摆动”是新发现；
2. **E4 是第五种**，是一条新假设，标 C；它能生成周期，但不解释周期为什么是这个长度；
3. **第 8 章只选一种主机制**，其余三种作对照；不要一章里把五种摆都讲一遍，那会变成“什么都能摆”。

## 5 不要做

1. **不要**把四种摆压成一句“社会会摇摆”。四种机制不同，混在一起会变成“什么都能解释”。
2. **不要**把 E4 写成 E2 的自动结果。E4 是新假设；正文必须同页写。
3. **不要**把“周期 18／28 步”写进正文当读数。它是 C 级模拟值，只能放在“最小模型”框里，不能当历史周期。
4. **不要**为了“摇摆”删掉 V1 的旧句子；旧句子是最好的入口，先接上，再补 E4。
5. **不要**说“波兰尼证明了 `ν` 的摆”。波兰尼给的是历史叙述；`ν` 的摆是本书的读法，标 C。
