## 2 三条 grep（必须归零）

```bash
# ① 计数与罗马数字部分号
grep -rn "七部分\|三十三章\|第 V 部分\|第 VI 部分\|第 VII 部分" source-v2
#   → 仅剩“第七部分　文明”这类合法命中（中文部名本身含“七部分”三字）；罗马数字 0

# ② 旧口径
grep -rn "半通\|两条半\|完全补足\|第五层\|七个模块" source-v2
#   → 0（“不是第五层”这一句是刻意的否定式，已单独标注）

# ③ ω 同名不同义
grep -rn "ω" source-v2/ch30.html source-v2/appendix_a.html
#   → ch30 的 ω 是“推断占比”（原义）；appendix_a 只在注里提一句“第 30 章的 ω 是推断占比”
```

**ω 的处理**：多层权重改记 **ζ<sub>LL′</sub>**（ζ 此前全书未用），并在 A.12 就地加注“ζ 只用于多层权重；第 30 章的 ω 是推断占比，两者不同名同义”。没有用 α（已是线性响应）、也没有用 Λ（已是当期损失）。
