# 推导的六处未封口：把链条接到定理上

> 作者判断：「完整的数学推导还没打通。」这一份先把「没打通」定位到六处，
> 每处写三样：**缺的是什么定理** → **接上以后得到什么** → **它换来哪条可检验的预言、付什么代价**。
> 只写能算的；算不出的老实标出来。
>
> 定位口径：原理一＝预算下的划分极小化（P1、P2，带出 P3、P4）；原理二＝账可外置（P6）。
> 现有的接缝在附录 A.1（驻点）、A.3（势与梯度流）、A.4（γ*=δ）、A.5（C=F₀）、A.7（三方程）。

## 0 六处接缝，一句话各一条

| # | 接缝 | 现在怎么说的 | 缺的东西 | 封口后的形态 |
|---|---|---|---|---|
| **J1** | 划分 → 标量 `v` | "取高斯信源，`v` 就是方差" | 高分辨率量化定理（Zador／Bennett） | `D = c_p·2^{-2R}`，指数是定理，常数看分布形状 |
| **J2** | 单码 → 类别数 `k` | `R = log₂k`（只算块数） | **块的边界也要描述**（边界成本 `b`） | `k*` 有闭式；**赌注加倍 ⇒ 类别数 ×√2 或 ×2^{1/3}** |
| **J3** | 多稳 → 迟滞 | 两件事常被写混 | 分开两把尺子：`C` 定宽度，`ΔΦ/β` 定速度 | 宽度＝2C（与势垒无关）；切换时间 ∝ e^{ΔΦ/β}（Kramers） |
| **J4** | 群体 → 社会 | 书里明说"没有桥" | 图上的平均场（Gibbs 测度） | `γ·z > δ`；`z` 换成谱半径 ⇒ **枢纽说了算** |
| **J5** | `ν` 从哪来 | 当作给定 | 委托人问题（Stackelberg） | `ν` 内生；**执法越便宜，外置越多** |
| **J6** | `ν<0` 的收益有没有上限 | 只说"目标可能无界" | 一行的界 | 上限＝`|w|·Var(X)`；**外置集中在方差大的领域** |

前四条属原理一，后两条属原理二。**没有一条需要第七个公设**——它们全是"把已有的话接到已有定理上"。

## 1 J1：从"划分"到标量 `v`，缺的是量化定理

**问题。** P2 说规则是一次划分；A.1 却把 `v` 当方差，`R = ½log(σ²/v)`。从"划分"到"一个标量"这一步，书里叫"投影"，但没证。

**缺的定理（已有，1948／1966）。** 设信源密度 `p(x)`，码本把支撑切成 `k` 个区间，重构取块内条件均值，失真取平方误差。**高分辨率渐近**（Bennett 1948；Zador 1966；Gersho 1979）：

```
D_k = c_p · k^{-2} + o(k^{-2}),     c_p = (1/12)·( ∫ p(x)^{1/3} dx )³
```

**于是 `R = log₂k` 给出 `D = c_p·2^{-2R}`。** 书里那条关系因此不是假设：

- **指数是定理级的**：`2^{-2R}` 与 Shannon 下界 `(σ²/2πe)·2^{-2R}` 同指数；
- **常数是形状依赖的**：`c_p` 由 `p` 的"胖瘦"决定，高斯时最小（这正是"高斯情形失真等于方差"那句话的准确版本）。

**这一接换来三条。**

1. **比较静态一条都不变**：`∂v*/∂w < 0`、`∂v*/∂(T+λ) > 0` 只用指数，与 `c_p` 无关。**这是好消息：书里所有符号预言不需要重证。**
2. **新预言（低码率破缺）**：`k^{-2}` 是渐近律。`k=2` 时真实失真通常是"一块码"（一刀不切）的 0.35—0.50，而 `k^{-2}` 预测 0.25。**所以模型在 `k≤3` 时会低估失真、高估"再切一刀"的收益**——它预测人应当比实际更细。这一条可查：找只用两三个类别的人（分诊三级、信用分档、学历三档），看他们的 `v` 是否系统性地比模型预测更粗。**若真如此，`k^{-2}` 要在 `k≤3` 处换成精确的最优量化表（可算，一维情形有现成算法）。**
3. **一个说法要改**：书里"格子越少，事到临头越容易分错"是对的方向，但**边际收益递减得比直觉快**（第 `k` 刀的收益 ∝ `k^{-3}`）。这解释了为什么"再加一档"常常不值——不是因为懒，是因为第 `k` 刀的边际收益本来就小。

## 2 J2：类别数 `k` 的上限从哪来——缺边界成本

**问题。** 书里 `R = log₂k`，只算"有几块"，没算"**每块在哪儿**"。而一个划分要能被写下来、传下去，**边界位置本身也要码**：`k−1` 个切点，每个约 `log₂(Δ/ε)` 位。

**把它写进去。** 令 `b` ＝ 每个切点的描述成本（位／块）。总账：

```
J(k) = w·c_p/k²  +  (T+λ)·[ log₂k + (k−1)·b ]
```

一阶条件 `dJ/dk = 0`：

```
2 w c_p = (T+λ)·k²/ln2 + (T+λ)·b·k³
```

**两个极限，各给一条标度律。**

| 边界成本 | 最优类别数 | 赌注的弹性 |
|---|---|---|
| `b = 0`（切点免费） | `k* = √( 2 w c_p ln2 /(T+λ) )` | `d ln k*/d ln w = 1/2` |
| `b` 支配（切点很贵） | `k* ≈ ( 2 w c_p /((T+λ) b) )^{1/3}` | `d ln k*/d ln w = 1/3` |

**这是这一份里最值得写进正文的一条。** 它有三件好处：

1. **解释了一个此前没有解释的事实**：人的类别数在 `10²—10⁴` 量级，而不是 `10⁶`。原因不是"人笨"，是 **`b > 0`**：切点也要记。`b` 才是"词汇量有上限"的那个参数。
2. **给出一个可以被两种答案否证的预言**：把赌注 `w` 抬高十倍（真奖金、真追责），类别数应涨 `√10 ≈ 3.2` 倍（若切点便宜）或 `10^{1/3} ≈ 2.2` 倍（若切点贵）。**两个指数都能被打**，而"多给钱就分得细"这种无指数说法不能。
3. **顺手解释了 `R ≥ log₂|A|` 这条界为何"只是界"**：真实描述长度是 `log₂k + (k−1)b`，线性的块数项在 `k` 大时被三次项压过去——**所以最优 `k` 一定存在、且不会太大**，不需要另外加"认知上限"这种假设。

**代价（要写在同一页）**：`b` 没有直接读数。可用的代理是"教一个人一套新分类要多久"（切点是要教的，块名不必），或"分类表改版的工作量"。**没有 `b` 的估计，上面两条标度律只能当"两种可能"读，不能当"预测"读。**

## 3 J3：多稳不等于迟滞——缺"两把尺子"

**问题。** 书里 A.3（势函数、多个局部极小）与 A.5（带宽＝2C）常被读成同一件事。**它们在数学上是两件事。**

- **多稳**来自 `γ` 项的非线性（势函数出现两个极小）——**没有换码成本，一样多稳**；
- **迟滞（带）**只来自固定成本 `F₀`：**没有 `F₀` 的系统在 Maxwell 点一次跳过去，带宽为零。**

**两把尺子因此分开：**

| 量 | 由什么定 | 决定什么 | 可查形式 |
|---|---|---|---|
| 带宽 `2C`（`C=F₀` 归一后） | **一次性的换码成本** | **在哪儿翻** | 两阈值之差；图 20.1 的 3.6—6.0 |
| 势垒 `ΔΦ` | `γ` 项造出的两个极小之间的落差 | **多快翻** | 切换时间 ∝ `e^{ΔΦ/β}`（Kramers 1940） |

**换来的预言（一条新的、可查的）**：**同样的带、不同的噪声 ⇒ 翻的位置一样，翻的时间差指数级。** 具体查法：找两个 `F₀` 相近、但噪音环境不同的共同体（同样严格的行业规范，一个在稳定市场、一个在动荡市场），比较"规范改变的时间分布"：位置（阈值）应当重合，尾部（多快改）应当差一个数量级。**这是书里第一次把"突然性"与"宽度"分开写，而且两者各有参数。**

**代价**：Kramers 律要求噪声是可加的、势垒比 `β` 大；书里的 `β` 是"选择噪声"，与"环境噪声"是不是同一个 `β`，**没有交代**——这一条必须写清，否则就是把两个 `β` 偷偷并成一个（这是全书第八个坑的同类错误）。

## 4 J4：群体 → 社会，缺的是图上的平均场

**问题。** 书里说"第三层没有博弈、第四层只有一条桥"。其实**第二层到第三层这一段，标准工具已经存在**：把 P3 的一致性代价放到图上，取平均场，就得到 Gibbs 测度与序参量——**而 A.4 的 `γ*=δ` 是它的特例。**

**推。** 两码（A 较差、差 `δ`；B 较准），个体 `i` 的目标：

```
u_i(A) = −wδ − γ·N_B(i),        u_i(B) = −γ·N_A(i)
A 是最优反应  ⟺  γ·(N_A(i) − N_B(i)) ≥ wδ
             ⟺  Σ_{j~i} x_j ≥ wδ/γ          （x_j = +1 若 j 用 A）
```

平均场（`Σ_{j~i} x_j ≈ z·m`，`z` ＝ 平均度，`m` ＝ 序参量）加 Logistic 噪声（强度 `β`）：

```
m = tanh( β( z·γ·m − w·δ ) )
```

**三条结果。**

1. **临界条件 `β z γ = 1`**，即 `γ_c = 1/(β z)`。**同样一套规范（同样的 `γ`），连接更密的社会更容易锁死**——而稀疏社会解套。书里 A.4 的 `γ* = δ` 是 `z=1` 的一对一情形，**因此 A.4 不再是独立假设，而是平均场的一个特例**。
2. **异质图上 `z` 要换成邻接矩阵的谱半径 `λ_max`**（阈值现象的通用结果：Granovetter 1978；Pastor-Satorras–Vespignani 2001）。尺度无关图上 `λ_max` 由枢纽支配 ⇒ **少数高连接节点决定相变位置**。**这是"评价权 `Φ`"第一次有了一个可算的上界**：`Φ` 的影响不超过 `λ_max` 的特征向量所能动员的那一部分。
3. **它与 A.7 那句"中心性 ≠ Φ"可以对表了**：中心性是**结构**的，`Φ` 是**制度**的；但当制度席位与特征向量重心高度重合时，两者可互读——**判据是余弦相似度，是一个数，不是一句话。**

**代价（必须写）**：平均场忽略了涨落与有限规模，**近临界点附近会错**（真实网络的临界指数与平均场不同）；而且它要求 `γ` 只在边上起作用（书里 ch16 的"连通分量"正好是这条的直译）。所以这条桥的适用范围是：**远离临界、或完全图**；临界附近只能给方向。

## 5 J5：`ν` 不能当作给定——把委托人写出来

**问题。** 原理二说"账可以外置"，但 `ν` 是谁定的？书里把它当环境。**不写委托人，ch27 那条链就只是七个环的排列。**

**写。** 委托人选 `ν`，承担执行成本 `E(ν)`（递增、凸），并对外置出去的那部分损失 `L` 不负全责：

```
max_ν  A·q( v(ν) )  −  ν·L  −  E(ν),       v(ν) = (T+λ) / (2w₀(1−ν))
```

一阶条件：

```
A·q'(v)·v'(ν)  =  L + E'(ν)
```

**比较静态三条，都可查：**

1. **执法越便宜（`E'` 小），外置越多**。检验：两个评价权同样集中的制度，一个执法成本低（有现成的登记与追责系统）、一个高，`ν` 应当不同——**这是 ch27 第一环"Φ→ν"缺的那一步：Φ 只给能力，`E'` 才给意愿。**
2. **被外置的损失越大（`L` 大），外置越多**——所以外置集中在"后果严重"的领域（安全、环境、金融），而不是均匀分布。
3. `q` 有下界（噪声地板 `σ_n`，ch03 §3.8），因此 `q'` 在极粗处趋零 ⇒ **`ν` 不会跑到 1**：再外置，代理人已经粗到没法更粗，委托人自己也受损。**这是"外置有上限"的第二个来源**（第一个见 J6）。

**代价（必须写在同页）**：这一步引进三个新对象（`A`、`L`、`E`）。它们**不是新公设**（不是关于"人怎么想"的假设，而是委托人目标函数的三个系数），但**它们都不可测**——所以 J5 的意义是"把 `ν` 从假设降为可讨论的对象"，不是"把 `ν` 估出来"。

## 6 J6：外置的收益有上限——一行的界

**问题。** A.9 写"目标函数可能无界"。**其实不会。**

**界。** `ν<0` 时，代理人想最大化失真。但码是有限的：**最粗的码是一刀不切**，其失真为 `D_max = Var(X)`（把一切都当同一类，误差就是总方差）。于是

```
外置能拿到的最大好处  =  |w|·Var(X)
```

**换来的预言（便宜、可查）**：账外置**集中在"结果差异大"的领域**——金融、安全、环境、医疗；而在"结果都差不多"的领域（例行的、标准化的）几乎没有外置空间。**这是原理二的第一条可查的形状，而且不需要任何新数据。**

**顺带修一处**：A.9 的"可能无界"要改成"有界，界是 `|w|·Var(X)`"。这不削弱原理二，反而让它更锐：**外置不是万能的，它受信源方差的限制。**

## 7 一条共用的识别引理（把两处"只有比值可识别"合成一条）

书里两处都写着"只有比值可识别"：`v*` 里的 `T+λ` 与 `w`、`γ*` 里的 `γ` 与 `δ`。**它们是同一条引理的两个实例：**

> **凡以比值进入结论的量，单一情境只能识别比值；要分开，必须找第二个改变分母的情境。**

| 要分开 | 单一情境只能识别 | 第二个情境要动什么 |
|---|---|---|
| `T+λ` 与 `w` | `(T+λ)/w` | **信源模糊度 `D`**（清晰／模糊刺激两批） |
| `γ` 与 `δ` | `γ/δ` | **平均度 `z`**（密网／疏网两个共同体） |

这条引理值得写进 ch26 的识别一节：**它把"不可识别"从一句谦辞变成了一个可执行的实验设计。** 而且它解释了一个方法论事实：**为什么书里那些"用睡眠债校准 `λ`、用量表校准 `T`"的做法站不住**——它们都没有改变分母。

## 10 J7（本轮补）：反身性的 `g(·)` 不再是空的

第 9 节留的那一句「`μ_{t+1}=μ_t+ε·g(q_t)`，而 `g` 是空的」，可以填掉大半。**做法不是加一个假设，而是问一句：被分类的人在被分类之后做了什么？**

**设定。** 码 `q` 给出标签 `ℓ=q(x)`；他人按标签处置（信贷、录用、排班、入学、巡查），记 `t_ℓ`；被分类者选一个动作 `a`（投资、努力、申报），代价 `c(a)`，收益随处置升。一阶条件给 `a* = a*(t_ℓ, x)`，产出 `y = a* + x`。于是

```
E[y] = E[ a*( t_{q(x)} ) ] + E[x]
```

相对「没有这条码」的情形（处置记 `t̄`），下一期的均值位移是

```
g(q) = β · [ t̄(q) − t̄ ],      β ≡ ∂a*/∂t,      t̄(q) ≡ Σ_ℓ P_μ(ℓ) · t_ℓ
```

**一句话：反馈强度＝行为对处置的弹性；反馈方向＝处置差的方向。** 于是 `ε` 不再是一个自由参数——它有一个可测的对应物（处置变动引起的行为变动）。

**三条推论，都可查。**

1. **自我实现需要三件事同时成立**：标签与 `x` 相关；处置按标签分档（`t` 有差）；行为对处置有弹性（`β≠0`）。缺一条，预言不会自我实现，只会变成噪声。**三条各是一个断环点。**
2. **符号由政策定，不由人心定。** 若低预测的那一格拿到**更少**的处置（`t_A < t̄`），位移向下，预言自我实现；若给的是**补偿**（`t_A > t̄`），位移向上，预言被侵蚀。同一批人、同一个偏见，只换处置符号，结论反过来。
3. **强度决定收敛还是摆动。** 设两格差距 `Δ`，补偿强度 `c`（`t_A − t̄ = −cΔ`），则 `Δ_{t+1} = (1 − βc)Δ`。**收敛当且仅当 `0 < βc < 2`；`βc > 2` 时差距来回摆。** 所以「补偿太猛会反弹」不是道德判断，是一个稳定性条件。

**自洽与多解。** 码在下一期会被重新估（统计歧视的做法）。若 `q ∈ argmin_{q'} [ w·D(q', μ(q)) + (T+λ)R(q') ]`，称 `q` **自洽**。码集有限 ⇒ 自洽码必存在；但**周期 2 的循环也可能**——这正是「标签来回换」（同一批人隔几年换一个正当的词）。而若两个不同的划分同时自洽（目标函数在两者之间近乎平），就是第 23 章那种「两套码并存」——**它不需要两个群体，只需要两个自洽解。**

**没填的（三件，按重要性）。**
1. **内容**：`g` 给位移的大小与方向，不给「该用哪个词、边界划在哪」。那是语义，与第 26 章第四件同一处空白。
2. **身份通道**：这里的 `a` 是行为；还有一条更慢的通道——被分类者改变**自己的码**（不认那一格、另起一个词），那动的是 `q` 而不是 `μ`，本节没写。
3. **排序**：两个自洽解哪个更好，本节答不出。要排序得有一个不随 `q` 变的 `w`，而 `w` 本身可能被 `q` 定（退回原理二）。

**能不能被打掉。** 若在处置被外生改变（政策变动）、标签不变的情形下，被分类者的行为与产出分布**不动**，那么 `β=0`，`g` 归零，反身性在这批人身上不成立。**这是一条干净的否证条件，比「反身性很重要」这句态度有用。**

## 11 封口判决（2026-11-19，V2 第七十八轮）

> 问题：这六处（加上 `I(q)` 与四层＝RG）**能不能封**？"封"分三档，不许混：
> **① 可封**＝接上已有定理，正文可以写成定理（带条件）；
> **② 条件封**＝写成"给定某条件即定理"，条件本身没有代理或没有数据；
> **③ 不能封**＝要么需要第七个公设，要么需要本书没有的测量，只能降级声明。

### 11.1 "自然涌现"在这本书里的准确含义

**涌现＝宏观量是解出来的，不是写进去的。** 判据只有一条：把个体规则与网络给定，宏观结构是否**从极小化／动力学里出来**，而不是在目标函数里预先出现。按这条判据，第三部分那五件事的现状是：

| 现象 | 现状 | 为什么 |
|---|---|---|
| **群体（边界）** | **真涌现（定理）** | `γ*=δ` 从"重标号不变 ⇒ 对称距离 ⇒ 势博弈 ⇒ 复制子"推出来（A.2—A.4）；边界不是写进去的 |
| **社会摆动** | **条件涌现** | E2 未通过、E4 条件通过（周期 18／28 步）；要成定理，需要显式的相位动力学（`κ` 与 `γ` 的时标比），本书只给了"摆"的四种旧机制＋一种新机制 |
| **文明特质** | **描述性** | 五个量（`μ、ν、κ、H、C`）是记账口径，不是从个体规则解出来的；要成涌现，得先有跨政体的测量协议 |
| **文化同化** | **部分** | 重叠主项通过；强桥之后 `ν`／`C` 仍不稳 ⇒ 桥的识别没做 |
| **社会品味** | **条件涌现** | `κ` 通过、`A` 控制 `κ` 后通过；完整模型被更强的混杂盖住 |

一句话：**五件里一件是真涌现、两件是条件涌现、两件还是记账。** 把"五件全通"写成结论，是把条件写成定理——这正是 `AGENTS-DERIVATION` 禁止的第六个公设式偷渡。

### 11.2 封口顺序（按"改一句就变硬"排）

1. **P0（当版可做，不需新数据）**：J1 的适用域、J6 的一行界、`I(q)` 的概念格写法、`γ*=δ` 升格为定理 —— 四件都是"把已有的话接到已有定理上"。

### 12.2 P1（两条落地，一条仍未）

**① J2 的 `k*`：从"缺一条"变成"一张能查的算术表"。** 账写成 `J(k)=w·c_p/k²+(T+λ)[log₂k+(k−1)b]`，脚本 `analysis/derive_kstar_table.py`，结果进 **ch06 表 6.2**、`data/derived/kstar_table.json`。三条结论：

- `b=0` 时赌注加倍 ⇒ `k*` ×**1.414**（正好 √2，即 T3 的 ½ 指数）；
- `b` 变大把倍数压下来：`b=0.5` ⇒ ×1.35，`b=2` ⇒ ×1.06 —— **边界越贵的领域，加赌注越换不来更细的分类**（法律、税则、临床路径）；
- 角点：`b=1` 时 `w<1.37` 最优就是 `k*=1`（一刀不切）——**满意化是角点，不是心理学描述**。
- 仍缺：`b` 的独立代理。已给方向（同一批规则的两次修订：只加边界 vs 只改措辞），但**没有面板**。

**② J4 的误差倍率：平均场错多少，算出来了——而且结论反直觉。** 脚本 `analysis/derive_meanfield_error.py`，结果 `data/derived/meanfield_error.json`。平均场把临界条件里的 `⟨k⟩` 当成谱半径 `λ_max`，误差倍率就是 `λ_max/⟨k⟩`：

| 图 | `⟨k⟩`=4 | `⟨k⟩`=8 | `⟨k⟩`=16 |
|---|---|---|---|
| ER（度不均匀） | **1.315** | 1.147 | 1.063 |
| WS（度均匀、有聚类） | 1.000 | 1.000 | 1.000 |

**误差源是度分布的不均匀（枢纽），不是聚类。** ER 上 `⟨k⟩` 小时倍率高（平均场把阈值放宽三成），`⟨k⟩` 大时趋于 1；WS 上环图正则、谱半径恰等于 `k`，聚类再高倍率仍是 1。<b>所以"小圈子会放大惯性"这个直觉，在二次型一致性代价下是错的；放大惯性的是"有人认识很多人"。</b> 落点：第 IV 部分写群体层时，把 `γ·⟨k⟩>δ` 旁边并排写上 `γ·λ_max>δ`，并注明两者的差就是上表。
