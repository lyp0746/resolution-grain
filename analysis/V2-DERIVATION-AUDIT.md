# V2 推导总检：主链通，但要把假设亮出来

> 2026-11-19。最后走一遍：第一性原理 → 公设 → 数学模型 → 个人 → 群体 → 社会 → 文明网络。
> 结论先说：**逻辑链是通的；漏气的地方不是推理，是“未声明的建模假设”。把假设亮出来，书会更硬，不会更弱。**

---

## 0 一句话

**“一条原理”能生成方向，但不能单独生成 `v*` 的具体形式。** `v*` 依赖失真形状；`I(q)` 依赖特征集；`w(P,A)` 依赖线性响应；`Φ` 依赖制度成本；核实三角依赖生产技术；`κ` 依赖 Wundt 曲线。建议口径改成：

> **一条原理＋五个建模假设＋一个网络约定。**

不是退让，是把“可被攻击的点”从暗处搬到明处。

## 3 五处主要漏气

### 3.1 `v*` 依赖失真形状

`v*=(T+λ)/(2w)` 不是 A1 单独推出的；它依赖：

- `v` 是“宽度”还是“精度”；
- `D(v)` 是二次、线性、还是其他；
- 成本是 `(T+λ)log(1/v)` 还是 `(T+λ)log k`。

**修法**：在 A1 后加一条 **A2 失真形状**，明确 `D(v)` 与 `v` 的定义；`v*` 标为“在 A2 下的定理”。换形状，系数/指数变，方向不变。

### 3.2 `I(q)` 依赖特征集

一个划分 `q` 只给格；不给“从这一格能推出什么”。`I(q)` 需要形式背景 `(G,M,R)`：对象、特征、关系。**没有 `M`，`I(q)` 不唯一。**

**修法**：把 `I(q)` 写成 `I(q; M,R)`；在正文里至少给一个真实案例的 `M`（AI 标签：`A/O/C/M` 四个特征）。语义章不能只说“蕴涵集”，要给出特征表。

### 3.3 `w(P,A)` 的线性响应是假设

`w_i=w_i⁰+α(AP)_i−βP_i` 是最小线性响应；生态、经济、军事、历史各有不同函数形式。**存在性**是定理；**形式**是假设。

**修法**：标为“线性响应假设”；给四条特殊化（生态/经济/军事/历史）；用 `A` 的外生冲击做识别。

### 3.4 `Φ` 与核实技术仍是制度/技术子模型

`Φ` 三件套、`C_Φ`、`H`、`a(e,s)`、`τ_v(e)`、`C(e,s)` 都是**子模型**，不是 A1 的推论。它们让第6、8章能“自然涌现”，但仍是假设。

**修法**：在 V2 里明确“制度子模型”和“核实技术子模型”；给代理与判决线；不要写成“从第一性原理推出”。

### 3.5 四层＝RG 是形式类比

`q_{l+1}=R_l(q_l)` 是一个有用的形式类比，但没有证明四层是同一状态空间的粗粒化。**不能称定理。**

**修法**：保留“形式类比”标签；在正文里只用作组织语言，不用作证明。

### 3.6 爱与好奇的“涌现”仍是假设

`ν`、`κ` 在个体层可写；但群体、社会摆动、文明特质、文化同化、社会品味，目前是**涌现假设**，不是推导。它们需要显式动力学与案例检验。

**修法**：第三部分每章先写“个体层定义”，再写“群体/社会/文明涌现假设”，每条给一个可查案例与一条判决线；不要用“因此”把假设写成结论。

## 4 建议口径

正文可以继续讲“一条原理”，但在“本书主张”与附录里写：

> **一条原理（有限区分）＋五个建模假设（失真形状、线性响应、语义特征集、制度成本、核实技术）＋一个网络约定（无向图/二次型）。**

这样既不放弃“少假设”的叙事，也不把假设藏在“定理”后面。
