# 从变分与对称到四层：涌现到底在哪一步发生

> 作者问：**从公设出发，个人—群体—社会—文明这条链通了吗？能不能自发涌现？得到的形式好用、符合现实吗？**
> 这一份给判定：**通到第二层（涌现是导出的），第三层在平均场＋两时标意义下通，第四层不通——而“不通”的那一处正好是语义。**
> 判定之后给三条能用的形式：相变阈值的来源、敏感性 χ、临界慢化（早期预警信号）。

---

## 0 判定表

| 层 | 涌现出来的是什么 | 通不通 | 靠什么闭合 | 现实里的对应 |
|---|---|---|---|---|
| **L1 个人** | 一个驻点 `v*`，及其比较静态 | **通** | 变分极小（A.1）＋量化定理的指数 | 利害↑则细、疲劳↑则粗；有实验支撑 |
| **L2 群体** | **一个共享码**（多数被自发选中）、多重均衡、极化 | **通** | 份额自由能含熵项；**误解矩阵 `D` 的非正定结构**给出分裂方向 | 从众、规范、极化；阿希类实验 |
| **L3 社会** | 敏感性 `χ`、**临界慢化**（方差与自相关上升）、迟滞 | **半通** | 平均场＋两时标消去；**要原理二（账）才有一半变量** | 信任/规范转折前的“越来越不稳”；生态与金融里已验的预警信号 |
| **L4 文明** | **词表本身**（有哪几套码） | **不通** | 需要“码的先验”——即语义 | 分类表更新、行业词表换代 |

一句话：**涌现发生在 L2，而它是“不同意的价钱”造出来的，不是外加的。L3 要借两时标。L4 缺的那一样是语言。**

## 1 L1 个人：变分给驻点，定理给指数

`min_q w D(q) + (T+λ)R(q)`，高斯情形 `R = ½log(σ²/v)`，一阶条件给

```
v* = (T+λ)/(2w)
```

这一步没有争议。**唯一要补的**（已写进附录 A.1 与第 6 章 6.14）：`D ∝ 2^{-2R}` 的**指数**是定理（Zador／Bennett），**常数**看信源形状；`k^{-2}` 是渐近律，`k ≤ 3` 会破缺。

**L1 有没有涌现？** 没有——一个驻点不是涌现。涌现从这里往上才开始。

## 2 L2 群体：涌现是“分歧要付钱”的直接后果

### 2.1 份额层的自由能

把 P2（规则＝划分）落到一组有限码 `Q = {q_1…q_m}` 上。群体状态是份额 `P`。取

```
𝓕[P] = Σ_q P_q·h_q  +  (γ/2)·Σ_{q,q'} P_q P_q' D(q,q')  −  (1/β)·H(P)
        └ 准确度的价 ┘   └──── 分歧的价 ────┘            └ 选择噪声的熵 ┘
```

其中 `h_q = w·D(q, q*)`。**这就是一个平均场模型的自由能**：`q` 是“自旋状态”，`h` 是外场，`D` 是相互作用矩阵，`β` 是逆温度。**所以第 5 章那个“分布泛函”不是自造的——它是 Gibbs 自由能，而第 6 章的复制子方程是它在 Shahshahani 度量下的梯度流（A.3）。**

### 2.2 为什么会有相变：一个此前没写出来的关键结构

`D` 是一个**对角为零、非对角为正**的矩阵（同一套码之间不付费，不同码之间付费）。**这种矩阵不定**：它在“混合方向”上有**负特征值**。

于是那一项不是“让分布更分散”，而是**惩罚混合**：`Σ_{q≠q'} P_qP_q'D(q,q')` 在均匀分布处取最大值，在“全押一套码”处取零。**换句话说：这套模型里出现双稳，原因不是“人喜欢从众”这条心理学事实，而是“不同意要付钱”这条代价结构本身。**

一阶条件（在单纯形内极小）：

```
P_q ∝ exp{ −β[ h_q + γ·Σ_{q'} P_{q'} D(q,q') ] }
```

均匀解 `P = 1/m` 失稳的条件是：**`βγ·|λ_min(D)| >` 熵的曲率**。两码情形退化为

```
βγ·D_AB > 2      （“内点不稳”，即双稳）

# 而 A.4 的 γ > δ 是另一条、管另一件事：
#   γD_AB > wδ  管“有没有内点”（代价比较，与噪声无关）；
#   βγD_AB > 2  管“那个内点稳不稳”（噪声压不住才是双稳）。
# 两条合起来才叫多稳。以前把这条并成一条，是本轮修掉的一个错。
```

三条后果，都是导出的，不是假设的：

1. **自发涌现**：越过阈值，**某一个码被群体选中**，而“选哪一个”在准确度相近的码之间是任意的（对称破缺）。**“共享码”这个对象不在任何一个人的目标函数里，它在群体层出现**——这就是涌现。
2. **多重均衡**：对称破缺的方向不止一个，于是同一套价格下可以有两个以上稳定态；`A.4`、`16.5`、`20.x` 说的“双稳”都是它的实例。
3. **阈值可算**：阈值由三样乘起来决定——`β`（噪声）、`γ`（一致性代价）、`|λ_min(D)|`（误解结构）。**所以“同样一套规范，换个误解结构就可能不锁死”**，这句话现在有式子。

### 2.3 与图上平均场的关系（A.10）

份额层是“完全混合”的版本；把 `γ` 放到边上（`A_ij`），平均场给出

```
m = tanh( β( zγm − wδ ) ),   γ_c = 1/(βz)
```

两处是同一件事的两种取法：**份额层按 `D` 的特征值分裂，图上层按 `z`（或谱半径）分裂**。前者回答“为什么会有多个稳定态”，后者回答“谁先被拉过去”。**A.4 是 `z=1` 的特例，`A.10` 是它的图版本。**

### 2.4 L2 还缺什么

**迟滞不在这一层。** 份额自由能只给“有哪几个稳”，不给“翻过去要多少钱”；带由固定成本 `F₀` 给出（A.5）。**多稳与迟滞是两件事，这一点书里以前混着说过，现在分开了。**

## 3 L3 社会：两时标消去，得到三个能用的量

### 3.1 慢变量从哪来

个人选码以天—周计；份额以月—年计；价格与制度以年—代计。**三层时标分离**是标准前提，于是可以把快的消去：给定价格与制度，份额立刻落在 `P*(γ, w, network)` 上；慢变量只在“份额已到准平衡”的曲面上移动。**这一步不是新假设，是第 5 章已经用过的“绝热消去”。**

### 3.2 三个能用的量（都可查）

**(i) 敏感性 `χ`。** `χ ≡ ∂m/∂h`。平均场下

```
χ ∝ 1 / (1 − βzγ)
```

**越接近阈值，同一个小推动引起的码份额变化越大。** 这不是“社会更敏感”这种形容词，是一个可估的斜率：`h` 的一次外生变化（一次曝光、一次政策）对应的份额变化，除以 `1−βzγ`。

**(ii) 临界慢化（早期预警）。** 同一套展开给出松弛时间

```
τ_relax ∝ 1 / (1 − βzγ)
```

于是**在转折之前，方差与一阶自相关会同时上升**——这正是生态与金融里用过的那组预警信号（Scheffer 等 2009，第 20 章已引）。**本书此前把“突然性”当结果描述；现在它有了一个可查的前兆。**

- **可查形式**：对一条规范/信任的份额序列，在转折前 3—5 个观测窗里算（a）方差、（b）滞后一阶自相关、（c）偏度。**三者同升是慢化的指纹。**
- **必写的对照**：方差上升也可能是噪声 `β` 变大（换测量口径、扩样本），那与“接近阈值”同形不同因。**判别法：看自相关是否也升**——只有慢化会同时抬高自相关。

**(iii) 迟滞带宽 `2C`。** 由 A.5 给出，与 L2 的势垒分开：**宽度看成本，速度看势垒/噪声**（Kramers）。

### 3.3 L3 为什么只是“半通”

因为社会层的四个慢变量里，**只有两个能从 L2 的平衡里长出来**（份额、敏感性），另两个（评价权 `Φ`、账的分配 `ν`）**必须借原理二**：它们是“谁能定账”的对象，不是群体动力学的产物。所以：

> **L1→L2 是纯推导；L2→L3 是“推导＋一个委托人”。少了原理二，第三层只剩一半——这不是本书偷懒，是结构如此。**

而这也解释了全书的结构：第 27 章必须存在，且它是唯一一章用原理二做功。

## 4 L4 文明：不通，而且“不通”的位置很明确

文明层要的涌现是**词表本身**：不是“哪套码占多数”，而是“有哪几套码可选”。这等价于问：**码集 `Q` 从哪来？**

- 若 `Q` 给定，L4 只是 L3 的慢版本（`Q` 固定，份额与价格慢慢漂）。
- 若 `Q` 内生，就必须有一个**在码集上的先验**（对“哪些划分是可能的、可命名的”的先验）。**这个先验就是语义。而语义正是第 26 章第四件空白。**

所以 L4 的诚实说法是：**能用现有公设给出“词表换代的速率上界”，给不出“下一个词是什么”。**

**速率上界怎么来（能写的部分）。** 换一代词表要付 `F₀`，而 `F₀` 被反身性反馈调制（A.11：`g = β(t̄(q) − t̄)`）。于是

```
换代速率  ≤  失真累积速率 / F₀        （A.5）
而 F₀ 的有效值随 βc 变：βc > 2 时“换代”会来回摆，不是单向推进（A.11）
```

**可查形式**：同一类词表（疾病分类、职业分类、学科目录）在各国的改版间隔，与该国“培训 + 立法”成本的代理（改版所需的过渡期、行业培训时数）应当负相关；而 `βc` 高的领域应当出现“改名—改回”的振荡。**本书没有做；但它不需要新数据源，只需要各版分类表的年份。**

## 5 一句话回答作者的问题

**通到第二层，且涌现是导出的**：共享码、多重均衡、极化阈值，全部从“分歧要付钱”这一条代价结构里长出来，阈值是 `β·γ·|λ_min(D)|`。
**第三层半通**：两时标消去给出敏感性、临界慢化与迟滞，**但必须借原理二才有一半变量**。
**第四层不通**：缺的是“码集上的先验”，也就是语义；能给速率上界，给不出内容。

**所以“符合现实世界的好用形式”现在有三件**：阈值的乘法结构、`χ ∝ 1/(1−βzγ)`、以及转折前的方差—自相关同升。**三件都能拿现成序列去查，都不需要新理论。**

## 6 这一份没有做到的（写出来）

1. **涨落与有限规模**：平均场在临界附近错，临界指数不对；要修得用有限规模标度，本书没做。
2. **多于两码的相图**：`D` 的特征值谱在高维上没有闭式；只能数值。
3. **`Q` 的先验**：L4 的缺口不是“以后再算”，是“换工具”（语义）。
4. **`χ` 与 `τ_relax` 的估法**：本节给的是形式，不是估计；要估，得先有一条“外生推力”的序列（政策、曝光），本书没有。

**这一轮补的两处，都是“接口”而不是“新结论”**：
1. **`F₀` 与 `b` 是同一笔钱的两种计法**（每期描述费 vs 一次性重建费），关系写成 `F₀≈k·b·n_重建`。禁掉“两个自由参数分别凑数”，并给出“该用哪条律”的判据。
2. **`z` 是 ⑦→⑧ 的唯一接口，却没有方程**。这是全链最薄的一格：群体层的度（谁能把码传出去）进社会层时就卡住了。补法只有一条：把 `z` 写成 `A` 的函数（A.6 的联立），否则社会层永远要“外部给一个 z”。

**时刻**这一维（ch28 表 28.3）不属于九步里的任何一步，它是**每一层的共同边界**：位置可算、时刻不可算；而在成文制度里，时刻还被排班盖住（A15），在有复位的地方则以“成团”露出来（A16，历法采纳 `B=+0.52`）。

## `z` 收口之后（2026-11-18）

- **式子**：`z_i(q) = Σ_j W_ij · 1{|q_i − q_j| ≥ d}`。执行范围只数**看得出来**的差别。
- **三个模拟结果**（`analysis/sim_endogenous_z.py`）：① 双稳（粗起点→均值 6.5、`z`=0.73；细起点→全员 8、`z`=0）；② `d` 从 1 抬到 2，粗均衡更粗（6.5→3.9）；抬到 3，两个均衡都塌；③ `d`=0 时双稳消失（两起点同分布，均值 6.0、`z`=2.8）。
- **新预言（反直觉）**：**只加重惩罚 `γ`、不提高可观测性，码不变**。罚决定到达上限的速度，可观测性决定上限。
- **收口的诚实说法**：借的东西小了一号——从“借 `z`”变成“借 `d`”。`d` 从哪来（技术＋制度）仍未写。
