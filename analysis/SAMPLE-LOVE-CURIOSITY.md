## 0　这一部分要证明什么

V1 把爱与好奇写成两个偏好权重：`ν` 与 `κ`。V2 不再这样写。V2 要把它们写成**两个引擎**：

- 没有 `ν`，模型只对外部 `w` 反应；有了 `ν`，**别人的错进入你的目标**。
- 没有 `κ`，模型只对现有 `q` 优化；有了 `κ`，**压缩进展本身成为收益**。

两个引擎不是两个参数，是两个**会随环境变的动力学**。这一部分的任务，不是“给爱和好奇各写一章散文”，是**检验**：把这两个引擎放进同一张网络，五件事会不会自己长出来；关掉引擎，五件事会不会消失或转向。**检验结果见 §4.4：不是五件都通过。**

### 0.1 “涌现”的判据

本文的“涌现”不是“看起来像”，是三条：

1. **生成**：聚合层面的现象，由个体层的 `ν`／`κ` 与网络 `A` 生成，不是作为聚合约束硬加进去的。
2. **可关掉**：把 `ν` 或 `κ` 设为常数，现象消失，或方向改变。
3. **可随代理变**：现象的方向随 `φ`（`ν` 的范围）、`γ`（一致性压力）、`C`（换码成本）的可测代理变化。

三条缺一，降为“对应”，不写“涌现”。这一条比“五件事都写到了”重要：**宁可少写一件，不把假设写成结论。**

### 0.2 VOI 改写（2026-11-19）

好奇从 `−κ·IG` 改成 `−VOI`：`κ` 不再是自由参数，而是信息价值的影子价格；`W(N)` 的倒 U 由 VOI 推出；E2 不再单列。

二元决定（先验 `p`，信号准确率 `q`，漏掉代价 `L_FN`，误报代价 `L_FP`）的峰位是：

```
p* = L_FP / (L_FN + L_FP)
```

`L_FN=L_FP` 时峰在 0.5；`L_FN=5、L_FP=1` 时峰在 0.17；`L_FN=1、L_FP=5` 时峰在 0.83。**这是一条新预言：** 好奇的峰位随决定阈值移动，不是固定的 Wundt 曲线。VOI 需要一个决定模型；没有它，好奇仍只能写成 `κ` 或 `IG`。第 8 章已按此改写；`κ` 在群体／品味的旧结果里只作“VOI 的影子价格”简写。

## 1　两个引擎的骨架

### 1.1 `ν`：爱是集中的，不是均匀的

`ν` 不是“善意”，是“别人的失真记进自己账上的权重”。它可以是 0（只在乎自己），可以是负的（从别人的错里获益），也可以大于 1（为别人牺牲自己）。所以“爱”在模型里不是道德评价，是一个**账本结构**。

V1 第 17 章已经把这个位置写过一次：`θ` 是“把别人的错算进自己账上”的权重，而且它还能再降一层——`θ` ≈ 折现因子<sup>时间</sup> × 以后还会遇到他的概率 × 那次相遇值多少。V2 只做一件事：把 `θ` 从一个标量拆成矩阵 `ν_ij`，加上范围 `φ_ij` 与期限 `τ_ij`。这样“爱是集中的”就不是形容词，是矩阵的形状。

`ν` 不是一个标量，是一个矩阵 `ν_ij`：`i` 对 `j` 的错有多疼。它有两个参数：

- **范围** `φ_ij`：谁在“我们”里面。范围随社会距离衰减；亲缘、互惠、依恋、照护，都是不同的 `φ` 形状。
- **期限** `τ_ij`：这份权重持续多久。照护有时限，亲子有时限，制度化的团结也可以有时限。

一个最小的写法（假设 E1，C 级）：

```
ν_ij = ν0 · exp(−d_ij / φ_i) · 1{t < t_i}
```

`d_ij` 是社会距离（亲缘、共同经历、互惠记录、共同 `I(q)` 的任意组合）；`φ_i` 是这个人能“把别人记进来”的范围；`t_i` 是期限；`1{·}` 是指示函数。这个式子不是从 A1 推出来的，是一个**偏好假设**；它的用处是让“爱是集中的”变成一个可以被反驳的句子：若照护时长是均匀分布，或与 `d_ij` 无关，E1 就死。

`ν_ij` 是矩阵；若写成“一个标量权重 `ν` × 一个范围指示 `φ_ij`”，就是 `ν_ij = ν·φ_ij`。舞台第 3 章那个 `ν Σ_j φ_ij w_j` 是这一矩阵的标量版；这里用矩阵版，避免把“爱有多大”与“爱给谁”混成一个数。

爱进入联合泛函的第一项：

```
Σ_i [ w_i + Σ_j ν_ij w_j ] D_i(q∘Π, μ)
```

读法：`i` 错分的疼，加上“`j` 的疼被 `i` 记进来多少”。`ν_ij` 越大，别人的错越像自己的错；`ν_ij` 只在对内那一块高，容易变成排外；`ν_ij` 跨群体也高，才可能成为同化的入口。

### 1.2 `κ`：好奇是压缩进展的定价

`κ` 不是“喜欢新东西”，是“对不确定性的定价”。它乘的是信息增益：

```
IG(q; e) = H(q) − E[H(q | e)]
```

`IG` 是“看到 `e` 之后，码的不确定性减少了多少”。好奇的收益是 `−κ·IG`：`IG` 越大，越值得投入。本书假设 `IG` 对先验不确定性是**单峰**的——先验不确定性太小，没有缺口；太大，缺口合不上；Wundt 曲线是另一个附加假设（C）。两者叠在一起，好奇在中等不确定性处最高，不是越多越好。

`κ` 也不是常数。一个最小的动力学（假设 E2，C 级）：

```
dκ_i/dt = η_κ [ κ0 + a_IG·IG_i − a_γ·γ_i − a_T·T_i − d_κ·κ_i ]
```

读法：信息增益越高、越不被一致性压力压住、时间越宽裕，`κ` 越能起作用；反过来，`γ` 高、`T` 紧，好奇被压回守成。这个式子的系数全部未标定；它的用处不是“算出一个数”，是给三条可查的方向：`T` 越低，`κ` 越能起作用；`γ` 越高，`κ` 越被压；`IG` 越大，探索越可能发生。

### 1.3 两个引擎的相互作用

`ν` 与 `κ` 不是并列的两个偏好，它们会互相拉扯：

- `ν` 高、`κ` 低：团结、守成、对内好、对外硬。
- `ν` 高、`κ` 高：团结且探索，容易产生“我们一起去试新东西”。
- `ν` 低、`κ` 高：探索但不同化，容易产生“各玩各的”。
- `ν` 低、`κ` 低：封闭、重复、靠外部冲击才动。

社会摆动就是这两组参数在时间上的相位差：`κ` 先动（新东西出现），`γ` 后动（大家跟上），`ν` 在中间扩缩（谁被算进“我们”）。**摆动不是一条外加的正弦曲线，是三个量的相位差。**（这是待验方向；最小模型里固定 `γ` 没有产生摆动，见 §4.4。）

## 3　四章提纲

### 第7章　爱：`ν` 的范围与期限

**主提问。** 为什么爱是集中的，不是均匀的？为什么照护时长是重尾的，而“博爱”总是稀薄？

**场景（C）。** 小吴的诊所里，一个女儿每天来给父亲送饭、擦身、记药，四个小时；同一个女儿，在手机里给一个灾区项目捐了五十块。她不是虚伪；她的 `ν` 只对少数人高。这个场景是合成的，用来把“集中”演一遍。

**个体层定义。** `ν_ij`、`φ_ij`、`τ_ij`；`ν` 可正、可负、可大于 1；爱不是均匀的善意，是有范围的账。给一个可测代理：照护时长、关系距离、共同 `I(q)` 的重叠。

**涌现路径（本章与后三章共管五条；正面写群体、文明特质、文化同化，社会摆动与社会品味作收束）：**

1. **群体**：群体边界＝`{j : ν_ij ≥ ν_c}`；群体规模随 `φ` 变；`κ` 的分布决定边界内是否分化。**最小模型里，`ν=1.5` 单独只有 10% 的种子分离；`ν=1.5＋κ=1.0` 才 100% 分离**——爱给边界，好奇给“两边不一样”。案例：开源社区的 fork/merge——维护者替一次坏合并付账（`ν` 高），跨 fork 的 `ν` 低；探索型 fork 的 `κ` 高。数据：GitHub API；等级 A/B。判决线：若群体边界只随平台/语言变，不随 `φ`／`κ` 变，群体这条降为“平台划分”。
2. **文明特质（描述性：五量记账，不作检验）**：`ν` 的范围是五个量之一。案例：明治日本从“藩”到“国民”的 `ν` 扩张；1774《解体新书》、1868 明治、1871 岩仓使节团、1873 征兵令。等级 B。判决线：若两个 `ν` 范围相同、其他四量也相同的案例，行为不同，则五量不够。
3. **文化同化**：`ν` 跨群体＋`I(q)` 重叠＋`γ`＋`C`。案例：印刷术与方言圣经（Luther 1534；Tyndale 1526）；印刷降低 `C`，方言圣经提高 `I(q)` 重叠；`γ` 决定它是“同化”还是“压制”。等级 B。判决线：若同化率不随重叠／`C` 变，机制死。
4. **社会摆动**（与第 8 章共管）：`ν` 的扩缩（危机时扩大、稀缺时收缩）与 `κ`／`γ` 的相位差。案例：灾后互助与排外的交替（灾难社会学；Solnit 2009，B/C）。判决线：若互助/排外只随外部事件变，不随 `ν` 的扩缩变，摆动这条降为“事件响应”。
5. **社会品味**（与第 9 章共管）：`ν` 的范围决定“谁有资格怪”；`κ` 分布决定谁先试；`A` 决定谁先传（A-isolation 通过；完整模型被 `κ` 盖住）；`γ` 决定容忍度。案例：印象派（1874）。判决线：若早期采用者的顺序与 `κ`／`A` 无关，品味这条降为“随机流行”。

**反例。** 爱不是万能的。`ν` 高可以产生裙带、护短、对内好对外硬（parochial altruism）。若模型只产出“好结果”，它就是规范理论，不是描述理论。这一节要写“爱的暗面”，否则读者会把它读成道德赞歌。

**判决线（本章主判决）。** 照护时长应当是重尾的，且与关系距离 `d_ij` 负相关；若照护时长是均匀分布、或与 `d_ij` 无关，`ν` 集中这条死。第二条：若 `ν` 在不同情境下完全不变，它是参数，不是引擎；引擎要求 `ν` 随 `I(q)` 重叠、`C`、危机扩缩而变。

**章末钩子。** 爱是集中的；好奇是倒 U 的。为什么同一种“想要更多”，在爱里变窄，在好奇里变宽？

**字数。** 8,000—9,000 字。**V1 接口。** ch17（`θ`＝`ν` 的平均值、折现的影子价格）、ch27（`ν` 的正支/反支、谁承担）、ch9（`μ`）。

### 第8章　好奇：`κ` 与压缩进展

**主提问。** 为什么好奇是倒 U，不是“越多越好”？为什么一个人会花四十分钟看一个修水管的视频，却划走三百条标题？

**场景（C）。** 凌晨一点，小林还在刷。她一天看三百条标题，却能在一个“维修工怎么找到漏水点”的视频上停四十分钟。不是那个视频更新，是它有一个**合得上的缺口**：她想知道“到底漏在哪”，视频一步一步给出来。好奇不是“新”，是“能闭合的缺口”。

**个体层定义。** `VOI(q;e)`：一条信息能让决定变好多少；`κ` 读作 VOI 的影子价格；倒 U 由 VOI 推出，不再假设 Wundt 曲线。给一个可测代理：探索时间、信息选择、停留时长、提问分布；决定模型（决定集、`L_FN/L_FP`、未来视野）要同页写。

**涌现路径（本章与前后章共管五条；正面写社会摆动，群体从“探索侧”共管，其余三条作收束）：**

1. **群体**：`κ` 分布决定探索／守成的比例（与 `ν` 交互；见 §4.4）；`A` 决定探索能否传播。案例：开源社区的探索型 fork 与稳定 release；数据：GitHub API；等级 A/B。判决线：若探索型 fork 的比例不随 `κ` 的尾部变，群体这条降为“平台激励”。
2. **社会摆动**：`κ`（求新）与 `γ`（求同）的相位差。**E2 单独未通过：固定 `γ` 只产生一步塌缩；加 E4（`γ` 的滞后反馈）后周期 18／28 步**。正文写周期必须同页写 E4；不写 E4 就只写“事件响应”。案例：美国婴儿名字的流行周期（SSA 1880—2023；Lieberson 2000）；`κ` 代理＝稀有名字份额，`γ` 代理＝前几名名字的集中度。等级 A/B。判决线：若周期只随战争/疫情等外部冲击变，不随 `γ` 变，内生摆动死。加一条可查的：稀有名字峰值与集中度峰值之间的滞后，应随 `γ` 变短（最小模型的方向，不是定理）；若跨社会恒定，机制死。
3. **文明特质（描述性：五量记账，不作检验）**：`κ` 开放度是五个量之一。案例：明治日本的兰学／洋学；1774《解体新书》，1868 明治，1871 岩仓；`κ` 开放、`H` 集中（国家主导）、`C` 下降（翻译与学校）。等级 B。判决线：若 `κ` 开放度不能把明治与另一个“五量相同”的案例分开，五量不够。
4. **文化同化**：`κ` 低＋`γ` 高→封闭；`κ` 高＋`γ` 低→借用。案例：印刷术与方言圣经；Luther 1534；等级 B。判决线：若借用/封闭不随 `κ`／`γ` 变，这条降为“宗教政策”。
5. **社会品味**：`κ` 分布＋`A`＋`γ`；早期采用者高 `κ`、网络位置密（A-isolation 通过；完整模型被 `κ` 盖住）；`γ` 低容忍怪。案例：印象派（1874）；等级 B。判决线：若采用顺序与 `κ`／`A` 无关，品味不是涌现。

**反例。** 好奇也会有害。`VOI` 算错、或者 `ρ`（核实延迟）太高时，新码先扩散、后被纠正；V1 的 agent“求偶”就是例子：它先过审美与传播，后过核实与责任，第二关没过，就被弃养。若 VOI 总是提高福利，模型又变成规范理论。

**判决线（本章主判决）。** VOI 应在 `p=0/1` 为零、在决策阈值 `p*=L_FP/(L_FN+L_FP)` 附近最高；给同一批人同一套材料，只改 `p` 或 `L_FN/L_FP`，峰位应随之移动。若峰位不动，VOI 这条死，倒 U 只能作近似。第二条：若好奇高、但信息不能改变任何决定（纯 trivia 高、决策相关信息低），VOI 死，`κ` 要回来。

**章末钩子。** 好奇产生新码；但新码要过一道审美判断，才被保留。为什么有些新东西被留下，有些没有？

**字数。** 8,000—9,000 字。**V1 接口。** ch9（好奇与边际回报）、ch11（带宽、睡眠与利害；新颖表达）。

### 第9章　审美：压缩×连贯×新颖

**主提问。** 为什么有些新东西被保留，有些没有？为什么“新”本身不够？

**场景（B）。** 1874 年，巴黎，第一届独立展。评论家路易·勒鲁瓦用“印象派”讥讽一幅画；这个名字后来成了流派。新画不是“更准确”，是另一种压缩：它把光影的瞬时关系压成几笔，牺牲细节，换连贯与新颖。它先过审美，后过市场与核实。

**个体／群体定义。** 审美值

```
A(q; q0, e) = C(q) · K(q) · W(N)
```

> **记号提醒：** `A=C·K·W(N)` 里的 `C` 是“压缩”，不是“换码成本”；本书两处都用 `C`，正文必须分开（建议压缩写 `C_comp`，换码写 `C_sw`）。这是 V2 排版前必须解决的符号冲突，不能靠读者自己猜。

`C` 是压缩（用更少的格装更多的关系），`K` 是连贯（格与格对得上），`N` 是新颖，`W(N)` 是倒 U（太新看不懂，太旧没人看）。保留概率写成 `Pr(retain)=σ(β[A−A_c])`（假设 E3，C 级）。审美的功能是**在核实之前先筛一遍**：它比核实便宜，决定哪些新码有资格进入核实。

**涌现路径（本章与前后章共管五条；正面写社会品味、文明特质（正典），群体（风格）共管，其余两条作收束）：**

1. **社会品味**：`κ` 分布＋`A` 网络＋`γ` 门槛；高 `κ` 的人先试，`A` 密的人先传，`γ` 低的社会容忍怪。**最小模型：`κ` 通过；`A` 在控制 `κ` 后通过、完整模型里被盖住。**案例：印象派；1874 第一届展，1886 纽约展；画商杜朗—吕埃尔是 `A` 的节点；等级 B。判决线：若早期收藏者的顺序与 `κ`／`A` 无关，品味不是涌现。
2. **群体**：共享风格形成群体；`A` 网络与 `γ` 决定边界。案例：印象派小圈与沙龙体制；等级 B。判决线：若群体边界只随画廊/市场变，不随 `A`／`γ` 变，这条降为“市场划分”。
3. **文明特质（描述性）**：审美经典是五个量之外的“读数”，不是第六个量；它由 `μ`（中心）、`κ`（开放）、`H`（谁定义）、`C`（换码）共同决定。案例：明治日本的“洋画”与“日本画”并存；等级 B/C。判决线：若经典的形成完全由 `Φ` 解释，审美过滤是多余的。
4. **文化同化（部分：重叠通过）**：审美趋同（`I(q)` 重叠上升、`C` 下降）；案例：印刷术与版画风格扩散；等级 B/C。判决线：若趋同不随 `I(q)` 重叠变，这条降为“贸易”。
5. **社会摆动**：审美周期（新奇—疲劳—回摆）；`κ`／`γ`／`W(N)`。案例：印象派之后的反印象派；等级 B/C。判决线：若周期只随市场变，不随 `W(N)` 变，这条降为“市场周期”。

**反例。** 审美判断会被 `Φ` 俘获。经典不是纯 `C·K·W(N)`；谁有命名权，谁就能把某一套写进正典。若 `A` 完全由 `Φ` 解释，审美过滤就只是权力的影子。这一节要写“审美的政治”，否则读者会把它读成“好艺术自然留下”。

**判决线（本章主判决）。** `A=C·K·W(N)` 对保留的预测，应当优于“只靠新颖”的模型；若两者一样好，审美过滤按奥卡姆剃掉。第二条：`W(N)` 应是倒 U；若新颖单调地越好，倒 U 死。

**章末钩子。** 审美决定什么被保留；创造决定什么被生成。新码到底从哪里来？

**字数。** 7,000—8,000 字。**V1 接口。** 审美公式在 V2 样章第 3 章与 `REFOUNDATION.md`，V1 无专章；接口是 ch13（粗码）、ch14（标签）、ch15（注意力）。

### 第10章　创造与保留：新码怎么生成、怎么过选择

**主提问。** 新码从哪里来？为什么大多数新码死了，少数活下来？

**场景（B）。** 1973 年，贝尔实验室，一条竖线把两个程序接起来：前一个的输出，变成后一个的输入。管道不是从零发明，是把“文件”“进程”“标准输入输出”几块旧东西重新拼了一次。新码的第一种来源，是**重组**，不是灵感。

**生成算子。** 五种，全部是旧部件的组合，不是新公设：

- `Rc` 重组：把已有的块拼在一起（管道、集装箱、活字印刷）。
- `An` 类比：把一个领域的关系映射到另一个领域（“城市是身体”“市场是网络”）。
- `Mu` 变异：局部随机改动（错字、误读、手滑）。
- `L` 松弛：去掉一个约束（“必须是一个程序”→“可以是两个”）。
- `Tr` 翻译：把一套码映射到另一套码（《解体新书》、方言圣经）。

生成是便宜的，保留是贵的。一个循环：

```
提案 → 压缩（C） → 连贯（K） → 过审美（W(N)） → 过网络（A/γ） → 核实 → 保留
```

大多数新码死在第二步或第四步；不是“不够新”，是“压不紧、对不上、没人传、核不过”。

**涌现路径（本章与前三章共管五条；正面写文化同化、社会品味（新正典），其余三条作收束）：**

1. **群体**：创造的分工；`ν` 范围决定谁愿意替别人的试错付账；`κ` 分布决定谁去试；`A` 决定试错能否传播。案例：开源社区的模块作者与维护者；GitHub API；等级 A/B。判决线：若分工不随 `ν`／`κ` 变，这条降为“平台规则”。
2. **社会摆动**：新码的爆发与整合；`κ` 高→爆发，`γ` 高→整合；`ν` 的扩缩决定“我们”是否跟着换。案例：印象派之后的市场整合；等级 B/C。判决线：若爆发只随资本变，不随 `κ`／`γ` 变，这条降为“投资周期”。
3. **文明特质（描述性）**：`H` 集中度决定谁能把新码写进正典；`C` 决定换码成本；`μ` 决定中心；`κ` 决定开放；`ν` 决定谁被算进“我们”。案例：明治日本的翻译官僚与《解体新书》；等级 B。判决线：若 `H` 不能把两个案例分开，五量不够。
4. **文化同化（部分：重叠通过）**：借用与翻译；`I(q)` 重叠＋`C`＋`γ`。案例：方言圣经；Luther 1534；等级 B。判决线：若借用不随重叠／`C` 变，这条降为“宗教政策”。
5. **社会品味（`κ` 通过；`A` 控制 `κ` 后通过）**：新正典的形成；`A`＋`γ`＋`κ`。案例：印象派进入博物馆；等级 B。判决线：若新正典的形成与 `A`／`γ` 无关，品味不是涌现。

**反例。** 创造没有选择，就是噪声。若随机生成一千个程序，留下的和按 `C·K·W(N)` 筛出来的差不多，那么“选择”这个故事死。另一个反例：过度选择会杀死新码——`γ` 太高、`T` 太紧，新码在第一步就被压掉。这一节要写“选择的代价”，不是“选择总是好”。

**判决线（本章主判决）。** 新码被保留，应当先过压缩/连贯/审美，再过核实；若存在大量“完全随机但被保留”的新码，选择故事死。第二条：若新颖单调地越好（`W(N)` 不倒 U），审美过滤死。

**章末钩子。** 爱与好奇是引擎；但它们产生的群体、摆动、文明特质、同化、品味，需要一张网络来承载。下一部分：共用码、标签、权力、维护。

**字数。** 7,000—8,000 字。**V1 接口。** ch10（`C` 与 `2C`）、ch12（自我改变）、ch22（转型）、ch23（争议）。

## 4　先验证：最小模型与五个检查

写正文之前，先做一个最小模型。不是“证明”，是“看五件事会不会自己长出来”。若长不出来，改提纲，不改原理。

### 4.1 最小模型

- `N=200` 个 agent；一维或二维特征空间；每个 agent 有一个 `q`（划分）与一个 `μ`（中心）。
- `ν_ij` 按 E1 随距离衰减；`κ_i` 按 E2 随 `IG`、`T`、`γ` 变；`γ` 是全局一致性压力；`A` 是随机图或小世界图。
- 四个情景：`ν` 高/低 × `κ` 高/低；每个情景跑 1,000 步；记录群体边界、周期、五量、同化率、采用顺序。

### 4.2 五个检查

| 现象 | 最小机制 | 看什么 | 通过标准 | 不通过怎么办 |
|---|---|---|---|---|
| 群体 | `ν` 阈值＋`κ` 分布 | 群体边界的模块度；边界与 `φ` 的相关 | 边界随 `φ` 变，且 `κ` 高时群体更探索 | 删“群体从 ν/κ 涌现”，改写成“平台划分” |
| 社会摆动 | `κ` 与 `γ` 的相位差 | 周期、振幅、峰值滞后 | 周期随 `γ` 变短（假设）；`κ` 高时振幅更大 | 删“内生摆动”，改写成“外部冲击响应” |
| 文明特质 | 五量向量 | 五量能否分开四个情景 | 五量分开，且方向与案例一致 | 删“文明特质”，只写“五量描述” |
| 文化同化 | `ν` 跨群体＋重叠＋`C` | 同化率；重叠与 `C` 的偏效应 | 同化率随重叠升、随 `C` 降 | 删“同化机制”，改写成“政策案例” |
| 社会品味 | `κ` 分布＋`A`＋`γ` | 采用顺序；与 `κ`／`A` 的相关 | 高 `κ`、高 `A` 的人先采用 | 删“品味涌现”，改写成“市场随机” |

### 4.3 数据检查（不新增头条读数）

| 检查 | 数据 | 等级 | 用途 |
|---|---|---|---|
| 照护时长重尾 | 时间使用调查（ATUS 等）；照护日志 | B | 判 `ν` 集中 |

## 5　这一部分什么会杀死它

1. **若 `ν`／`κ` 对预测没有增量**：控制 `w`、`T`、`γ` 后，加 `ν`／`κ` 不改善预测，它们就只是两个参数，不是两个引擎。第三部分降为“偏好描述”。
2. **若五件事需要五套不同的辅助假设**：每件事都要新加一条假设才能讲通，“两个引擎”就是假的；应改成“五条独立的涌现假设”，并承认。**最小模型已经显示至少两条：摆动要 E4，同化要强桥；`A` 要控制 `κ` 才看得见。这还不能算“两个引擎包打五件”。**
3. **若所有案例都是 C 级**：第三部分只能叫“研究议程”，不能叫“结果”。
4. **若正文出现“国民性”形容词**：违反五量规则，删；只写 `μ、ν、κ、H、C`。
5. **若社会摆动只随外部冲击变**：内生摆动死；只写“事件响应”，不写“周期”。**最小模型已经触发了这一条：固定 `γ` 的 E2 没有周期；E4 下有 18／28 步周期。**

<div class="note"><b>若反向，什么死：</b>第 1 条死，两个引擎降为两个参数；第 2 条死，“两部分”要拆成“五条假设”；第 3 条死，这一部分不能写成“结果”，只能写成“待验”。</div>
