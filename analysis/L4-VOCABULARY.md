# L4 的锁钥：词汇的复制子（不是"语义先验"）

> 作者判断：四层应该都通，锁钥落在**心理学与语言表征**上，也许藏在"反差名人"那组案例里；底层是**地缘先验**。
> 这一份把这句话变成可写的形式。结论先说：**L4 缺的不是"语义分布"，是一个在词汇上的动力学**；
> 而它的三个部件全都已有理论与数据支撑——**维特根斯坦的"用法"（固定点）、迭代学习的"传递瓶颈"（先验的来源）、语义变化的两条经验律（速率）**。
> 换一种说法：**锁钥是传递通道，不是语义模块。**

---

## 0 一句话链条

```
地理（最慢）→ 决定"哪些区分可观测、有后果"  ⇒ 可行码集 Q_可行
传递（次慢）→ 瓶颈 R 与一次性成本 F₀ 决定"哪些提案活得下来" ⇒ 词汇更新
群体（快）  → γz > δ 决定"哪一套被锁死"            ⇒ 份额
个人（最快）→ 价格决定 v                            ⇒ 分辨率
```

**四层是同一个变分问题的四个时标；而"语义"在这个图里不是一层，是传递通道本身。**

## 1 维特根斯坦给的不是定义，是三个条件

| 维特根斯坦 | 它在这套式子里是什么 | 立即得到的结论 |
|---|---|---|
| **意义＝用法**（PI §43） | 一个码"存在"当且仅当它被使用到能自我维持：`q ∈ Q* ⟺ q 是对 μ(q) 的最优反应` | **词汇不是给定集合，是一个固定点**——与 A.11 的"自洽码"同一个条件，只是提到词汇层 |
| **规则遵循**（§201：没有任何解释能决定应用） | 划分在新情形上的外延不由划分本身决定；**由 `γ`（共同体的执行）决定** | **P3 不是心理学补丁，而是"规则之所以是规则"的可能性条件**——没有 γ 就只有私人的印象 |
| **私人语言**（§243–315） | 一个人的码 `γ=0`；它的外延随时间漂 | **私人码会折旧**——这正是第 10 章那条"码的折旧"，现在有了哲学侧的同一句话 |
| **家族相似**（§66–67） | 不靠必要充分条件，靠 `D(q,q')` 的梯度；原型＝块内条件均值 `μ` | 与 Rosch（1978）、Nosofsky（1986）同构，本书的度量版本正是它的形式 |

**这一步的收益**：第 10 章的"折旧"与第 13 章的"类内方差"以前是两条工程事实，现在它们有同一个根——**没有共同体执行的码，会散**。

## 2 先验从哪来：迭代学习说"先验是通道造出来的"

L4 一直卡在一句话上：「码集 `Q` 的先验给不出，因为那是语义。」
**而 Kirby–Cornish–Smith（2008）的实验与 Kirby 等的模型给了另一条路：先验不必天生，它可以是传递的产物。**

机制：每一代只能看到上一代**有限样本**（瓶颈 `R`）。传递链上，能活下来的结构是那些"在被截断之后还能被复原"的结构——于是**组合性（compositionality）自己长出来**，不需要谁设计它。

放回本书：

```
每一次传递 = 一次有损压缩（R 有限） + 一次一次性成本（F₀：学一套新码要重来）
传递链的稳态 = 在被截断后可复原的码
```

**所以"码集的先验"不是一条外加的分布，而是传递通道的稳态分布。** 这与第 6 章 6.14 的 `b`（切点成本）是同一件事的两种说法：**切点要教，教的通道有瓶颈，瓶颈决定哪些切点留得下来。**

**这一接的价值**：L4 从"缺一个哲学对象"变成"缺一次传递链的计算"。而那种计算**已经有现成做法**（iterated learning 的标准模型），不需要新理论。

## 3 词汇的复制子：L4 的方程

把词汇层写成一个离散动力系统。设词汇 `Q_t`（当前被使用的码集）。每一步发生三件事：

```
① 提案：某个行动者提出一套新划分 q′（成本 F₀，由 P4 给）
② 采纳：q′ 被采纳，当且仅当 γ·z(q′) > δ(q′)        （A.10 的门槛；z 是能把 q′ 传到的人）
③ 自洽：q′ 留下来，当且仅当它面对的分布正是它造出来的那个（A.11 的固定点）
淘汰：连续若干期无人使用（γ 收不上来）的码退出 Q
```

**一句话：`Q_{t+1} = { q ∈ Q_t ∪ 提案 : 过门槛且自洽 }`。** 这不是新公设——①②③ 全是已有部件的组合；它只是把它们放到"词汇"这一层。

**而"反差名人"那组案例正好是这四种提案命运的天然标本**（`analysis/CASE-FIGURES.md` §5—§7、§10.3）：

| 案例型 | 在方程里是什么 | 为什么它落在这一格 |
|---|---|---|
| **抢占**（秦宗权、拿破仑三世） | 提案过不了 γ 门槛，或过了但不自洽 | 秦宗权被部将执送；拿破仑三世过了门槛（顺承既有 γ），却在 1870 年崩——**门槛与自洽是两件事** |
| **陈述**（安重荣"兵强马壮者为之耳"） | 提案已潜伏在 `Q` 里，只是没人说出口 | 人死而语存——**它不需要过门槛，因为它已经是用法** |
| **反例型·变的是后世的码**（冯道、李鸿章） | 提案由**后来的人**提出，且成功 | 冯道没换码；是宋以后把"忠"放进了合法性划分——**这是 L4 最干净的一次观测** |
| **拒绝换码**（恩古吉、德米特鲁克） | 个体层面的"不采纳"，只有被别人跟随即成提案 | 恩古吉拒用英语：个人成本他付了，公共码只在局部改变——**这正是"提案 ≠ 采纳"** |

**这就是作者预感的那把锁**：那组案例不是"人物分析"，是**词汇更新的微观基础**——它们各自对应方程里的一格，而且每一格都有可核的年份与材料。

## 4 语义变化的两条经验律，在本模型里可以推

社会语言学已经量出了两条（Hamilton–Leskovec–Jurafsky 2016，历时词向量）：

- **趋同律**：词频越高，语义变化越慢；
- **创新律**：多义程度越高，语义变化越快。

**在本书里，两条都能从已有式子推出来，而不用新假设：**

- 高频词 ⇒ 用的人多、用得熟 ⇒ 该词的码更准（`D` 更小）⇒ **换码能带来的失真下降更小** ⇒ 换码收益低于 `F₀` ⇒ 变得慢。**趋同律 = "D 已经很小，没什么可赚"。**
- 多义词 ⇒ 同一个码要覆盖两个分布 ⇒ 该码的 `D` 大（歧义就是失真）⇒ **分出新码能省下的失真大** ⇒ 容易变。**创新律 = "D 还很大，有的赚"。**

而两条律恰好是同一个比较的两端：**换码收益 ∝ 现码的失真**。所以它们不是两条独立的经验规律，**是一条式子的两个符号**。

**可查的形式**：把某词的历时变化速率对"该词当时的歧义度（义项数）"与"频次"回归，符号应当一正一负；而本书的说法多一句：**这两条应当被 `F₀` 的代理（跨群体协调成本）调制**——同一个词在协调成本低的环境里应当变得更快。**这一条是本书加的、可被否证的。**

## 5 底层是地缘先验：把作者那句话写准

作者说"底层是地缘先验"。写准一点：**地理不给出码，它给出"哪些区分可观测、哪些区分有后果"。**

- **可观测**：`R(q)` 有限——某些区分在这个环境里根本测不出来（没有仪器、没有记录）。
- **有后果**：`w > 0`——某些区分错了要付钱，另一些错了没人管。
- **支撑宽度**：`Δ` 由地理给（第 4 章 §4.6 与第 21 章讲过：地理的"可用性"在两代人的尺度上会变）。

于是

```
Q_可行 = { q : q 的每一块都可观测，且至少一块有后果 }
```

**这就是"地缘先验"的式子形态**：不是 `P(Q)` 的概率分布，而是一个**可行集**。这也解释了为什么"地理决定论"与"文化自由"两边都能找到证据——**地理定的是可行集，不是选择**。选哪一套，是 `γ` 与 `z` 的事（L2/L3）。

## 6 四层合成一张图

| 时标 | 对象 | 方程 | 涌现出来的东西 | 状态 |
|---|---|---|---|---|
| 天—周 | 个人 | `v* = (T+λ)/(2w)` | （无涌现） | 通 |
| 月—年 | 群体 | 份额自由能；`P_q ∝ e^{−β(h+γDP)}` | **共享码**（对称破缺） | 通（A.10，数值见 A.12） |
| 年—代 | 社会 | `χ ∝ 1/(1−βzγ)`、迟滞 `2C`、`ν` 由委托人定 | 敏感性、临界慢化、迟滞 | 半通（另一半要原理二） |
| 代—世纪 | 文明 | **词汇的复制子**（§3）＋传递瓶颈（§2）＋地缘可行集（§5） | **词表本身** | **候选闭合**（A.13）——三处前提未验 |

**判定改写**：L4 以前写成"不通（缺语义）"。本轮之后更准确的说法是：**"通了形式，没通内容"**——
方程有了（提案—采纳—自洽），速率律有了（§4），可行集有了（§5）；**没通的是"提案者的私码"**：
一个人为什么提出**这一套**划分而不是另一套，那取决于他的私人表征，而私人表征没有 `γ`、不可观测、而且会折旧（§1）。
**所以 L4 的残余不是"语义学"，是"私人表征的不可观测性"。**

## 7 这一步没做到的（四条）

1. **`z(q′)` 怎么算**：能把一套新码传出去的人有多少，需要传播网络数据；本书没有。
2. **提案的到达率**：`Q` 的更新步数（多久出现一次提案）是一个外生率，本书没有估。
3. **私人表征**：不可观测，本节只能把它标成残余（与第 26 章"语义"同一处空白，但现在**位置更准了**）。
4. **数值**：词汇复制子没有跑过。可以跑——`F₀`、`γz`、`δ` 给定后它就是一个有限状态马尔可夫链，A.8 的框架能直接扩。
