## 3 被删掉的六项（这是内化的实质）

来自 `REWALK.md` §8。删掉不是丢弃，是**把过强的假设换成更弱的**：

| 删掉 | 换成什么 |
|---|---|
| 四种人（类型学） | 一条曲线，类型只是曲线上的点 |
| 耗竭指数 `α` | `w` 单调下降即可，不需要幂律（顺带解决了"测不出 α"这件事） |
| 标签比例的独立方程 `π_L` | `π_L` 是 `v` 的读数，不是独立状态 |
| 塔西佗陷阱的外生阈值 `θ_c` | 由 `w, v, τ` 推出 |
| 套利收益比 `Π>1` 作为核心判据 | "失真未被定价"的一个特例 |
| δ 冲击 + 卷积 | `D` 跳升即可，不需要假设冲击形状 |

**净效果**：未知参数 7 → 3（时间/带宽 `T`、利害 `w`、疲劳 `λc''`），三个都有可操纵的对应物。
这就是 `PROTOCOL-gradients.md` 里 2×2×2 设计的来源。
