第22章　改码：每次都要付，来回各付一次

本章主张。换一套码，只付一次钱——但这一次要去、要回，各付一次，所以两个阈值之间是一条宽 2C 的带。带子里的世界很特别：更差的码换不掉，更好的码也推不开，抱怨不改变任何事。 而 C 不只是钱：它还包括重写、重训、停运、与旧码既得者的抵制。

1888 年，一场打字比赛在美国办了起来。参赛者用同一套键盘布局——左上角起手是 Q、W、E、R、T、Y——打同一段文字，比谁快。胜出的那位用的是“盲打”：眼睛不看键盘，十指分工。这场比赛之后，QWERTY 成了事实标准。

这场比赛常被当成“QWERTY 科学的证明”。它不是。它证明的是一件更小的事：盲打能在 QWERTY 上跑得很快。 而“哪套布局更省力”这个问题，此后一百年一直有人测，结论也不完全一致。本章不打算裁决这件事——它要问的是另一个问题：即使有一套更省力的布局，它为什么换不动？

这个问题有一个很干净的答案，而且与布局本身无关。换一套布局的收益，按天摊给每个使用者；换的成本，一次性落在每个使用者身上。 收益是“每千次击键省几分之一秒”，成本是“几个星期打不快”。两者不在同一个量级上，也不在同一个时点上。

此后一百多年，不断有人提出更省力的布局：1936 年 Dvorak 申请了专利，声称能让手指移动的距离减少一大截；后来又有若干种。它们的宣传都不弱，实测也有支持，但都没有取代 QWERTY。

常见的解释是“先入为主”或“路径依赖”，这话不错，但太松。这一章要把它算清：换一套布局要付的钱，不是“换一个软件”，是“让所有已经会打字的人重新学一遍”。 这是一次性的、巨大的、而且必须由使用者自己承担的成本。而收益是“以后打字省力一点”，按天摊、几十年摊。 两笔账一对比，答案就出来了。

22.1　C 是什么：四个成分

第2章与第6章都给过 C 的式子。这一章把它拆成可数的四项，因为“换码很贵”这句话，只有拆开才知道贵在哪儿（表22.1）。

四项之间还有一条“替代链”，解释了为什么有些换码看起来很便宜、实际很贵。重建表可以省（外包写文档），但省下来的会转到“停运与迁移”——文档写得不好，迁移时返工。设备可以拖（先用着旧的），但拖出来的会转到“既得者抵制”——旧设备越用越顺手，越难换。所以四项不是四个独立预算，是一条可以互相挤压的链。

这条链给了一个很实用的判断：看一项换码的预算表，若四项里有某一项是零，那一项的成本一定被推到了别处。 常见的三处推法：把“重建表”推给加班、把“停运”推给客户、把“抵制”推给“以后再说”。推出去的成本不会消失，它会在完工后的第一年回来找你。

四项里最容易被低估的是第四项。旧码上有专用资产的人，是换码最大的阻力，而他们的损失是真实的：一个练了十年 QWERTY 的人，换布局等于把十年折旧掉；一个按旧标准建了产线的厂，换标准等于把设备报废。“抵制”不是保守，是一笔已经付过的钱要求被认账。

还有一个“看不见的既得者”，值得单列：教学与认证体系。 一套码用了很久之后，会沉淀出一整套教材、考试、资格、师傅；换码意味着这些都要重做。而教材与资格的背后是人：编教材的人、出考题的人、靠教这套码吃饭的人。 他们不在“设备清单”里，却在抵制的最前排。所以换码的第四项成分，往往不是“有人反对”，是“有人要重新找活干”。

第四项还有一个“分布”上的特点，决定了抵制有多硬。如果旧码上的投资是分散的（每个人都会一点），抵制是软的——每个人只损失一点，没人愿意出头。如果投资是集中的（一个部门、一个行业、一批师傅），抵制是硬的——他们有组织、有话说、有资源。所以同一个 C 的总额，会因为“分散还是集中”而有完全不同的政治后果。

C 的四个成分还可以按“能不能分期”再分一次。重建表与设备可以分期（先换一部分、先改一条线）；停运不能分期（换的时候就是不能干活）；抵制不能分期（它在决定换的那一刻就发生了，而且随拖延而加强）。两类成本的性质不同：能分期的，可以摊到多年预算里；不能分期的，必须在当期一次拿出来。

这一条解释了一个常见的失败模式：把“不能分期”的那两项，当成“能分期”的那两项来编预算。 于是第一年看起来很便宜，第二三年集中爆发，然后被叫停。叫停时的沉没成本，往往比一开始就付全额还高。

这也是为什么换码很少是“说服”成功的。说服改的是“愿不愿意”，而 C 说的是“付不付得起”。 要真的换，通常得有人在 C 上出一份钱：补偿既得者、承担停运、提供新工具。没有人出这份钱，再好的新码也推不开。

四项成分还可以按“谁付”再切一刀，切完会看见一个很稳定的格局。重建表与设备，通常由组织付（公司、政府、学校）；停运与迁移，由用户与上下游付（等、绕、重做）；既得者抵制，由整个系统付（谈判、延期、补偿）。三种付款人，三种时点，而决定换不换的人，往往只看得见第一种。

这就是换码决策里最常见的一处错位：决策者算的是“我要花多少钱”，而实际的社会成本是“三方加起来”。 当后两方不在决策者的账上时，C 会被系统性低估——于是“看起来划算”的换码，实际推起来处处受阻。受阻不是执行不力，是账算漏了。

22.2　2C：为什么是一条带，不是一个点

第2章的推论四给过结论：去程付一次 C，回程再付一次，所以两个阈值之差是 2C。这里把它画成一条时间线（图22.1）。

带子还有一个“层次”问题。同一个系统里，不同层的 C 不一样。 一个公司换财务软件，个人层的 C 是“学新界面”（几天），组织层的 C 是“改流程与对账”（几个月），行业层的 C 是“改审计与申报口径”（几年）。三层各有一个带子，而且三层的阈值不在同一天被跨过。 所以“换码”往往是分层发生的：个人先换，组织后换，行业最后换——而“看起来换了”的阶段，正好是三层的带子重叠的那一段。 这段时间里，同一件事有三套说法，而三套都不算错。

这个“带子”有一个很容易被忽略的后果：它让同一套码在不同地区、不同行业里处在不同的位置。 一个 C 大的领域（铁路、法律、键盘），全国可能同时存在三四种码，每一种都在自己的带子里不动；一个 C 小的领域（软件默认设置、网页排版），一天之内就能统一。所以“统一不统一”这个问题，不能跨领域问，只能问“在你的 C 下，带子有多宽”。

这条带子还有一个“方向不对称”，值得指出：进入带着容易，走出带着难。 旧码变坏，是随时间慢慢发生的（磨损、纠纷、事故），人是在“实在受不了”的那一刻才换；而新码变坏，是在换过去之后立刻感受到的（不熟、出错、被人抱怨）。于是“换”的那一刻，恰好是体验最差的那一刻。 这就是为什么换码的第一年总被评价得很低——不是新码差，是比较的基准错了：拿新码的第一天，比旧码的第一千天。

左幅的读法有三句。第一句：带子里的“不动”，不是懒，是算过账的——换过去要再付一次 C，而省下的那点坏处不够付。 第二句：带子越宽，系统的“记忆”越长——一个 C 很大的领域（轨距、键盘、法律体系），一次选择能管一个世纪。第三句：带子宽不宽，与码好不好无关——它只与 C 有关。所以“更好的码为什么没赢”这个问题，答案通常在 C 那一栏，不在质量那一栏。

右幅的读法只有一句：C 的大头常常不在设备，在人。 重写与重训、以及既得者的抵制，两项加起来往往超过硬件。这也是为什么“技术上很简单”的改动，实际推起来很难——技术那一项只是四分之一的账。

热点解剖：一次平台改版的 2C 带。一次改版把旧界面换掉，用户骂声很大，却很少立刻走：因为换回去也要付一次 C（重新学、重新配、丢数据）。于是“骂”与“走”之间隔着一条 2C 宽的带：旧版的坏处要涨到 +C，用户才换过去；换过去以后，新版的坏处要降到 −C，才有人换回来。带子里怎么抱怨都不动——这不是用户懒，是回程也要付钱。

可查的样子：若一次改版后“骂声”与“流失”同时爆发，带子不成立；若骂声先到、流失滞后到某个阈值，带子成立。C 级；本书没有平台级留存数据。

分期会把带宽收窄，这一点值得单独算一行。 前面说过 C 的四个成分里，两项能分期、两项不能（§22.1 末）。若把能分期的那部分摊到 N 期，那么每一期面对的换码成本变成 C/N，于是那条“怎么抱怨都不动”的带子从 2C 变成 2C/N——分期不是让换码变便宜，是让“不动”的区间变窄。

分期之后：带宽 = 2C/N　（去程与回程各付 C/N）

这个换算有一个立刻能用的判据：若一类换码常年“推不动”，先问它能不能分期——能，则带宽可以靠预算安排收窄；不能（停运与抵制），则只能靠一次性付钱，或者等一次危机把 D旧 抬上去。这也解释了为什么“分期”在实践里常被当成改革本身：它没改任何技术参数，却把 C 的到期日拆开，让每一期的 C/N 落进“值得换”的区间里。

分期的账也要算全：摊开的每一期，都要同时维护两套码（旧的还没拆、新的要养），这笔并存期的维护费按 §22.6 的三笔账走。所以净收益是 “带宽收窄减去并存期的维护费”；两者相等的那一点，就是分期的极限。超过它，分期只是把一次痛改成长期钝痛——这正是“只付单程票”那种失败的温和版本。

米制那一行还藏着一个细节，值得单独说：它不只是“换单位”，它同时换了进位制。 从十二进制、十六进制、各地杂制，换成十进制——这一步的 C 比“换一个单位名称”大得多，因为它要求所有人在心算上重新学一遍。而它之所以能推成，是因为国家同时做了三件事：立法强制、派员换发标准器、重编教材。 三件事分别对应 C 的三个成分：抵制（立法）、设备（标准器）、重建表（教材）。没有一件是“说服”，全是“替人付钱”。

把三个案例的 C 按四成分摊开，会看见一个很稳定的顺序：重训最大（键盘、米制都是），设备次之（米制），停运第三（轨距），抵制最难估（三者都有）。 而四个成分里，只有“重训”这一项是由使用者个人承担的——所以任何没人替使用者付重训的换码，都会卡住。这一条比“路径依赖”更具体：它不是“历史锁住了”，是“重训费没人出”。

三行一对比，差别只有一个：有没有人替使用者付那笔 C。 米制有人付（国家以法令推行、派员换发标准器），所以换成了；键盘没人付（每个使用者自己承担重训），所以没换成；轨距在新建时 C 被摊进建设费，所以新线统一、老线拖。换码的成败，几乎全看这一句。

三个案例还给出一个“时间长度”的对照，值得记住：键盘换了四十年没换成（1888 至 1936 至 今）；米制换了约一百年（1795 至 1875 至 各国陆续）；轨距在大陆国家换了约五十年，而在新建国家几乎一次到位。 三个数量级不同的时间，对应的不是一个数量级不同的“说服努力”，而是一个数量级不同的“C 的付款人”。有人付，就快；没人付，就慢；永远没人付，就永远不换。

这也给出一条可查的判据：看新码的推广方案里，C 由谁承担。 若方案只讲“新码更好”，不讲“谁来付重训与补偿”，那它多半推不动——不是因为它错，是因为它把成本留给了最没有能力承担的人。

三个案例里还有一个“时间上的规律”，值得单说：成功的换码，几乎都发生在旧码的坏处被一次事件放大之后，或者发生在新系统新建之时。 米制赶上了革命与度量混乱，轨距赶上了新线铺设，而键盘没有赶上任何一件事——它只是“想更好一点”，而“更好一点”推不动 2C。

这条规律给了一个很实际的建议：想换码的人，要等一个“窗口”，而不是等一个“论证”。 窗口有三种：事故（旧码的坏处突然显形）、新建（C 被摊薄）、强制（有人替使用者付 C）。三种窗口之外，最好的论证也只能换来“再研究研究”。

22.4　顺序：先改价，还是先改码

悟已往之不谏，知来者之可追。

——陶渊明《归去来兮辞》

第3章讲过两个算子不对易：改价格的 Uw 与改码的 Uq。换码这件事，把不对易变成了一个可算的量：环面积 ∝ C·|ΔD|。

环面积这个量还有一个“可做实验”的版本：同一批人，一半先被告知“错了要赔”，再被要求改变分类；另一半反过来。 若两组的最终分类分布有系统差异，环面积不为零。这个实验很便宜，而且不需要长期跟踪——它只需要两组人的一次选择。 这个实验还没有人做，而它是本章少数几个“可以当版就做”的设计。

读法很直：先抬价再换码，人是在“贵”的背景下换的，换完以后回头看，会觉得自己“被逼的”；先换码再抬价，人是在“便宜”的背景下换的，换完以后回头看，会觉得自己“选的”。两条路走到同一个终点，但留下的记忆不同，而下一次换码的阻力，正来自这些记忆。

环面积有三个可查的后果。一、C 越大的领域，顺序的痕迹越明显（键盘布局换了以后，人会记很久“当初是被迫的”）。二、C 接近零时，顺序几乎没有痕迹（软件改个默认值，没人记得先后）。三、两次路径的失真差越大，痕迹越大——所以“先改价”与“先改码”的差别，在那些“价格与质量强相关”的领域最大。

顺序还有一个“可见性”的用法：先降 C 的动作是看得见的（发了新工具、给了补偿、开了培训班），先抬 w 的动作也是看得见的（加了罚款、加了追责）。两者都可见，但方向相反：一个说“我帮你”，一个说“我要你”。 同一套政策，先做哪一个，公众记住的就是哪一个。这解释了为什么有些改革“内容一样、反响相反”——顺序不同。

这一条对政策有直接用处：如果想让一个新码站住，最好先降 C（给工具、给补偿），再抬 w（加后果）。 反过来的顺序，能换来短期的服从，但会在下一次改革时付出更高的谈判成本。

顺序这件事还有一层“记忆”的后果，值得写清。同样一次换码，被记住的方式不同，下一次的成本就不同。 若第一次是“被逼的”，第二次改革要付出更高的说服成本；若第一次是“自己选的”，第二次会容易些。所以顺序不只是路径问题，是“信任存量”的问题——而信任存量，是第9章那个 θ。

这也是为什么“先降 C 再抬 w”这条建议，不只是效率考虑。降 C 的动作（给工具、给补偿）本身就是一个信号：这次不是要你吃亏。 而抬 w 的动作（加后果）如果先做，信号就反了：这次是要你付。两个动作的顺序，决定了同一套政策被读成“帮忙”还是“惩罚”。

22.5　四种失败

换码不是“换成”或“没换成”两种结果。它有四种典型的失败，各有各的样子（表22.3）。

四种失败各自有一个“最省钱的对照检查”。只付单程票：查旧通道有没有被关；没关，就一定会回去。新旧并存：查双轨的成本记在谁账上；若三方各摊一点，它就永远结束不了。改了壳没改核：遮住新名字，看流程能不能被认出来。换了没人用：查实际使用率与影子系统；有影子，说明 C 高于收益。

四检查还有一个共同的“时间陷阱”：它们都只能在换码之后做。 而在换码之前，能做的只有“估”。估的办法有一个：找一个已经换过的同类组织，看它的这四项是怎么演的。 这比任何模型都便宜，也比任何模型都准——因为 C 的四项，几乎全是“组织内部的知识”，外面的人估不出来，换过的人一问就知道。

四个检查都不需要新数据，只需要一次现场观察。它们的共同点是：不看“新码有没有发布”，看“旧码有没有被关掉”。 这一条很土，但它把“改革成效”从“文件层”拉到了“行动层”。

四种里最常见的是第一种，也最容易被误读为“改革失败”。它不是失败，是只买了一张票。 去程付了 C，回程没设门槛；于是当新码的维护费开始到期（第一年之后），人们发现回去更便宜。要让它站住，必须把旧码的维护费抬上去——旧流程要额外签字、旧单据要额外说明、旧系统要额外维护。这一条与第17章那个“改流程”的动作，是同一件事。

第二种（新旧并存）的根源不是技术，是权力：没有任何一个人有资格说“从明天起，旧码不算数”。而“谁有资格宣布作废”，正是第16章那三件套里的执行权。 三件分开的机构，最容易卡在这一格。

第三种最隐蔽，也最常见于“改名式改革”。名字换了，解释没换，执行没换——于是新名字底下跑的还是旧流程。判据很土：把新名字遮住，看流程能不能被认出来是新的。

四种失败里，第二种（新旧并存）有一个可查的成本：双轨运行的成本，通常等于两套码各自的维持费之和，再加上桥的成本。 而双轨之所以能长期存在，是因为没有任何一方单独承担全部成本——组织承担一部分，执行者承担一部分，桥上的翻译承担一部分。成本被摊薄，于是没有人有动力结束它。

这一条解释了很多“改革改了十年还在改”的现象：不是因为难，是因为双轨对每一方都还过得去。 要结束它，得让某一方承担“继续双轨”的全部成本——通常的做法是设一个截止日，并把旧通道关掉。截止日本身不产生效益，它只是把成本重新集中。

22.6　谁付账

换码的账，落在三处，三处都不在“决定换码的人”身上。

第一处是旧码上的既得者。 他们投过资（时间、设备、资质），换码等于让这些投资折旧。这一笔账通常是显性的：补偿、转岗、培训。 而它常常被写成“改革成本”，模糊了“谁收到、谁付出”。

第二处是执行者。 换码的过渡期，他们要同时会用两套码；错一次，责任在他们。这一笔账是隐性的：加班、出错、被投诉。 它与第17章那个“末梢的人”是同一个位置。

第三处是桥上的人。 新旧并存期间，跨两套码说话的人（翻译、基层、客服）要额外做一次转换。这一笔账最不容易看见，因为它落在“多说一句话”上。

还有一处账要单列：换码期间，组织的“记忆”会断。 旧码里的经验（哪种情形该怎么处理）不在新码里，而新码的规则还没积累出经验。这一段空档里，人只能靠临时判断；而临时判断不出现在任何流程里。 这一条与第12章那个“码的折旧”是同一件事：换码不是替换，是先归零再重建。

三处之外，还有一处“向下转”的账：换码的成本，往往被推给最没有议价权的那一环——一线员工、供应商、外包、用户。推的方式很朴素：不加工资、不延交期、不给过渡期。 这一条与第20章那条“外部性转嫁”是同一个动作，只是发生在时间轴上而不是价格轴上：把当期的成本推给下一环，把过渡期的成本推给末梢。

三处合起来，可以写成一个很朴素的判断：换码的收益是分散的、延迟的；成本是集中的、当期的。 这就是为什么“更好的码”常常推不动——不是因为它不好，是因为它的好处要等，而坏处立刻到。

三处账单里，最需要写清的是第一处的“谁收到”。补偿与转岗不是平均发的：它按“有没有组织”发。 有组织的（部门、行业协会、工会）能拿到补偿与过渡期；没组织的（个体、临时工、用户）拿不到。于是同一笔 C，在报销单上是一个总数，在人与人之间是一次再分配。 而这一次再分配，通常不出现在换码的评估里。

三处账单之外，还有一处“没人记的账”：过渡期的错误率。 两套码并行的时候，人会按旧码做事、按新码填表；错一次，返工一次。这笔成本落在执行者身上，通常表现为“最近差错变多了”，而不表现为“换码成本”。 它与第17章那个“走过场”同源：考核的是“有没有换”，不是“换得对不对”。

过渡期的错误率还有一个“学习曲线”的形状，值得一说：刚换的第一个月，错误率最高；第三个月回落；第六个月往往低于旧码时期。 这条 U 形曲线有一个直接的后果：如果在第三个月做评估，任何一次换码都会显得失败。 而现实里的评估，恰好常常在第三个月做。这不是评估者不专业，是评估的时点被项目周期决定了。

所以“换码的总成本”这句说法，其实是四笔账：C 的四个成分、加上过渡期的错误率。而预算里通常只列第一笔。 这一条解释了为什么换码总是超支——不是估算不准，是科目不全。

22.7　反例与边界

还要认一处本章没做的：它没有算过任何一个真实的 C。 四个成分都只是“可数”，不是“已数”；2C 的带子也只是形状，不是任何一个领域的实测宽度。要把带子量出来，需要一样东西：同一批人在两个时点的选择。 这需要面板数据，而换码这种事，本来就不常发生——所以这个领域的经验研究，天然是“案例多、面板少”。 本章因此只给结构，不给宽度。

这一章最容易被读成“改不动就算了”。四句话把它按回去。

第一，C 可以被降下来。 工具（模板、转换器）、培训、补偿，三样都是在降 C。降到某个程度，换码就从“不划算”变成“划算”。 所以“路径依赖”不是命，是一个可以买的选项。

第二，新建是最好的窗口。 新建时 C 被摊进本来就要付的成本里，所以新线、新系统、新机构用新码，几乎不额外花钱。这条策略不是妥协，是把 C 藏进沉没成本。

第三，危机能压低 C。 一次事故、一场战争、一次系统崩溃，会让“旧码继续用下去的成本”突然变大，于是 C 相对变小。这就是为什么很多制度变革发生在危机之后——不是因为危机让人聪明，是因为它改了分母。

第四，不是所有旧码都该换。 一个码能在很长时间里不被换掉，可能不是因为它好，也可能因为它“够用而 C 太高”。这两种情形要分开：前者不该换，后者换不起。 判据是“新码的收益能不能在合理期限内摊完 C”——能，是换不起；不能，是不该换。

22.7.1　这一章怎么用：三问与一个窗口

三问，判断一次换码能不能成。一、C 的四个成分各是多少，谁付？ 只算第一项的方案，几乎都会超支。二、带子有多宽？ 带子越宽，越需要“窗口”（事故、新建、强制），越不能靠论证。三、旧码的维护费抬不抬？ 不抬，就是只买单程票，两年后会回摆。

一个窗口：事故、新建、强制。三者之外，最好的论证也只能换来“再研究研究”。而三者的共同点，都是“有人替使用者付了那笔 C”——事故让旧码的坏处突然显形，新建让 C 摊进沉没成本，强制让国家或组织出钱。

还要留一句给“不改”这个选项。本章通篇在讲 C，容易被读成“能改就改”。 但模型里没有这个意思：当旧码仍够用、而新码的收益要几十年才摊完 C 时，“不改”就是最优解。 键盘那一例，与其说是失败，不如说是一个恰当的决定——QWERTY 够用，重训的成本付不起。真正的问题不在“有没有换”，在“有没有算过账”；算了账之后不换，与没算账就不换，是两件事。

三问与一个窗口，是本章能给出的全部工具。它们不告诉你“该不该换”——那是价值判断；它们告诉你“换得起换不起、什么时候换”。

22.7.2　这一条怎么查：换码的四个痕迹

看什么。 换码成本 C 没有直接读数，但它留下四个可查的痕迹：①重训的时长（新人多久能独立做对）；②停运的天数（切换期产出掉多少）；③旧件的清点（多少东西要重做、重印、重录）；④既得者的组织化程度（有没有协会、有没有反对的公开文本）。四个里前三个能算，第四个只能判。

去哪查。 ①人事与培训记录（课时、考核通过率）；②生产或服务的日均量（切换前后各取三个月）；③库存与档案清单（改一版要重做多少件）；④行业志、工会记录、公开信。四处都在机构内部，但前三处的汇总数通常出现在年报里。

查不到怎么记。 缺第 ② 项（停运），就只能报“C 的上界”；缺第 ④ 项（组织化），只能报“C 的下界”——因为抵制会把 C 推高，而抵制是看不见的那一部分。 本书的写法是把能算的三项列出来，第四项写“未测”，不把它折成一个系数塞进 C——一折，C 就成了作者的态度。

22.8　本章小结

最后补一句本章与下一章的接口。2C 的带子说的是“回得去”，下一章说的是“回不去”——两者的分界正是带子的宽度。 当 C 有限时，旧码再坏也能回去（只是要付钱）；当某件事的“回去”需要重建整个系统（比如鱼群、土壤、信任），C 就趋于无穷，那时不再是带子，而是单向门。所以“临界”不是另一个现象，是 2C 的极限情形。

五句。第一，C 有四个成分：重建表、设备与物理、停运与迁移、既得者抵制；大头常常不在设备，在人。第二，去程与回程各付一次，所以两阈值之间是一条宽 2C 的带；带子里怎么抱怨都不动。第三，三个案例的差别只有一句：有没有人替使用者付那笔 C——米制有人付，键盘没人付，轨距在新建时摊进了建设费。第四，顺序有痕迹：环面积 ∝ C·|ΔD|，所以最好先降 C 再抬 w。第五，四种失败里最常见的是“只付单程票”：旧码的维护费没抬，回程比去程便宜。

一句话带走：更好的码推不开，通常不是因为不够好，是因为没人替使用者付那笔重训的钱。

钩子。带子宽到一定程度，会出现一种更硬的局面：不是“换不换”，是“回不回得去”。下一章讲临界：1992 年那条禁令之后，鳕鱼为什么二十年没回来。
